# Fibbinary number

 [Add links](https://www.wikidata.org/wiki/Special:EntityPage/Q108913632#sitelinks-wikipedia)                          From Wikipedia, the free encyclopedia   Numbers whose binary representation does not contain two consecutive ones

In [mathematics](https://en.wikipedia.org/wiki/Mathematics), the **fibbinary numbers** are the numbers whose [binary representation](https://en.wikipedia.org/wiki/Binary_representation) does not contain two consecutive ones. That is, they are sums of distinct and non-consecutive [powers of two](https://en.wikipedia.org/wiki/Power_of_two).[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)[[2]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-arndt-2)

## Relation to binary and Fibonacci numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Fibbinary_number&action=edit&section=1)]

The fibbinary numbers were given their name by Marc LeBrun, because they combine certain properties of [binary numbers](https://en.wikipedia.org/wiki/Binary_number) and [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number):[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)

- The number of fibbinary numbers less than any given power of two is a Fibonacci number. For instance, there are 13 fibbinary numbers less than 32, the numbers 0, 1, 2, 4, 5, 8, 9, 10, 16, 17, 18, 20, and 21.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)
- The condition of having no two consecutive ones, used in binary to define the fibbinary numbers, is the same condition used in the [Zeckendorf representation](https://en.wikipedia.org/wiki/Zeckendorf_representation) of any number as a sum of non-consecutive Fibonacci numbers.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)
- The     n   {\displaystyle n}  th fibbinary number (counting 0 as the 0th number) can be calculated by expressing     n   {\displaystyle n}   in its Zeckendorf representation, and re-interpreting the resulting binary sequence as the binary representation of a number.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1) For instance, the Zeckendorf representation of 19 is 101001 (where the 1's mark the positions of the Fibonacci numbers used in the expansion 19 = 13 + 5 + 1), the binary sequence 101001, interpreted as a binary number, represents 41 = 32 + 8 + 1, and the 19th fibbinary number is 41.
- The     n   {\displaystyle n}  th fibbinary number (again, counting 0 as 0th) is [even](https://en.wikipedia.org/wiki/Parity_(mathematics)) or [odd](https://en.wikipedia.org/wiki/Parity_(mathematics)) if and only if the     n   {\displaystyle n}  th value in the [Fibonacci word](https://en.wikipedia.org/wiki/Fibonacci_word) is 0 or 1, respectively.[[3]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-kimberling-3)

## Properties

[[edit](https://en.wikipedia.org/w/index.php?title=Fibbinary_number&action=edit&section=2)]

Because the property of having no two consecutive ones defines a [regular language](https://en.wikipedia.org/wiki/Regular_language), the binary representations of fibbinary numbers can be recognized by a [finite automaton](https://en.wikipedia.org/wiki/Finite_automaton), which means that the fibbinary numbers form a [2-automatic set](https://en.wikipedia.org/wiki/Automatic_sequence).[[4]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-allsha-4)

The fibbinary numbers include the [Moser–de Bruijn sequence](https://en.wikipedia.org/wiki/Moser%E2%80%93de_Bruijn_sequence), sums of distinct powers of four. Just as the fibbinary numbers can be formed by reinterpreting Zeckendorff representations as binary, the Moser–de Bruijn sequence can be formed by reinterpreting binary representations as quaternary.[[5]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-mdb-5)

A number     n   {\displaystyle n}   is a fibbinary number if and only if the [binomial coefficient](https://en.wikipedia.org/wiki/Binomial_coefficient)         (    3 n  n   )       {\displaystyle {\tbinom {3n}{n}}}   is odd.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1) Relatedly,     n   {\displaystyle n}   is fibbinary if and only if the central [Stirling number of the second kind](https://en.wikipedia.org/wiki/Stirling_numbers_of_the_second_kind)       {    2 n  n   }     {\displaystyle \textstyle \left\{{2n \atop n}\right\}}   is odd.[[6]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-chaman-6)

Every fibbinary number      f  i     {\displaystyle f_{i}}   takes one of the two forms     2  f  j     {\displaystyle 2f_{j}}   or     4  f  j   + 1   {\displaystyle 4f_{j}+1}  , where      f  j     {\displaystyle f_{j}}   is another fibbinary number.[[3]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-kimberling-3)[[7]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-madwag-7) Correspondingly, the [power series](https://en.wikipedia.org/wiki/Power_series) whose exponents are fibbinary numbers,     B ( x ) = 1 + x +  x  2   +  x  4   +  x  5   +  x  8   + ⋯ ,   {\displaystyle B(x)=1+x+x^{2}+x^{4}+x^{5}+x^{8}+\cdots ,}   obeys the [functional equation](https://en.wikipedia.org/wiki/Functional_equation)[[2]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-arndt-2)     B ( x ) = x B (  x  4   ) + B (  x  2   ) .   {\displaystyle B(x)=xB(x^{4})+B(x^{2}).}

[Madritsch & Wagner (2010)](https://en.wikipedia.org/wiki/Fibbinary_number#CITEREFMadritschWagner2010) provide asymptotic formulas for the number of [integer partitions](https://en.wikipedia.org/wiki/Integer_partition) in which all parts are fibbinary.[[7]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-madwag-7)

If a [hypercube graph](https://en.wikipedia.org/wiki/Hypercube_graph)      Q  d     {\displaystyle Q_{d}}   of dimension     d   {\displaystyle d}   is indexed by [integers](https://en.wikipedia.org/wiki/Integer) from 0 to      2  d   − 1   {\displaystyle 2^{d}-1}  , so that two [vertices](https://en.wikipedia.org/wiki/Vertex_(graph_theory)) are adjacent when their indexes have binary representations with [Hamming distance](https://en.wikipedia.org/wiki/Hamming_distance) one, then the [subset](https://en.wikipedia.org/wiki/Subset) of vertices indexed by the fibbinary numbers forms a [Fibonacci cube](https://en.wikipedia.org/wiki/Fibonacci_cube) as its [induced subgraph](https://en.wikipedia.org/wiki/Induced_subgraph).[[8]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-klavzar-8)

Every number has a fibbinary multiple. For instance, 15 is not fibbinary, but multiplying it by 11 produces 165 (101001012), which is.[[9]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-multiple-9)

In [mathematics](https://en.wikipedia.org/wiki/Mathematics), the **fibbinary numbers** are the numbers whose [binary representation](https://en.wikipedia.org/wiki/Binary_representation) does not contain two consecutive ones. That is, they are sums of distinct and non-consecutive [powers of two](https://en.wikipedia.org/wiki/Power_of_two).[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)[[2]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-arndt-2)

Relation to binary and Fibonacci numbers

# Relation to binary and Fibonacci numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Fibbinary_number&action=edit&section=1)]

The fibbinary numbers were given their name by Marc LeBrun, because they combine certain properties of [binary numbers](https://en.wikipedia.org/wiki/Binary_number) and [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number):[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)

- The number of fibbinary numbers less than any given power of two is a Fibonacci number. For instance, there are 13 fibbinary numbers less than 32, the numbers 0, 1, 2, 4, 5, 8, 9, 10, 16, 17, 18, 20, and 21.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)
- The condition of having no two consecutive ones, used in binary to define the fibbinary numbers, is the same condition used in the [Zeckendorf representation](https://en.wikipedia.org/wiki/Zeckendorf_representation) of any number as a sum of non-consecutive Fibonacci numbers.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1)
- The     n   {\displaystyle n}  th fibbinary number (counting 0 as the 0th number) can be calculated by expressing     n   {\displaystyle n}   in its Zeckendorf representation, and re-interpreting the resulting binary sequence as the binary representation of a number.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1) For instance, the Zeckendorf representation of 19 is 101001 (where the 1's mark the positions of the Fibonacci numbers used in the expansion 19 = 13 + 5 + 1), the binary sequence 101001, interpreted as a binary number, represents 41 = 32 + 8 + 1, and the 19th fibbinary number is 41.
- The     n   {\displaystyle n}  th fibbinary number (again, counting 0 as 0th) is [even](https://en.wikipedia.org/wiki/Parity_(mathematics)) or [odd](https://en.wikipedia.org/wiki/Parity_(mathematics)) if and only if the     n   {\displaystyle n}  th value in the [Fibonacci word](https://en.wikipedia.org/wiki/Fibonacci_word) is 0 or 1, respectively.[[3]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-kimberling-3)

Properties

# Properties

[[edit](https://en.wikipedia.org/w/index.php?title=Fibbinary_number&action=edit&section=2)]

Because the property of having no two consecutive ones defines a [regular language](https://en.wikipedia.org/wiki/Regular_language), the binary representations of fibbinary numbers can be recognized by a [finite automaton](https://en.wikipedia.org/wiki/Finite_automaton), which means that the fibbinary numbers form a [2-automatic set](https://en.wikipedia.org/wiki/Automatic_sequence).[[4]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-allsha-4)

The fibbinary numbers include the [Moser–de Bruijn sequence](https://en.wikipedia.org/wiki/Moser%E2%80%93de_Bruijn_sequence), sums of distinct powers of four. Just as the fibbinary numbers can be formed by reinterpreting Zeckendorff representations as binary, the Moser–de Bruijn sequence can be formed by reinterpreting binary representations as quaternary.[[5]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-mdb-5)

A number     n   {\displaystyle n}   is a fibbinary number if and only if the [binomial coefficient](https://en.wikipedia.org/wiki/Binomial_coefficient)         (    3 n  n   )       {\displaystyle {\tbinom {3n}{n}}}   is odd.[[1]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-oeis-1) Relatedly,     n   {\displaystyle n}   is fibbinary if and only if the central [Stirling number of the second kind](https://en.wikipedia.org/wiki/Stirling_numbers_of_the_second_kind)       {    2 n  n   }     {\displaystyle \textstyle \left\{{2n \atop n}\right\}}   is odd.[[6]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-chaman-6)

Every fibbinary number      f  i     {\displaystyle f_{i}}   takes one of the two forms     2  f  j     {\displaystyle 2f_{j}}   or     4  f  j   + 1   {\displaystyle 4f_{j}+1}  , where      f  j     {\displaystyle f_{j}}   is another fibbinary number.[[3]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-kimberling-3)[[7]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-madwag-7) Correspondingly, the [power series](https://en.wikipedia.org/wiki/Power_series) whose exponents are fibbinary numbers,     B ( x ) = 1 + x +  x  2   +  x  4   +  x  5   +  x  8   + ⋯ ,   {\displaystyle B(x)=1+x+x^{2}+x^{4}+x^{5}+x^{8}+\cdots ,}   obeys the [functional equation](https://en.wikipedia.org/wiki/Functional_equation)[[2]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-arndt-2)     B ( x ) = x B (  x  4   ) + B (  x  2   ) .   {\displaystyle B(x)=xB(x^{4})+B(x^{2}).}

[Madritsch & Wagner (2010)](https://en.wikipedia.org/wiki/Fibbinary_number#CITEREFMadritschWagner2010) provide asymptotic formulas for the number of [integer partitions](https://en.wikipedia.org/wiki/Integer_partition) in which all parts are fibbinary.[[7]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-madwag-7)

If a [hypercube graph](https://en.wikipedia.org/wiki/Hypercube_graph)      Q  d     {\displaystyle Q_{d}}   of dimension     d   {\displaystyle d}   is indexed by [integers](https://en.wikipedia.org/wiki/Integer) from 0 to      2  d   − 1   {\displaystyle 2^{d}-1}  , so that two [vertices](https://en.wikipedia.org/wiki/Vertex_(graph_theory)) are adjacent when their indexes have binary representations with [Hamming distance](https://en.wikipedia.org/wiki/Hamming_distance) one, then the [subset](https://en.wikipedia.org/wiki/Subset) of vertices indexed by the fibbinary numbers forms a [Fibonacci cube](https://en.wikipedia.org/wiki/Fibonacci_cube) as its [induced subgraph](https://en.wikipedia.org/wiki/Induced_subgraph).[[8]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-klavzar-8)

Every number has a fibbinary multiple. For instance, 15 is not fibbinary, but multiplying it by 11 produces 165 (101001012), which is.[[9]](https://en.wikipedia.org/wiki/Fibbinary_number#cite_note-multiple-9)
