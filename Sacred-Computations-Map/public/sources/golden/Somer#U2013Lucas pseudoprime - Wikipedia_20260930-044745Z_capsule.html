# Somer–Lucas pseudoprime

- [Español](https://es.wikipedia.org/wiki/N%C3%BAmero_pseudoprimo_de_Somer-Lucas)
 [Edit links](https://www.wikidata.org/wiki/Special:EntityPage/Q7559991#sitelinks-wikipedia)                          From Wikipedia, the free encyclopedia   Type of odd composite number

In [mathematics](https://en.wikipedia.org/wiki/Mathematics), specifically [number theory](https://en.wikipedia.org/wiki/Number_theory), an [odd](https://en.wikipedia.org/wiki/Odd_number) and [composite number](https://en.wikipedia.org/wiki/Composite_number) *N* is a **Somer–Lucas *d*-[pseudoprime](https://en.wikipedia.org/wiki/Pseudoprime)** (with given *d* ≥ 1) if there exists a nondegenerate [Lucas sequence](https://en.wikipedia.org/wiki/Lucas_sequence)     U ( P , Q )   {\displaystyle U(P,Q)}   with the discriminant     D =  P  2   − 4 Q ,   {\displaystyle D=P^{2}-4Q,}   such that     gcd ( N , D ) = 1   {\displaystyle \gcd(N,D)=1}   and the rank appearance of *N* in the sequence *U*(*P*, *Q*) is

       1 d    (  N −  (   D N   )   )  ,   {\displaystyle {\frac {1}{d}}\left(N-\left({\frac {D}{N}}\right)\right),}

where      (   D N   )    {\displaystyle \left({\frac {D}{N}}\right)}   is the [Jacobi symbol](https://en.wikipedia.org/wiki/Jacobi_symbol).

## Applications

[[edit](https://en.wikipedia.org/w/index.php?title=Somer%E2%80%93Lucas_pseudoprime&action=edit&section=1)]

Unlike the standard [Lucas pseudoprimes](https://en.wikipedia.org/wiki/Lucas_pseudoprime), there is no known efficient primality test using the Lucas *d*-pseudoprimes. Hence they are not generally used for computation.

## See also

[[edit](https://en.wikipedia.org/w/index.php?title=Somer%E2%80%93Lucas_pseudoprime&action=edit&section=2)]

Lawrence Somer, in his 1985 thesis, also defined the [Somer d-pseudoprimes](https://en.wikipedia.org/wiki/Somer_d-pseudoprime?action=edit&redlink=1). They are described in brief on page 117 of Ribenboim 1996.
