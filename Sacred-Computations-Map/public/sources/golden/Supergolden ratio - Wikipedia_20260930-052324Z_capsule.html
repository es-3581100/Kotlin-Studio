In mathematics, the **supergolden ratio** is a geometrical [proportion](https://en.wikipedia.org/wiki/Aspect_ratio), given by the unique real [solution](https://en.wikipedia.org/wiki/Polynomial_root) of the equation *x*3 = *x*2 + 1. Its decimal expansion begins with 1.465571231876768...  (sequence [A092526](https://oeis.org/A092526) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)).

The name *supergolden ratio* is by analogy with the [golden ratio](https://en.wikipedia.org/wiki/Golden_ratio), the positive solution of the equation *x*2 = *x* + 1.

## Narayana sequence

[[edit](https://en.wikipedia.org/w/index.php?title=Supergolden_ratio&action=edit&section=3)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/e/ee/Supergolden_Rauzy_cub.png/330px-Supergolden_Rauzy_cub.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Supergolden_Rauzy_cub.png)A [Rauzy fractal](https://en.wikipedia.org/wiki/Supergolden_ratio#matrix) associated with the supergolden ratio-cubed. The central tile and its three subtiles have areas in the ratios ψ4 : ψ2 : ψ : 1.[![](https://thumb.wikimedia.org/wikipedia/commons/thumb/c/ca/Supergolden_Rauzy_sqr.png/330px-Supergolden_Rauzy_sqr.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Supergolden_Rauzy_sqr.png)A Rauzy fractal associated with the supergolden ratio-squared, with areas as above.

Narayana's cows is a [recurrence sequence](https://en.wikipedia.org/wiki/Constant-recursive_sequence) originating from a problem proposed by the 14th century Indian mathematician [Narayana Pandita](https://en.wikipedia.org/wiki/Narayana_Pandita_(mathematician)).[[7]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-oeiscow-9) He asked for the number of cows and calves in a herd after 20 years, beginning with one cow in the first year, where each cow gives birth to one calf each year from the age of three onwards.

The Narayana sequence has a close connection to the [Fibonacci](https://en.wikipedia.org/wiki/Fibonacci_sequence) and [Padovan sequences](https://en.wikipedia.org/wiki/Padovan_sequence) and plays an important role in data coding, cryptography and combinatorics. The number of [compositions](https://en.wikipedia.org/wiki/Composition_(combinatorics)) of n into parts 1 and 3 is counted by the *n*th Narayana number.

The Narayana sequence is defined by the third-order [recurrence relation](https://en.wikipedia.org/wiki/Recurrence_relation)      N  n   =  N  n − 1   +  N  n − 3     for   n > 2 ,   {\displaystyle N_{n}=N_{n-1}+N_{n-3}{\text{ for }}n>2,}   with initial values      N  0   =  N  1   =  N  2   = 1.   {\displaystyle N_{0}=N_{1}=N_{2}=1.}

The first few terms are 1, 1, 1, 2, 3, 4, 6, 9, 13, 19, 28, 41, 60, 88,... (sequence [A000930](https://oeis.org/A000930) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)). The limit ratio between consecutive terms is the supergolden ratio:     lim  n → ∞    N  n + 1    /   N  n   = ψ .   {\displaystyle \lim _{n\rightarrow \infty }N_{n+1}/N_{n}=\psi .}

The first 11 indices n for which      N  n     {\displaystyle N_{n}}   is prime are n = 3, 4, 8, 9, 11, 16, 21, 25, 81, 6241, 25747 (sequence [A170954](https://oeis.org/A170954) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)). The last number has 4274 decimal digits.

The sequence is extended to negative indices using      N  n   =  N  n + 3   −  N  n + 2   ,   {\displaystyle N_{n}=N_{n+3}-N_{n+2},}   obtaining (1), 0, 0, 1, 0,−1, 1, 1,−2, 0, 3,−2,−3, 5,...

Powers of the supergolden ratio can be written with Narayana numbers as quadratic coefficients      ψ  n   =  ψ  2    N  n − 2   + ψ  N  n − 4   +  N  n − 3   ,   {\displaystyle \psi ^{n}=\psi ^{2}N_{n-2}+\psi N_{n-4}+N_{n-3},}   which is proved by [mathematical induction](https://en.wikipedia.org/wiki/Mathematical_induction) on ⁠    n .   {\displaystyle n.}  ⁠ This relation also holds for ⁠    n < 0.   {\displaystyle n<0.}  ⁠ The order of the coefficients corresponds to the bottom row of matrix ⁠    Q   {\displaystyle Q}  ⁠ below.

The [generating function](https://en.wikipedia.org/wiki/Generating_function) of the Narayana sequence for non-negative ⁠    n   {\displaystyle n}  ⁠ is given by       1  1 − x −  x  3      =  ∑  n = 0   ∞    N  n    x  n     for   x <    1 ψ      {\displaystyle {\frac {1}{1-x-x^{3}}}=\sum _{n=0}^{\infty }N_{n}x^{n}{\text{ for }}x<{\tfrac {1}{\psi }}}

The Narayana numbers are related to sums of [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficient) by      N  n   =  ∑  k = 0   ⌊ n  /  3 ⌋      (    n − 2 k  k   )      {\displaystyle N_{n}=\sum _{k=0}^{\lfloor n/3\rfloor }{n-2k \choose k}}

The [characteristic equation](https://en.wikipedia.org/wiki/Characteristic_equation_(calculus)) of the recurrence is      x  3   −  x  2   − 1 = 0.   {\displaystyle x^{3}-x^{2}-1=0.}   If the three solutions are real root ⁠    ψ   {\displaystyle \psi }  ⁠ and conjugate pair ⁠    β   {\displaystyle \beta }  ⁠ and ⁠    γ   {\displaystyle \gamma }  ⁠, the Narayana numbers are given by the [Binet formula](https://en.wikipedia.org/wiki/Fibonacci_sequence#Binet's_formula) [[8]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-10)      N  n − 1   = a  ψ  n   + b  β  n   + c  γ  n   ,   {\displaystyle N_{n-1}=a\psi ^{n}+b\beta ^{n}+c\gamma ^{n},}   with real ⁠    a   {\displaystyle a}  ⁠ and conjugates ⁠    b   {\displaystyle b}  ⁠ and ⁠    c   {\displaystyle c}  ⁠ the roots of     31  x  3   − 3 x − 1 = 0.   {\displaystyle 31x^{3}-3x-1=0.}

Since      |  b  β  n   + c  γ  n    |  <  ψ  − n  /  2     {\displaystyle \left\vert b\beta ^{n}+c\gamma ^{n}\right\vert <\psi ^{-n/2}}  , the number ⁠     N  n     {\displaystyle N_{n}}  ⁠ is the [nearest integer](https://en.wikipedia.org/wiki/Nearest_integer_function) to ⁠     a   ψ  n + 1     {\displaystyle \,a\,\psi ^{n+1}}  ⁠, with ⁠    n ≥ 0   {\displaystyle n\geq 0}  ⁠ and coefficient     a =  ψ  2    /  (  ψ  3   + 2 ) =   {\displaystyle a=\psi ^{2}/(\psi ^{3}+2)=}   0.4172379879262187776214755...

Coefficients     a = b = c = 1   {\displaystyle a=b=c=1}   result in the Binet formula for the related sequence      A  n   =  N  n   + 2  N  n − 3   .   {\displaystyle A_{n}=N_{n}+2N_{n-3}.}

The first few terms are 3, 1, 1, 4, 5, 6, 10, 15, 21, 31, 46, 67, 98, 144,... (sequence [A001609](https://oeis.org/A001609) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)).

This anonymous sequence has the [Fermat property](https://en.wikipedia.org/wiki/Fermat's_little_theorem): if p is prime,      A  p   ≡  A  1    mod  p   .   {\displaystyle A_{p}\equiv A_{1}{\bmod {p}}.}   The converse does not hold, but the small number of odd [pseudoprimes](https://en.wikipedia.org/wiki/Pseudoprime)      n ∣ (  A  n   − 1 )   {\displaystyle \,n\mid (A_{n}-1)}   makes the sequence special.[[9]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-11) The 8 odd composite numbers below 108  to pass the test are n = 1155, 552599, 2722611, 4822081, 10479787, 10620331, 16910355, 66342673.

### Supergolden rectangle

A supergolden rectangle is a [rectangle](https://en.wikipedia.org/wiki/Rectangle) whose side lengths are in a ⁠    ψ : 1   {\displaystyle \psi :1}  ⁠ ratio. Compared to the [golden rectangle](https://en.wikipedia.org/wiki/Golden_rectangle), the supergolden rectangle has one more degree of [self-similarity](https://en.wikipedia.org/wiki/Self-similarity).

Given a rectangle of height 1, length ⁠    ψ   {\displaystyle \psi }  ⁠ and diagonal length        ψ  3       {\displaystyle {\sqrt {\psi ^{3}}}}   (according to     1 +  ψ  2   =  ψ  3     {\displaystyle 1+\psi ^{2}=\psi ^{3}}  ). The triangles on the diagonal have [altitudes](https://en.wikipedia.org/wiki/Altitude_(triangle))     1  /    ψ    ;   {\displaystyle 1/{\sqrt {\psi }}\,;}   each perpendicular foot divides the diagonal in ratio ⁠     ψ  2     {\displaystyle \psi ^{2}}  ⁠.

On the left-hand side, cut off a square of side length 1 and mark the intersection with the falling diagonal. The remaining rectangle now has [aspect ratio](https://en.wikipedia.org/wiki/Aspect_ratio)      ψ  2   : 1   {\displaystyle \psi ^{2}:1}   (according to     ψ − 1 =  ψ  − 2     {\displaystyle \psi -1=\psi ^{-2}}  ). Divide the original rectangle into four parts by a second, horizontal cut passing through the intersection point.[[13]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-15)[[14]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-16)

The rectangle below the diagonal has aspect ratio ⁠     ψ  3     {\displaystyle \psi ^{3}}  ⁠, the other three are all supergolden rectangles, with a fourth one between the feet of the altitudes. The parent rectangle and the four scaled copies have linear sizes in the ratios      ψ  3   :  ψ  2   : ψ :  ψ  2   − 1 : 1.   {\displaystyle \psi ^{3}:\psi ^{2}:\psi :\psi ^{2}-1:1.}  It follows from the [theorem of the gnomon](https://en.wikipedia.org/wiki/Theorem_of_the_gnomon) that the areas of the two rectangles opposite the diagonal are equal.

In the supergolden rectangle above the diagonal, the process is repeated at a scale of ⁠    1 :  ψ  2     {\displaystyle 1:\psi ^{2}}  ⁠.

### Supergolden spiral

[[edit](https://en.wikipedia.org/w/index.php?title=Supergolden_ratio&action=edit&section=7)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/e/ea/Supergolden_spiral.svg/500px-Supergolden_spiral.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Supergolden_spiral.svg)Supergolden spirals with different initial radii on a ψ− rectangle.

A supergolden spiral is a [logarithmic spiral](https://en.wikipedia.org/wiki/Logarithmic_spiral) that gets wider by a factor of ⁠    ψ   {\displaystyle \psi }  ⁠ for every quarter turn. It is described by the [polar equation](https://en.wikipedia.org/wiki/Polar_equation)     r ( θ ) = a exp ⁡ ( k θ ) ,   {\displaystyle r(\theta )=a\exp(k\theta ),}   with initial radius ⁠    a   {\displaystyle a}  ⁠ and parameter     k =   2 π   ln ⁡ ( ψ ) .   {\displaystyle k={\frac {2}{\pi }}\ln(\psi ).}   If drawn on a supergolden rectangle, the spiral has its pole at the foot of altitude of a triangle on the diagonal and passes through vertices of rectangles with aspect ratio ⁠    ψ   {\displaystyle \psi }  ⁠ which are perpendicularly aligned and successively scaled by a factor ⁠     ψ  − 1   .   {\displaystyle \psi ^{-1}.}  ⁠

In mathematics, the **supergolden ratio** is a geometrical [proportion](https://en.wikipedia.org/wiki/Aspect_ratio), given by the unique real [solution](https://en.wikipedia.org/wiki/Polynomial_root) of the equation *x*3 = *x*2 + 1. Its decimal expansion begins with 1.465571231876768...  (sequence [A092526](https://oeis.org/A092526) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)).

The name *supergolden ratio* is by analogy with the [golden ratio](https://en.wikipedia.org/wiki/Golden_ratio), the positive solution of the equation *x*2 = *x* + 1.

# Narayana sequence

[[edit](https://en.wikipedia.org/w/index.php?title=Supergolden_ratio&action=edit&section=3)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/e/ee/Supergolden_Rauzy_cub.png/330px-Supergolden_Rauzy_cub.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Supergolden_Rauzy_cub.png)A [Rauzy fractal](https://en.wikipedia.org/wiki/Supergolden_ratio#matrix) associated with the supergolden ratio-cubed. The central tile and its three subtiles have areas in the ratios ψ4 : ψ2 : ψ : 1.[![](https://thumb.wikimedia.org/wikipedia/commons/thumb/c/ca/Supergolden_Rauzy_sqr.png/330px-Supergolden_Rauzy_sqr.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Supergolden_Rauzy_sqr.png)A Rauzy fractal associated with the supergolden ratio-squared, with areas as above.

Narayana's cows is a [recurrence sequence](https://en.wikipedia.org/wiki/Constant-recursive_sequence) originating from a problem proposed by the 14th century Indian mathematician [Narayana Pandita](https://en.wikipedia.org/wiki/Narayana_Pandita_(mathematician)).[[7]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-oeiscow-9) He asked for the number of cows and calves in a herd after 20 years, beginning with one cow in the first year, where each cow gives birth to one calf each year from the age of three onwards.

The Narayana sequence has a close connection to the [Fibonacci](https://en.wikipedia.org/wiki/Fibonacci_sequence) and [Padovan sequences](https://en.wikipedia.org/wiki/Padovan_sequence) and plays an important role in data coding, cryptography and combinatorics. The number of [compositions](https://en.wikipedia.org/wiki/Composition_(combinatorics)) of n into parts 1 and 3 is counted by the *n*th Narayana number.

The Narayana sequence is defined by the third-order [recurrence relation](https://en.wikipedia.org/wiki/Recurrence_relation)      N  n   =  N  n − 1   +  N  n − 3     for   n > 2 ,   {\displaystyle N_{n}=N_{n-1}+N_{n-3}{\text{ for }}n>2,}   with initial values      N  0   =  N  1   =  N  2   = 1.   {\displaystyle N_{0}=N_{1}=N_{2}=1.}

The first few terms are 1, 1, 1, 2, 3, 4, 6, 9, 13, 19, 28, 41, 60, 88,... (sequence [A000930](https://oeis.org/A000930) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)). The limit ratio between consecutive terms is the supergolden ratio:     lim  n → ∞    N  n + 1    /   N  n   = ψ .   {\displaystyle \lim _{n\rightarrow \infty }N_{n+1}/N_{n}=\psi .}

The first 11 indices n for which      N  n     {\displaystyle N_{n}}   is prime are n = 3, 4, 8, 9, 11, 16, 21, 25, 81, 6241, 25747 (sequence [A170954](https://oeis.org/A170954) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)). The last number has 4274 decimal digits.

The sequence is extended to negative indices using      N  n   =  N  n + 3   −  N  n + 2   ,   {\displaystyle N_{n}=N_{n+3}-N_{n+2},}   obtaining (1), 0, 0, 1, 0,−1, 1, 1,−2, 0, 3,−2,−3, 5,...

Powers of the supergolden ratio can be written with Narayana numbers as quadratic coefficients      ψ  n   =  ψ  2    N  n − 2   + ψ  N  n − 4   +  N  n − 3   ,   {\displaystyle \psi ^{n}=\psi ^{2}N_{n-2}+\psi N_{n-4}+N_{n-3},}   which is proved by [mathematical induction](https://en.wikipedia.org/wiki/Mathematical_induction) on ⁠    n .   {\displaystyle n.}  ⁠ This relation also holds for ⁠    n < 0.   {\displaystyle n<0.}  ⁠ The order of the coefficients corresponds to the bottom row of matrix ⁠    Q   {\displaystyle Q}  ⁠ below.

The [generating function](https://en.wikipedia.org/wiki/Generating_function) of the Narayana sequence for non-negative ⁠    n   {\displaystyle n}  ⁠ is given by       1  1 − x −  x  3      =  ∑  n = 0   ∞    N  n    x  n     for   x <    1 ψ      {\displaystyle {\frac {1}{1-x-x^{3}}}=\sum _{n=0}^{\infty }N_{n}x^{n}{\text{ for }}x<{\tfrac {1}{\psi }}}

The Narayana numbers are related to sums of [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficient) by      N  n   =  ∑  k = 0   ⌊ n  /  3 ⌋      (    n − 2 k  k   )      {\displaystyle N_{n}=\sum _{k=0}^{\lfloor n/3\rfloor }{n-2k \choose k}}

The [characteristic equation](https://en.wikipedia.org/wiki/Characteristic_equation_(calculus)) of the recurrence is      x  3   −  x  2   − 1 = 0.   {\displaystyle x^{3}-x^{2}-1=0.}   If the three solutions are real root ⁠    ψ   {\displaystyle \psi }  ⁠ and conjugate pair ⁠    β   {\displaystyle \beta }  ⁠ and ⁠    γ   {\displaystyle \gamma }  ⁠, the Narayana numbers are given by the [Binet formula](https://en.wikipedia.org/wiki/Fibonacci_sequence#Binet's_formula) [[8]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-10)      N  n − 1   = a  ψ  n   + b  β  n   + c  γ  n   ,   {\displaystyle N_{n-1}=a\psi ^{n}+b\beta ^{n}+c\gamma ^{n},}   with real ⁠    a   {\displaystyle a}  ⁠ and conjugates ⁠    b   {\displaystyle b}  ⁠ and ⁠    c   {\displaystyle c}  ⁠ the roots of     31  x  3   − 3 x − 1 = 0.   {\displaystyle 31x^{3}-3x-1=0.}

Since      |  b  β  n   + c  γ  n    |  <  ψ  − n  /  2     {\displaystyle \left\vert b\beta ^{n}+c\gamma ^{n}\right\vert <\psi ^{-n/2}}  , the number ⁠     N  n     {\displaystyle N_{n}}  ⁠ is the [nearest integer](https://en.wikipedia.org/wiki/Nearest_integer_function) to ⁠     a   ψ  n + 1     {\displaystyle \,a\,\psi ^{n+1}}  ⁠, with ⁠    n ≥ 0   {\displaystyle n\geq 0}  ⁠ and coefficient     a =  ψ  2    /  (  ψ  3   + 2 ) =   {\displaystyle a=\psi ^{2}/(\psi ^{3}+2)=}   0.4172379879262187776214755...

Coefficients     a = b = c = 1   {\displaystyle a=b=c=1}   result in the Binet formula for the related sequence      A  n   =  N  n   + 2  N  n − 3   .   {\displaystyle A_{n}=N_{n}+2N_{n-3}.}

The first few terms are 3, 1, 1, 4, 5, 6, 10, 15, 21, 31, 46, 67, 98, 144,... (sequence [A001609](https://oeis.org/A001609) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)).

This anonymous sequence has the [Fermat property](https://en.wikipedia.org/wiki/Fermat's_little_theorem): if p is prime,      A  p   ≡  A  1    mod  p   .   {\displaystyle A_{p}\equiv A_{1}{\bmod {p}}.}   The converse does not hold, but the small number of odd [pseudoprimes](https://en.wikipedia.org/wiki/Pseudoprime)      n ∣ (  A  n   − 1 )   {\displaystyle \,n\mid (A_{n}-1)}   makes the sequence special.[[9]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-11) The 8 odd composite numbers below 108  to pass the test are n = 1155, 552599, 2722611, 4822081, 10479787, 10620331, 16910355, 66342673.

# Supergolden rectangle

[[edit](https://en.wikipedia.org/w/index.php?title=Supergolden_ratio&action=edit&section=6)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/d/d8/Supergolden_ratio.svg/500px-Supergolden_ratio.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Supergolden_ratio.svg)Nested supergolden rectangles with perpendicular diagonals and side lengths in powers of ψ.

A supergolden rectangle is a [rectangle](https://en.wikipedia.org/wiki/Rectangle) whose side lengths are in a ⁠    ψ : 1   {\displaystyle \psi :1}  ⁠ ratio. Compared to the [golden rectangle](https://en.wikipedia.org/wiki/Golden_rectangle), the supergolden rectangle has one more degree of [self-similarity](https://en.wikipedia.org/wiki/Self-similarity).

Given a rectangle of height 1, length ⁠    ψ   {\displaystyle \psi }  ⁠ and diagonal length        ψ  3       {\displaystyle {\sqrt {\psi ^{3}}}}   (according to     1 +  ψ  2   =  ψ  3     {\displaystyle 1+\psi ^{2}=\psi ^{3}}  ). The triangles on the diagonal have [altitudes](https://en.wikipedia.org/wiki/Altitude_(triangle))     1  /    ψ    ;   {\displaystyle 1/{\sqrt {\psi }}\,;}   each perpendicular foot divides the diagonal in ratio ⁠     ψ  2     {\displaystyle \psi ^{2}}  ⁠.

On the left-hand side, cut off a square of side length 1 and mark the intersection with the falling diagonal. The remaining rectangle now has [aspect ratio](https://en.wikipedia.org/wiki/Aspect_ratio)      ψ  2   : 1   {\displaystyle \psi ^{2}:1}   (according to     ψ − 1 =  ψ  − 2     {\displaystyle \psi -1=\psi ^{-2}}  ). Divide the original rectangle into four parts by a second, horizontal cut passing through the intersection point.[[13]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-15)[[14]](https://en.wikipedia.org/wiki/Supergolden_ratio#cite_note-16)

The rectangle below the diagonal has aspect ratio ⁠     ψ  3     {\displaystyle \psi ^{3}}  ⁠, the other three are all supergolden rectangles, with a fourth one between the feet of the altitudes. The parent rectangle and the four scaled copies have linear sizes in the ratios      ψ  3   :  ψ  2   : ψ :  ψ  2   − 1 : 1.   {\displaystyle \psi ^{3}:\psi ^{2}:\psi :\psi ^{2}-1:1.}  It follows from the [theorem of the gnomon](https://en.wikipedia.org/wiki/Theorem_of_the_gnomon) that the areas of the two rectangles opposite the diagonal are equal.

In the supergolden rectangle above the diagonal, the process is repeated at a scale of ⁠    1 :  ψ  2     {\displaystyle 1:\psi ^{2}}  ⁠.
