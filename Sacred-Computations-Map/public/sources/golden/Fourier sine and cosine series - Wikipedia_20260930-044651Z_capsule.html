# Fourier sine and cosine series

- [العربية](https://ar.wikipedia.org/wiki/%D9%85%D8%AA%D8%B3%D9%84%D8%B3%D9%84%D8%A9_%D9%81%D9%88%D8%B1%D9%8A%D9%8A%D9%87_%D9%84%D8%AF%D9%88%D8%A7%D9%84_%D8%A7%D9%84%D8%AC%D9%8A%D8%A8_%D9%88%D8%AC%D9%8A%D8%A8_%D8%A7%D9%84%D8%AA%D9%85%D8%A7%D9%85)

In [mathematics](https://en.wikipedia.org/wiki/Mathematics), particularly the field of [calculus](https://en.wikipedia.org/wiki/Calculus) and [Fourier analysis](https://en.wikipedia.org/wiki/Fourier_analysis), the **Fourier sine and cosine series** are two [mathematical series](https://en.wikipedia.org/wiki/Mathematical_series) named after [Joseph Fourier](https://en.wikipedia.org/wiki/Joseph_Fourier).

## Notation

[[edit](https://en.wikipedia.org/w/index.php?title=Fourier_sine_and_cosine_series&action=edit&section=1)]

In this article, *f* denotes a [real](https://en.wikipedia.org/wiki/Real_number)-valued [function](https://en.wikipedia.org/wiki/Function_(mathematics)) on      R    {\displaystyle \mathbb {R} }   which is [periodic](https://en.wikipedia.org/wiki/Periodic_function) with period 2*L*.

## Sine series

[[edit](https://en.wikipedia.org/w/index.php?title=Fourier_sine_and_cosine_series&action=edit&section=2)]

If *f* is an [odd function](https://en.wikipedia.org/wiki/Odd_function) with period     2 L   {\displaystyle 2L}  , then the Fourier Half Range sine series of *f* is defined to be     f ( x ) =  ∑  n = 1   ∞    b  n   sin ⁡  (    n π x  L   )    {\displaystyle f(x)=\sum _{n=1}^{\infty }b_{n}\sin \left({\frac {n\pi x}{L}}\right)}   which is just a form of complete [Fourier series](https://en.wikipedia.org/wiki/Fourier_series) with the only difference that      a  0     {\displaystyle a_{0}}   and      a  n     {\displaystyle a_{n}}   are zero, and the series is defined for half of the [interval](https://en.wikipedia.org/wiki/Interval_(mathematics)).

In the formula we have      b  n   =   2 L    ∫  0   L   f ( x ) sin ⁡  (    n π x  L   )   d x ,  n ∈  N  .   {\displaystyle b_{n}={\frac {2}{L}}\int _{0}^{L}f(x)\sin \left({\frac {n\pi x}{L}}\right)\,dx,\quad n\in \mathbb {N} .}

## Cosine series

[[edit](https://en.wikipedia.org/w/index.php?title=Fourier_sine_and_cosine_series&action=edit&section=3)]

If *f* is an [even function](https://en.wikipedia.org/wiki/Even_function) with a period     2 L   {\displaystyle 2L}  , then the Fourier cosine series is defined to be     f ( x ) =    a  0   2   +  ∑  n = 1   ∞    a  n   cos ⁡  (    n π x  L   )    {\displaystyle f(x)={\frac {a_{0}}{2}}+\sum _{n=1}^{\infty }a_{n}\cos \left({\frac {n\pi x}{L}}\right)}   where      a  n   =   2 L    ∫  0   L   f ( x ) cos ⁡  (    n π x  L   )   d x ,  n ∈   N   0   .   {\displaystyle a_{n}={\frac {2}{L}}\int _{0}^{L}f(x)\cos \left({\frac {n\pi x}{L}}\right)\,dx,\quad n\in \mathbb {N} _{0}.}

## Remarks

[[edit](https://en.wikipedia.org/w/index.php?title=Fourier_sine_and_cosine_series&action=edit&section=4)]

This notion can be generalized to functions which are not even or odd, but then the above formulas will look different.
