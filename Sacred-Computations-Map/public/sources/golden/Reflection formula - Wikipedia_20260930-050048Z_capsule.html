In [mathematics](https://en.wikipedia.org/wiki/Mathematics), a **reflection formula** or **reflection relation** for a [function](https://en.wikipedia.org/wiki/Function_(mathematics)) f is a relationship between *f*(*a* − *x*) and *f*(*x*). It is a special case of a [functional equation](https://en.wikipedia.org/wiki/Functional_equation). It is common in mathematical literature to use the term "functional equation" for what are specifically reflection formulae.

Reflection formulae are useful for [numerical computation](https://en.wikipedia.org/wiki/Numerical_analysis) of [special functions](https://en.wikipedia.org/wiki/Special_function). In effect, an approximation that has greater accuracy or only converges on one side of a reflection point (typically in the positive half of the [complex plane](https://en.wikipedia.org/wiki/Complex_plane)) can be employed for all arguments.

## Known formulae

[[edit](https://en.wikipedia.org/w/index.php?title=Reflection_formula&action=edit&section=1)]

The [even and odd functions](https://en.wikipedia.org/wiki/Even_and_odd_functions) satisfy by definition simple reflection relations around *a* = 0. For all even functions,

f ( − x ) = f ( x ) ,   {\displaystyle f(-x)=f(x),}

and for all odd functions,

f ( − x ) = − f ( x ) .   {\displaystyle f(-x)=-f(x).}

A famous relationship is **Euler's reflection formula**

Γ ( z ) Γ ( 1 − z ) =   π  sin ⁡  ( π z )     ,  z ∉  Z    {\displaystyle \Gamma (z)\Gamma (1-z)={\frac {\pi }{\sin {(\pi z)}}},\qquad z\not \in \mathbb {Z} }

for the [gamma function](https://en.wikipedia.org/wiki/Gamma_function)     Γ ( z )   {\textstyle \Gamma (z)}  , due to [Leonhard Euler](https://en.wikipedia.org/wiki/Leonhard_Euler).

There is also a reflection formula for the general n-th order [polygamma function](https://en.wikipedia.org/wiki/Polygamma_function) *ψ*(*n*)(*z*),

ψ  ( n )   ( 1 − z ) + ( − 1  )  n + 1    ψ  ( n )   ( z ) = ( − 1  )  n   π    d  n    d  z  n      cot ⁡  ( π z )    {\displaystyle \psi ^{(n)}(1-z)+(-1)^{n+1}\psi ^{(n)}(z)=(-1)^{n}\pi {\frac {d^{n}}{dz^{n}}}\cot {(\pi z)}}

which springs trivially from the fact that the polygamma functions are defined as the derivatives of     ln ⁡ Γ   {\textstyle \ln \Gamma }   and thus inherit the reflection formula.

The [dilogarithm](https://en.wikipedia.org/wiki/Dilogarithm) also satisfies a reflection formula,[[1]](https://en.wikipedia.org/wiki/Reflection_formula#cite_note-1)[[2]](https://en.wikipedia.org/wiki/Reflection_formula#cite_note-2)

Li  2   ⁡ ( z ) +  Li  2   ⁡ ( 1 − z ) = ζ ( 2 ) − ln ⁡ ( z ) ln ⁡ ( 1 − z )   {\displaystyle \operatorname {Li} _{2}(z)+\operatorname {Li} _{2}(1-z)=\zeta (2)-\ln(z)\ln(1-z)}

The [Riemann zeta function](https://en.wikipedia.org/wiki/Riemann_zeta_function) *ζ*(*z*) satisfies

ζ ( 1 − z )   ζ ( z )    =    2  Γ ( z )   ( 2 π  )  z      cos ⁡  (    π z  2   )  ,   {\displaystyle {\frac {\zeta (1-z)}{\zeta (z)}}={\frac {2\,\Gamma (z)}{(2\pi )^{z}}}\cos \left({\frac {\pi z}{2}}\right),}

and the [Riemann Xi function](https://en.wikipedia.org/wiki/Riemann_Xi_function) *ξ*(*z*) satisfies

ξ ( z ) = ξ ( 1 − z ) .   {\displaystyle \xi (z)=\xi (1-z).}
