In [number theory](https://en.wikipedia.org/wiki/Number_theory), the **Padovan sequence** is the [sequence of integers](https://en.wikipedia.org/wiki/Integer_sequence) *P*(*n*) defined[[1]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-ps-1) by the initial values:

P ( 0 ) = P ( 1 ) = P ( 2 ) = 1 ,   {\displaystyle P(0)=P(1)=P(2)=1,}

and the [recurrence relation](https://en.wikipedia.org/wiki/Recurrence_relation)

P ( n ) = P ( n − 2 ) + P ( n − 3 ) .   {\displaystyle P(n)=P(n-2)+P(n-3).}

The first few values of *P*(*n*) are

 1, 1, 1, 2, 2, 3, 4, 5, 7, 9, 12, 16, 21, 28, 37, 49, 65, 86, 114, 151, 200, 265, ... (sequence [A000931](https://oeis.org/A000931) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)) [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/4/4d/Padovan_triangles_%281%29.svg/500px-Padovan_triangles_%281%29.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Padovan_triangles_(1).svg)Spiral of [equilateral triangles](https://en.wikipedia.org/wiki/Equilateral_triangle) with side lengths which follow the Padovan sequence.

The Padovan sequence is named after [Richard Padovan](https://en.wikipedia.org/wiki/Richard_Padovan) who attributed its discovery to [Dutch](https://en.wikipedia.org/wiki/Netherlands) architect [Hans van der Laan](https://en.wikipedia.org/wiki/Hans_van_der_Laan) in his 1994 essay *Dom. Hans van der Laan: Modern Primitive*.[[2]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-dhdl-2) The [sequence](https://en.wikipedia.org/wiki/Sequence) was described by [Ian Stewart](https://en.wikipedia.org/wiki/Ian_Stewart_(mathematician)) in his [Scientific American](https://en.wikipedia.org/wiki/Scientific_American) column *Mathematical Recreations* in June 1996.[[3]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-3) He also writes about it in one of his books, "Math Hysteria: Fun Games With Mathematics". [[4]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-stewart-4)

*The above definition is the one given by Ian Stewart and by [MathWorld](https://en.wikipedia.org/wiki/MathWorld). Other sources may start the sequence at a different place, in which case some of the identities in this article must be adjusted with appropriate offsets.*

## Recurrence relations

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=1)]

In the spiral, each [triangle](https://en.wikipedia.org/wiki/Triangle) shares a side with two others giving a visual proof that the Padovan sequence also satisfies the recurrence relation

     P ( n ) = P ( n − 1 ) + P ( n − 5 )   {\displaystyle P(n)=P(n-1)+P(n-5)}

Starting from this, the defining recurrence and other recurrences as they are discovered, one can create an infinite number of further recurrences by repeatedly replacing     P ( m )   {\displaystyle P(m)}   by     P ( m − 2 ) + P ( m − 3 )   {\displaystyle P(m-2)+P(m-3)}

The [Perrin sequence](https://en.wikipedia.org/wiki/Perrin_pseudoprime) satisfies the same recurrence relations as the Padovan sequence, although it has different initial values.

The Perrin sequence can be obtained from the Padovan sequence by the following formula:

      P e r r i n  ( n ) = P ( n + 1 ) + P ( n − 10 ) .    {\displaystyle \mathrm {Perrin} (n)=P(n+1)+P(n-10).\,}

## Extension to negative parameters

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=2)]

As with any sequence defined by a recurrence relation, Padovan numbers *P*(*m*) for *m*<0 can be defined by rewriting the recurrence relation as

     P ( m ) = P ( m + 3 ) − P ( m + 1 ) ,   {\displaystyle P(m)=P(m+3)-P(m+1),}

Starting with *m* = −1 and working backwards, we extend *P*(*m*) to negative indices:

## Sums of terms

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=3)]

The sum of the first *n* terms in the Padovan sequence is 2 less than *P*(*n* + 5), i.e.

      ∑  m = 0   n   P ( m ) = P ( n + 5 ) − 2.   {\displaystyle \sum _{m=0}^{n}P(m)=P(n+5)-2.}

Sums of alternate terms, sums of every third term and sums of every fifth term are also related to other terms in the sequence:

      ∑  m = 0   n   P ( 2 m ) = P ( 2 n + 3 ) − 1   {\displaystyle \sum _{m=0}^{n}P(2m)=P(2n+3)-1}   [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A077855](https://oeis.org/A077855)      ∑  m = 0   n   P ( 2 m + 1 ) = P ( 2 n + 4 ) − 1   {\displaystyle \sum _{m=0}^{n}P(2m+1)=P(2n+4)-1}        ∑  m = 0   n   P ( 3 m ) = P ( 3 n + 2 )   {\displaystyle \sum _{m=0}^{n}P(3m)=P(3n+2)}   [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A034943](https://oeis.org/A034943)      ∑  m = 0   n   P ( 3 m + 1 ) = P ( 3 n + 3 ) − 1   {\displaystyle \sum _{m=0}^{n}P(3m+1)=P(3n+3)-1}        ∑  m = 0   n   P ( 3 m + 2 ) = P ( 3 n + 4 ) − 1   {\displaystyle \sum _{m=0}^{n}P(3m+2)=P(3n+4)-1}        ∑  m = 0   n   P ( 5 m ) = P ( 5 n + 1 ) .   {\displaystyle \sum _{m=0}^{n}P(5m)=P(5n+1).}   [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A012772](https://oeis.org/A012772)

Sums involving products of terms in the Padovan sequence satisfy the following identities:

      ∑  m = 0   n   P ( m  )  2   = P ( n + 2  )  2   − P ( n − 1  )  2   − P ( n − 3  )  2     {\displaystyle \sum _{m=0}^{n}P(m)^{2}=P(n+2)^{2}-P(n-1)^{2}-P(n-3)^{2}}        ∑  m = 0   n   P ( m  )  2   P ( m + 1 ) = P ( n ) P ( n + 1 ) P ( n + 2 )   {\displaystyle \sum _{m=0}^{n}P(m)^{2}P(m+1)=P(n)P(n+1)P(n+2)}        ∑  m = 0   n   P ( m ) P ( m + 2 ) = P ( n + 2 ) P ( n + 3 ) − 1.   {\displaystyle \sum _{m=0}^{n}P(m)P(m+2)=P(n+2)P(n+3)-1.}

## Other identities

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=4)]

The Padovan sequence also satisfies the identity

     P ( n  )  2   − P ( n + 1 ) P ( n − 1 ) = P ( − n − 7 ) .    {\displaystyle P(n)^{2}-P(n+1)P(n-1)=P(-n-7).\,}

The Padovan sequence is related to sums of [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficient) by the following identity:

     P ( k − 2 ) =  ∑  2 m + n = k      (   m n   )    =  ∑  m = ⌈ k  /  3 ⌉   ⌊ k  /  2 ⌋      (   m  k − 2 m    )    .   {\displaystyle P(k-2)=\sum _{2m+n=k}{m \choose n}=\sum _{m=\lceil k/3\rceil }^{\lfloor k/2\rfloor }{m \choose k-2m}.}

For example, for *k* = 12, the values for the pair (*m*, *n*) with 2*m* + *n* = 12 which give non-zero binomial coefficients are (6, 0), (5, 2) and (4, 4), and:

        (   6 0   )    +    (   5 2   )    +    (   4 4   )    = 1 + 10 + 1 = 12 = P ( 10 ) .    {\displaystyle {6 \choose 0}+{5 \choose 2}+{4 \choose 4}=1+10+1=12=P(10).\,}

## Binet-like formula

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=5)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/1/19/Triangles_in_ratio_of_the_plastic_number_in_a_three_armed_counter_clockwise_spiral.svg/250px-Triangles_in_ratio_of_the_plastic_number_in_a_three_armed_counter_clockwise_spiral.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Triangles_in_ratio_of_the_plastic_number_in_a_three_armed_counter_clockwise_spiral.svg)Triangles with sides in ratio of 1/*ρ* form a closed spiral

The Padovan sequence numbers can be written in terms of powers of the [roots](https://en.wikipedia.org/wiki/Root_of_a_polynomial) of the equation[[1]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-ps-1)

      x  3   − x − 1 = 0.    {\displaystyle x^{3}-x-1=0.\,}

This equation has 3 roots; one [real](https://en.wikipedia.org/wiki/Real_number) root *p* (known as the [plastic ratio](https://en.wikipedia.org/wiki/Plastic_ratio)) and two [complex conjugate](https://en.wikipedia.org/wiki/Complex_conjugate) roots *q* and *r*.[[5]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-5) Given these three roots, the Padovan sequence can be expressed by a formula involving *p*, *q* and *r* :

     P ( n ) = a  p  n   + b  q  n   + c  r  n     {\displaystyle P(n)=ap^{n}+bq^{n}+cr^{n}}

where *a*, *b* and *c* are constants.[[1]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-ps-1)

Since the [absolute values](https://en.wikipedia.org/wiki/Absolute_value) of the [complex](https://en.wikipedia.org/wiki/Complex_number) roots *q* and *r* are both less than 1 (and hence *p* is a [Pisot–Vijayaraghavan number](https://en.wikipedia.org/wiki/Pisot%E2%80%93Vijayaraghavan_number)), the powers of these roots [approach](https://en.wikipedia.org/wiki/Limit_of_a_sequence) 0 for large *n*, and     P ( n ) − a  p  n     {\displaystyle P(n)-ap^{n}}   tends to zero.

For all     n ≥ 0   {\displaystyle n\geq 0}  , *P*(*n*) is the [integer closest](https://en.wikipedia.org/wiki/Nearest_integer) to        p  5    2 p + 3     p  n     {\displaystyle {\frac {p^{5}}{2p+3}}p^{n}}  . Indeed,        p  5    2 p + 3      {\displaystyle {\frac {p^{5}}{2p+3}}}   is the value of constant *a* above, while *b* and *c* are obtained by replacing *p* with *q* and *r*, respectively.

The ratio of successive terms in the Padovan sequence approaches *p*, which has a value of approximately 1.324718. This constant bears the same relationship to the Padovan sequence and the [Perrin sequence](https://en.wikipedia.org/wiki/Perrin_sequence) as the [golden ratio](https://en.wikipedia.org/wiki/Golden_ratio) does to the [Fibonacci sequence](https://en.wikipedia.org/wiki/Fibonacci_sequence).

## Combinatorial interpretations

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=6)]
- *P*(*n*) is the number of ways of writing *n* + 2 as an ordered sum in which each term is either 2 or 3 (i.e. the number of [compositions](https://en.wikipedia.org/wiki/Composition_(number_theory)) of *n* + 2 in which each term is either 2 or 3). For example, *P*(6) = 4, and there are 4 ways to write 8 as an ordered sum of 2s and 3s:
 2 + 2 + 2 + 2  ; 2 + 3 + 3  ; 3 + 2 + 3  ; 3 + 3 + 2
- The number of ways of writing *n* as an ordered sum in which no term is 2 is *P*(2*n* − 2). For example, *P*(6) = 4, and there are 4 ways to write 4 as an ordered sum in which no term is 2:
 4  ; 1 + 3  ; 3 + 1  ; 1 + 1 + 1 + 1
- The number of ways of writing *n* as a palindromic ordered sum in which no term is 2 is *P*(*n*). For example, *P*(6) = 4, and there are 4 ways to write 6 as a palindromic ordered sum in which no term is 2:
 6  ; 3 + 3  ; 1 + 4 + 1  ; 1 + 1 + 1 + 1 + 1 + 1
- The number of ways of writing *n* as an ordered sum in which each term is [odd](https://en.wikipedia.org/wiki/Parity_(mathematics)) and greater than 1 is equal to *P*(*n* − 5). For example, *P*(6) = 4, and there are 4 ways to write 11 as an ordered sum in which each term is odd and greater than 1:
 11 ; 5 + 3 + 3 ; 3 + 5 + 3 ; 3 + 3 + 5
- The number of ways of writing *n* as an ordered sum in which each term is [congruent](https://en.wikipedia.org/wiki/Modular_arithmetic) to 2 mod 3 is equal to *P*(*n* − 4). For example, *P*(6) = 4, and there are 4 ways to write 10 as an ordered sum in which each term is congruent to 2 mod 3:
 8 + 2  ; 2 + 8  ; 5 + 5  ; 2 + 2 + 2 + 2 + 2

## Generating function

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=7)]

The [generating function](https://en.wikipedia.org/wiki/Generating_function) of the Padovan sequence is

     G ( P ( n ) ; x ) =    1 + x   1 −  x  2   −  x  3      .   {\displaystyle G(P(n);x)={\frac {1+x}{1-x^{2}-x^{3}}}.}

This can be used to prove identities involving products of the Padovan sequence with [geometric terms](https://en.wikipedia.org/wiki/Geometric_series), such as:

      ∑  n = 0   ∞      P ( n )   2  n     =   12 5   .   {\displaystyle \sum _{n=0}^{\infty }{\frac {P(n)}{2^{n}}}={\frac {12}{5}}.}        ∑  n = 0   ∞      P ( n )   α  n     =     α  2   ( α + 1 )    α  3   − α − 1    .   {\displaystyle \sum _{n=0}^{\infty }{\frac {P(n)}{\alpha ^{n}}}={\frac {\alpha ^{2}(\alpha +1)}{\alpha ^{3}-\alpha -1}}.}

## Generalizations

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=8)]

In a similar way to the [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number) that can be generalized to a set of [polynomials](https://en.wikipedia.org/wiki/Polynomial) called the [Fibonacci polynomials](https://en.wikipedia.org/wiki/Fibonacci_polynomials), the Padovan sequence numbers can be generalized to yield the [Padovan polynomials](https://en.wikipedia.org/wiki/Padovan_polynomials).

## Padovan L-system

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=9)]

If we define the following simple grammar:

 **variables** : A B C **constants** : none **start**  : A **rules**  : (A → B), (B → C), (C → AB)

then this Lindenmayer system or [L-system](https://en.wikipedia.org/wiki/L-system) produces the following sequence of strings:

 *n* = 0 : A *n* = 1 : B *n* = 2 : C *n* = 3 : AB *n* = 4 : BC *n* = 5 : CAB *n* = 6 : ABBC *n* = 7 : BCCAB *n* = 8 : CABABBC

and if we count the length of each string, we obtain the Padovan numbers:

 1, 1, 1, 2, 2, 3, 4, 5, ...

Also, if you count the number of *A*s, *B*s and *C*s in each string, then for the *n*th string, you have *P*(*n* − 5) *A*s, *P*(*n* − 3) *B*s and *P*(*n* − 4) *C*s. The count of *BB* pairs and *CC* pairs are also Padovan numbers.

## Cuboid spiral

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=10)] Main article: [Padovan cuboid spiral](https://en.wikipedia.org/wiki/Padovan_cuboid_spiral)

A spiral can be formed based on connecting the corners of a set of 3-dimensional [cuboids](https://en.wikipedia.org/wiki/Cuboid). This is the [Padovan cuboid spiral](https://en.wikipedia.org/wiki/Padovan_cuboid_spiral). Successive sides of this spiral have lengths that are the Padovan numbers multiplied by the [square root of 2](https://en.wikipedia.org/wiki/Square_root_of_2).

In [number theory](https://en.wikipedia.org/wiki/Number_theory), the **Padovan sequence** is the [sequence of integers](https://en.wikipedia.org/wiki/Integer_sequence) *P*(*n*) defined[[1]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-ps-1) by the initial values:

P ( 0 ) = P ( 1 ) = P ( 2 ) = 1 ,   {\displaystyle P(0)=P(1)=P(2)=1,}

and the [recurrence relation](https://en.wikipedia.org/wiki/Recurrence_relation)

P ( n ) = P ( n − 2 ) + P ( n − 3 ) .   {\displaystyle P(n)=P(n-2)+P(n-3).}

The first few values of *P*(*n*) are

 1, 1, 1, 2, 2, 3, 4, 5, 7, 9, 12, 16, 21, 28, 37, 49, 65, 86, 114, 151, 200, 265, ... (sequence [A000931](https://oeis.org/A000931) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)) [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/4/4d/Padovan_triangles_%281%29.svg/500px-Padovan_triangles_%281%29.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Padovan_triangles_(1).svg)Spiral of [equilateral triangles](https://en.wikipedia.org/wiki/Equilateral_triangle) with side lengths which follow the Padovan sequence.

The Padovan sequence is named after [Richard Padovan](https://en.wikipedia.org/wiki/Richard_Padovan) who attributed its discovery to [Dutch](https://en.wikipedia.org/wiki/Netherlands) architect [Hans van der Laan](https://en.wikipedia.org/wiki/Hans_van_der_Laan) in his 1994 essay *Dom. Hans van der Laan: Modern Primitive*.[[2]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-dhdl-2) The [sequence](https://en.wikipedia.org/wiki/Sequence) was described by [Ian Stewart](https://en.wikipedia.org/wiki/Ian_Stewart_(mathematician)) in his [Scientific American](https://en.wikipedia.org/wiki/Scientific_American) column *Mathematical Recreations* in June 1996.[[3]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-3) He also writes about it in one of his books, "Math Hysteria: Fun Games With Mathematics". Recurrence relations

# Recurrence relations

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=1)]

In the spiral, each [triangle](https://en.wikipedia.org/wiki/Triangle) shares a side with two others giving a visual proof that the Padovan sequence also satisfies the recurrence relation

     P ( n ) = P ( n − 1 ) + P ( n − 5 )   {\displaystyle P(n)=P(n-1)+P(n-5)}

Starting from this, the defining recurrence and other recurrences as they are discovered, one can create an infinite number of further recurrences by repeatedly replacing     P ( m )   {\displaystyle P(m)}   by     P ( m − 2 ) + P ( m − 3 )   {\displaystyle P(m-2)+P(m-3)}

The [Perrin sequence](https://en.wikipedia.org/wiki/Perrin_pseudoprime) satisfies the same recurrence relations as the Padovan sequence, although it has different initial values.

The Perrin sequence can be obtained from the Padovan sequence by the following formula:

      P e r r i n  ( n ) = P ( n + 1 ) + P ( n − 10 ) .    {\displaystyle \mathrm {Perrin} (n)=P(n+1)+P(n-10).\,}

Sums of terms

# Sums of terms

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=3)]

The sum of the first *n* terms in the Padovan sequence is 2 less than *P*(*n* + 5), i.e.

      ∑  m = 0   n   P ( m ) = P ( n + 5 ) − 2.   {\displaystyle \sum _{m=0}^{n}P(m)=P(n+5)-2.}

Sums of alternate terms, sums of every third term and sums of every fifth term are also related to other terms in the sequence:

      ∑  m = 0   n   P ( 2 m ) = P ( 2 n + 3 ) − 1   {\displaystyle \sum _{m=0}^{n}P(2m)=P(2n+3)-1}   [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A077855](https://oeis.org/A077855)      ∑  m = 0   n   P ( 2 m + 1 ) = P ( 2 n + 4 ) − 1   {\displaystyle \sum _{m=0}^{n}P(2m+1)=P(2n+4)-1}        ∑  m = 0   n   P ( 3 m ) = P ( 3 n + 2 )   {\displaystyle \sum _{m=0}^{n}P(3m)=P(3n+2)}   [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A034943](https://oeis.org/A034943)      ∑  m = 0   n   P ( 3 m + 1 ) = P ( 3 n + 3 ) − 1   {\displaystyle \sum _{m=0}^{n}P(3m+1)=P(3n+3)-1}        ∑  m = 0   n   P ( 3 m + 2 ) = P ( 3 n + 4 ) − 1   {\displaystyle \sum _{m=0}^{n}P(3m+2)=P(3n+4)-1}        ∑  m = 0   n   P ( 5 m ) = P ( 5 n + 1 ) .   {\displaystyle \sum _{m=0}^{n}P(5m)=P(5n+1).}   [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A012772](https://oeis.org/A012772)

Sums involving products of terms in the Padovan sequence satisfy the following identities:

      ∑  m = 0   n   P ( m  )  2   = P ( n + 2  )  2   − P ( n − 1  )  2   − P ( n − 3  )  2     {\displaystyle \sum _{m=0}^{n}P(m)^{2}=P(n+2)^{2}-P(n-1)^{2}-P(n-3)^{2}}        ∑  m = 0   n   P ( m  )  2   P ( m + 1 ) = P ( n ) P ( n + 1 ) P ( n + 2 )   {\displaystyle \sum _{m=0}^{n}P(m)^{2}P(m+1)=P(n)P(n+1)P(n+2)}        ∑  m = 0   n   P ( m ) P ( m + 2 ) = P ( n + 2 ) P ( n + 3 ) − 1.   {\displaystyle \sum _{m=0}^{n}P(m)P(m+2)=P(n+2)P(n+3)-1.}

Other identities

# Other identities

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=4)]

The Padovan sequence also satisfies the identity

     P ( n  )  2   − P ( n + 1 ) P ( n − 1 ) = P ( − n − 7 ) .    {\displaystyle P(n)^{2}-P(n+1)P(n-1)=P(-n-7).\,}

The Padovan sequence is related to sums of [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficient) by the following identity:

     P ( k − 2 ) =  ∑  2 m + n = k      (   m n   )    =  ∑  m = ⌈ k  /  3 ⌉   ⌊ k  /  2 ⌋      (   m  k − 2 m    )    .   {\displaystyle P(k-2)=\sum _{2m+n=k}{m \choose n}=\sum _{m=\lceil k/3\rceil }^{\lfloor k/2\rfloor }{m \choose k-2m}.}

For example, for *k* = 12, the values for the pair (*m*, *n*) with 2*m* + *n* = 12 which give non-zero binomial coefficients are (6, 0), (5, 2) and (4, 4), and:

        (   6 0   )    +    (   5 2   )    +    (   4 4   )    = 1 + 10 + 1 = 12 = P ( 10 ) .    {\displaystyle {6 \choose 0}+{5 \choose 2}+{4 \choose 4}=1+10+1=12=P(10).\,}

Binet-like formula

# Binet-like formula

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=5)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/1/19/Triangles_in_ratio_of_the_plastic_number_in_a_three_armed_counter_clockwise_spiral.svg/250px-Triangles_in_ratio_of_the_plastic_number_in_a_three_armed_counter_clockwise_spiral.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Triangles_in_ratio_of_the_plastic_number_in_a_three_armed_counter_clockwise_spiral.svg)Triangles with sides in ratio of 1/*ρ* form a closed spiral

The Padovan sequence numbers can be written in terms of powers of the [roots](https://en.wikipedia.org/wiki/Root_of_a_polynomial) of the equation[[1]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-ps-1)

      x  3   − x − 1 = 0.    {\displaystyle x^{3}-x-1=0.\,}

This equation has 3 roots; one [real](https://en.wikipedia.org/wiki/Real_number) root *p* (known as the [plastic ratio](https://en.wikipedia.org/wiki/Plastic_ratio)) and two [complex conjugate](https://en.wikipedia.org/wiki/Complex_conjugate) roots *q* and *r*.[[5]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-5) Given these three roots, the Padovan sequence can be expressed by a formula involving *p*, *q* and *r* :

     P ( n ) = a  p  n   + b  q  n   + c  r  n     {\displaystyle P(n)=ap^{n}+bq^{n}+cr^{n}}

where *a*, *b* and *c* are constants.[[1]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-ps-1)

Since the [absolute values](https://en.wikipedia.org/wiki/Absolute_value) of the [complex](https://en.wikipedia.org/wiki/Complex_number) roots *q* and *r* are both less than 1 (and hence *p* is a [Pisot–Vijayaraghavan number](https://en.wikipedia.org/wiki/Pisot%E2%80%93Vijayaraghavan_number)), the powers of these roots [approach](https://en.wikipedia.org/wiki/Limit_of_a_sequence) 0 for large *n*, and     P ( n ) − a  p  n     {\displaystyle P(n)-ap^{n}}   tends to zero.

For all     n ≥ 0   {\displaystyle n\geq 0}  , *P*(*n*) is the [integer closest](https://en.wikipedia.org/wiki/Nearest_integer) to        p  5    2 p + 3     p  n     {\displaystyle {\frac {p^{5}}{2p+3}}p^{n}}  . Indeed,        p  5    2 p + 3      {\displaystyle {\frac {p^{5}}{2p+3}}}   is the value of constant *a* above, while *b* and *c* are obtained by replacing *p* with *q* and *r*, respectively.

The ratio of successive terms in the Padovan sequence approaches *p*, which has a value of approximately 1.324718. This constant bears the same relationship to the Padovan sequence and the [Perrin sequence](https://en.wikipedia.org/wiki/Perrin_sequence) as the [golden ratio](https://en.wikipedia.org/wiki/Golden_ratio) does to the [Fibonacci sequence](https://en.wikipedia.org/wiki/Fibonacci_sequence).

Combinatorial interpretations

# Combinatorial interpretations

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=6)]
- *P*(*n*) is the number of ways of writing *n* + 2 as an ordered sum in which each term is either 2 or 3 (i.e. the number of [compositions](https://en.wikipedia.org/wiki/Composition_(number_theory)) of *n* + 2 in which each term is either 2 or 3). For example, *P*(6) = 4, and there are 4 ways to write 8 as an ordered sum of 2s and 3s:
 2 + 2 + 2 + 2  ; 2 + 3 + 3  ; 3 + 2 + 3  ; 3 + 3 + 2
- The number of ways of writing *n* as an ordered sum in which no term is 2 is *P*(2*n* − 2). For example, *P*(6) = 4, and there are 4 ways to write 4 as an ordered sum in which no term is 2:
 4  ; 1 + 3  ; 3 + 1  ; 1 + 1 + 1 + 1
- The number of ways of writing *n* as a palindromic ordered sum in which no term is 2 is *P*(*n*). For example, *P*(6) = 4, and there are 4 ways to write 6 as a palindromic ordered sum in which no term is 2:
 6  ; 3 + 3  ; 1 + 4 + 1  ; 1 + 1 + 1 + 1 + 1 + 1
- The number of ways of writing *n* as an ordered sum in which each term is [odd](https://en.wikipedia.org/wiki/Parity_(mathematics)) and greater than 1 is equal to *P*(*n* − 5). For example, *P*(6) = 4, and there are 4 ways to write 11 as an ordered sum in which each term is odd and greater than 1:
 11 ; 5 + 3 + 3 ; 3 + 5 + 3 ; 3 + 3 + 5
- The number of ways of writing *n* as an ordered sum in which each term is [congruent](https://en.wikipedia.org/wiki/Modular_arithmetic) to 2 mod 3 is equal to *P*(*n* − 4). For example, *P*(6) = 4, and there are 4 ways to write 10 as an ordered sum in which each term is congruent to 2 mod 3:
 8 + 2  ; 2 + 8  ; 5 + 5  ; 2 + 2 + 2 + 2 + 2

Generating function

# Generating function

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=7)]

The [generating function](https://en.wikipedia.org/wiki/Generating_function) of the Padovan sequence is

     G ( P ( n ) ; x ) =    1 + x   1 −  x  2   −  x  3      .   {\displaystyle G(P(n);x)={\frac {1+x}{1-x^{2}-x^{3}}}.}

This can be used to prove identities involving products of the Padovan sequence with [geometric terms](https://en.wikipedia.org/wiki/Geometric_series), such as:

      ∑  n = 0   ∞      P ( n )   2  n     =   12 5   .   {\displaystyle \sum _{n=0}^{\infty }{\frac {P(n)}{2^{n}}}={\frac {12}{5}}.}        ∑  n = 0   ∞      P ( n )   α  n     =     α  2   ( α + 1 )    α  3   − α − 1    .   {\displaystyle \sum _{n=0}^{\infty }{\frac {P(n)}{\alpha ^{n}}}={\frac {\alpha ^{2}(\alpha +1)}{\alpha ^{3}-\alpha -1}}.}

Generalizations

# Generalizations

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=8)]

In a similar way to the [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number) that can be generalized to a set of [polynomials](https://en.wikipedia.org/wiki/Polynomial) called the [Fibonacci polynomials](https://en.wikipedia.org/wiki/Fibonacci_polynomials), the Padovan sequence numbers can be generalized to yield the [Padovan polynomials](https://en.wikipedia.org/wiki/Padovan_polynomials).

Padovan L-system

# Padovan L-system

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=9)]

If we define the following simple grammar:

 **variables** : A B C **constants** : none **start**  : A **rules**  : (A → B), (B → C), (C → AB)

then this Lindenmayer system or [L-system](https://en.wikipedia.org/wiki/L-system) produces the following sequence of strings:

 *n* = 0 : A *n* = 1 : B *n* = 2 : C *n* = 3 : AB *n* = 4 : BC *n* = 5 : CAB *n* = 6 : ABBC *n* = 7 : BCCAB *n* = 8 : CABABBC

and if we count the length of each string, we obtain the Padovan numbers:

 1, 1, 1, 2, 2, 3, 4, 5, ...

Also, if you count the number of *A*s, *B*s and *C*s in each string, then for the *n*th string, you have *P*(*n* − 5) *A*s, *P*(*n* − 3) *B*s and *P*(*n* − 4) *C*s. The count of *BB* pairs and *CC* pairs are also Padovan numbers.

Cuboid spiral

# Cuboid spiral

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=10)] Main article: [Padovan cuboid spiral](https://en.wikipedia.org/wiki/Padovan_cuboid_spiral)

A spiral can be formed based on connecting the corners of a set of 3-dimensional [cuboids](https://en.wikipedia.org/wiki/Cuboid). This is the [Padovan cuboid spiral](https://en.wikipedia.org/wiki/Padovan_cuboid_spiral). Successive sides of this spiral have lengths that are the Padovan numbers multiplied by the [square root of 2](https://en.wikipedia.org/wiki/Square_root_of_2).

Pascal's triangle

# Pascal's triangle

[[edit](https://en.wikipedia.org/w/index.php?title=Padovan_sequence&action=edit&section=11)]

[Erv Wilson](https://en.wikipedia.org/wiki/Erv_Wilson) in his paper *The Scales of Mt. Meru*[[6]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-6) observed certain diagonals in [Pascal's triangle](https://en.wikipedia.org/wiki/Pascal's_triangle) (see diagram) and drew them on paper in 1993. The Padovan numbers were discovered in 1994. Paul Barry (2004) observed that these diagonals generate the Padovan sequence by summing the diagonal numbers.[[7]](https://en.wikipedia.org/wiki/Padovan_sequence#cite_note-7)

# Geometric analogies
