In [mathematics](https://en.wikipedia.org/wiki/Mathematics) and computing, **Fibonacci coding** is a [universal code](https://en.wikipedia.org/wiki/Universal_code_(data_compression))[[1]](https://en.wikipedia.org/wiki/Fibonacci_coding#cite_note-1) which encodes positive integers into binary code words. It is one example of representations of integers based on [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number). Each code word ends with "11" and contains no other instances of "11" before the end.

The Fibonacci code is closely related to the [Zeckendorf representation](https://en.wikipedia.org/wiki/Zeckendorf_representation), a positional [numeral system](https://en.wikipedia.org/wiki/Numeral_system) that uses [Zeckendorf's theorem](https://en.wikipedia.org/wiki/Zeckendorf's_theorem) and has the property that no number has a representation with consecutive 1s. The Fibonacci code word for a particular integer is exactly the integer's Zeckendorf representation with the order of its digits reversed and an additional "1" appended to the end.

## Definition

[[edit](https://en.wikipedia.org/w/index.php?title=Fibonacci_coding&action=edit&section=1)]

For a number     N    {\displaystyle N\!}  , if     d ( 0 ) , d ( 1 ) , … , d ( k − 1 ) , d ( k )    {\displaystyle d(0),d(1),\ldots ,d(k-1),d(k)\!}   represent the digits of the code word representing     N    {\displaystyle N\!}   then we have:

     N =  ∑  i = 0   k − 1   d ( i ) F ( i + 2 ) ,   and   d ( k − 1 ) = d ( k ) = 1.    {\displaystyle N=\sum _{i=0}^{k-1}d(i)F(i+2),{\text{ and }}d(k-1)=d(k)=1.\!}

where *F*(*i*) is the *i*th [Fibonacci number](https://en.wikipedia.org/wiki/Fibonacci_number), and so *F*(*i*+2) is the *i*th distinct Fibonacci number starting with     1 , 2 , 3 , 5 , 8 , 13 , …   {\displaystyle 1,2,3,5,8,13,\ldots }  . The last bit     d ( k )   {\displaystyle d(k)}   is always an appended bit of 1 and does not carry place value.

It can be shown that such a coding is unique, and the only occurrence of "11" in any code word is at the end (that is, *d*(*k*−1) and *d*(*k*)). The penultimate bit is the most significant bit and the first bit is the least significant bit. Also, leading zeros cannot be omitted as they can be in, for example, decimal numbers.

To encode an integer N:

1. Find the largest [Fibonacci number](https://en.wikipedia.org/wiki/Fibonacci_number) equal to or less than *N*; subtract this number from *N*, keeping track of the remainder.
2. If the number subtracted was the ith Fibonacci number *F*(*i*), put a 1 in place *i* − 2 in the code word (counting the rightmost bit as place 0).
3. Repeat the previous steps, substituting the remainder for *N*, until a remainder of 0 is reached.
4. Place an additional 1 after the rightmost digit in the code word.

To decode a code word, remove the final "1", assign the remaining the values 1,2,3,5,8,13... (the [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number)) to the bits in the code word, and sum the values of the "1" bits.

## Comparison with other universal codes

[[edit](https://en.wikipedia.org/w/index.php?title=Fibonacci_coding&action=edit&section=2)]

Fibonacci coding has a useful property that sometimes makes it attractive in comparison to other universal codes: it is an example of a [self-synchronizing code](https://en.wikipedia.org/wiki/Self-synchronizing_code), making it easier to recover data from a damaged stream. With most other universal codes, if a single [bit](https://en.wikipedia.org/wiki/Bit) is altered, then none of the data that comes after it will be correctly read. With Fibonacci coding, on the other hand, a changed bit may cause one token to be read as two, or cause two tokens to be read incorrectly as one, but reading a "0" from the stream will stop the errors from propagating further. Since the only stream that has no "0" in it is a stream of "11" tokens, the total [edit distance](https://en.wikipedia.org/wiki/Edit_distance) between a stream damaged by a single bit error and the original stream is at most three.

This approach, encoding using sequence of symbols, in which some patterns (like "11") are forbidden, can be freely generalized.[[2]](https://en.wikipedia.org/wiki/Fibonacci_coding#cite_note-2)

## Generalizations

[[edit](https://en.wikipedia.org/w/index.php?title=Fibonacci_coding&action=edit&section=4)]

The Fibonacci encodings for the positive integers are binary strings that end with "11" and contain no other instances of "11". This can be generalized to binary strings that end with *N* consecutive 1s and contain no other instances of *N* consecutive 1s. For instance, for *N* = 3 the positive integers are encoded as 111, 0111, 00111, 10111, 000111, 100111, 010111, 110111, 0000111, 1000111, 0100111, …. In this case, the number of encodings as a function of string length is given by the sequence of [tribonacci numbers](https://en.wikipedia.org/wiki/Tribonacci_number).

For general constraints defining which symbols are allowed after a given symbol, the maximal information rate can be obtained by first finding the optimal transition probabilities using a [maximal entropy random walk](https://en.wikipedia.org/wiki/Maximal_entropy_random_walk), then using an [entropy coder](https://en.wikipedia.org/wiki/Entropy_coder) (with switched encoder and decoder) to encode a message as a sequence of symbols fulfilling the found optimal transition probabilities.

In [mathematics](https://en.wikipedia.org/wiki/Mathematics) and computing, **Fibonacci coding** is a [universal code](https://en.wikipedia.org/wiki/Universal_code_(data_compression))[[1]](https://en.wikipedia.org/wiki/Fibonacci_coding#cite_note-1) which encodes positive integers into binary code words. It is one example of representations of integers based on [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number). Each code word ends with "11" and contains no other instances of "11" before the end.

The Fibonacci code is closely related to the [Zeckendorf representation](https://en.wikipedia.org/wiki/Zeckendorf_representation), a positional [numeral system](https://en.wikipedia.org/wiki/Numeral_system) that uses [Zeckendorf's theorem](https://en.wikipedia.org/wiki/Zeckendorf's_theorem) and has the property that no number has a representation with consecutive 1s. The Fibonacci code word for a particular integer is exactly the integer's Zeckendorf representation with the order of its digits reversed and an additional "1" appended to the end.

Definition

# Definition

[[edit](https://en.wikipedia.org/w/index.php?title=Fibonacci_coding&action=edit&section=1)]

For a number     N    {\displaystyle N\!}  , if     d ( 0 ) , d ( 1 ) , … , d ( k − 1 ) , d ( k )    {\displaystyle d(0),d(1),\ldots ,d(k-1),d(k)\!}   represent the digits of the code word representing     N    {\displaystyle N\!}   then we have:

     N =  ∑  i = 0   k − 1   d ( i ) F ( i + 2 ) ,   and   d ( k − 1 ) = d ( k ) = 1.    {\displaystyle N=\sum _{i=0}^{k-1}d(i)F(i+2),{\text{ and }}d(k-1)=d(k)=1.\!}

where *F*(*i*) is the *i*th [Fibonacci number](https://en.wikipedia.org/wiki/Fibonacci_number), and so *F*(*i*+2) is the *i*th distinct Fibonacci number starting with     1 , 2 , 3 , 5 , 8 , 13 , …   {\displaystyle 1,2,3,5,8,13,\ldots }  . The last bit     d ( k )   {\displaystyle d(k)}   is always an appended bit of 1 and does not carry place value.

It can be shown that such a coding is unique, and the only occurrence of "11" in any code word is at the end (that is, *d*(*k*−1) and *d*(*k*)). The penultimate bit is the most significant bit and the first bit is the least significant bit. Also, leading zeros cannot be omitted as they can be in, for example, decimal numbers.

To encode an integer N:

1. Find the largest [Fibonacci number](https://en.wikipedia.org/wiki/Fibonacci_number) equal to or less than *N*; subtract this number from *N*, keeping track of the remainder.
2. If the number subtracted was the ith Fibonacci number *F*(*i*), put a 1 in place *i* − 2 in the code word (counting the rightmost bit as place 0).
3. Repeat the previous steps, substituting the remainder for *N*, until a remainder of 0 is reached.
4. Place an additional 1 after the rightmost digit in the code word.

To decode a code word, remove the final "1", assign the remaining the values 1,2,3,5,8,13... (the [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number)) to the bits in the code word, and sum the values of the "1" bits.

Comparison with other universal codes

# Comparison with other universal codes

[[edit](https://en.wikipedia.org/w/index.php?title=Fibonacci_coding&action=edit&section=2)]

Fibonacci coding has a useful property that sometimes makes it attractive in comparison to other universal codes: it is an example of a [self-synchronizing code](https://en.wikipedia.org/wiki/Self-synchronizing_code), making it easier to recover data from a damaged stream. With most other universal codes, if a single [bit](https://en.wikipedia.org/wiki/Bit) is altered, then none of the data that comes after it will be correctly read. With Fibonacci coding, on the other hand, a changed bit may cause one token to be read as two, or cause two tokens to be read incorrectly as one, but reading a "0" from the stream will stop the errors from propagating further. Since the only stream that has no "0" in it is a stream of "11" tokens, the total [edit distance](https://en.wikipedia.org/wiki/Edit_distance) between a stream damaged by a single bit error and the original stream is at most three.

This approach, encoding using sequence of symbols, in which some patterns (like "11") are forbidden, can be freely generalized.[[2]](https://en.wikipedia.org/wiki/Fibonacci_coding#cite_note-2)

Generalizations

# Generalizations

[[edit](https://en.wikipedia.org/w/index.php?title=Fibonacci_coding&action=edit&section=4)]

The Fibonacci encodings for the positive integers are binary strings that end with "11" and contain no other instances of "11". This can be generalized to binary strings that end with *N* consecutive 1s and contain no other instances of *N* consecutive 1s. For instance, for *N* = 3 the positive integers are encoded as 111, 0111, 00111, 10111, 000111, 100111, 010111, 110111, 0000111, 1000111, 0100111, …. In this case, the number of encodings as a function of string length is given by the sequence of [tribonacci numbers](https://en.wikipedia.org/wiki/Tribonacci_number).

For general constraints defining which symbols are allowed after a given symbol, the maximal information rate can be obtained by first finding the optimal transition probabilities using a [maximal entropy random walk](https://en.wikipedia.org/wiki/Maximal_entropy_random_walk), then using an [entropy coder](https://en.wikipedia.org/wiki/Entropy_coder) (with switched encoder and decoder) to encode a message as a sequence of symbols fulfilling the found optimal transition probabilities.
