The **Calabi triangle** is a special [triangle](https://en.wikipedia.org/wiki/Triangle) found by [Eugenio Calabi](https://en.wikipedia.org/wiki/Eugenio_Calabi).

It is the unique triangle that has 3 different placements for the largest [square](https://en.wikipedia.org/wiki/Square) that it contains, and is not the [equilateral triangle](https://en.wikipedia.org/wiki/Equilateral_triangle).[[1]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-1) It is an [isosceles](https://en.wikipedia.org/wiki/Isosceles) triangle which is [obtuse](https://en.wikipedia.org/wiki/Obtuse_triangle) with an [irrational](https://en.wikipedia.org/wiki/Irrational_number) but [algebraic](https://en.wikipedia.org/wiki/Algebraic_number) ratio between the lengths of its sides and its base.[[2]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-FOOTNOTEStewart200415-2)[[3]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-3)[[4]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-Wolfram-4)

Consider the largest square that can be placed in an arbitrary triangle. It may be that such a square could be positioned in the triangle in more than one way. In the [equilateral triangle](https://en.wikipedia.org/wiki/Equilateral_triangle), the largest such square can be positioned in three different ways. Calabi found that there is exactly one other case, and so it is named the Calabi triangle.

## Shape

[[edit](https://en.wikipedia.org/w/index.php?title=Calabi_triangle&action=edit&section=1)]

The triangle △*ABC* is [isosceles](https://en.wikipedia.org/wiki/Isosceles) which has the same length of sides as *AB* = *AC*. If the ratio of the base to either leg is x, we can set that *AB* = *AC* = 1, *BC* = x. Then we can consider the following three cases:

 case 1) △*ABC* is [acute triangle](https://en.wikipedia.org/wiki/Acute_triangle) The condition is     0 < x <   2     {\displaystyle 0<x<{\sqrt {2}}}  . In this case x = 1 is valid for [equilateral triangle](https://en.wikipedia.org/wiki/Equilateral_triangle). case 2) △*ABC* is [right triangle](https://en.wikipedia.org/wiki/Right_triangle) The condition is     x =   2     {\displaystyle x={\sqrt {2}}}  . In this case no value is valid. case 3) △*ABC* is [obtuse triangle](https://en.wikipedia.org/wiki/Obtuse_triangle) The condition is       2   < x < 2   {\displaystyle {\sqrt {2}}<x<2}  . In this case the Calabi triangle is valid for the largest positive root of     2  x  3   − 2  x  2   − 3 x + 2 = 0   {\displaystyle 2x^{3}-2x^{2}-3x+2=0}   at     x = 1.55138752454832039226...   {\displaystyle x=1.55138752454832039226...}   ((sequence [A046095](https://oeis.org/A046095) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences))). showExample of answer

## Root of Calabi's equation

[[edit](https://en.wikipedia.org/w/index.php?title=Calabi_triangle&action=edit&section=5)]

If x is the largest positive [root](https://en.wikipedia.org/wiki/Zero_of_a_function) of Calabi's equation:

     2  x  3   − 2  x  2   − 3 x + 2 = 0 ,   2   < x < 2   {\displaystyle 2x^{3}-2x^{2}-3x+2=0,{\sqrt {2}}<x<2}

we can calculate the value of x by following methods.

 [Edit links](https://www.wikidata.org/wiki/Special:EntityPage/Q5018300#sitelinks-wikipedia)                          From Wikipedia, the free encyclopedia   Special triangle in geometry [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/f/f5/Calabi_triangle.svg/330px-Calabi_triangle.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Calabi_triangle.svg)A Calabi triangle is a triangle     A B C   {\displaystyle ABC}   with three squares, each of which is described as the green region and blue vertices and edges

The **Calabi triangle** is a special [triangle](https://en.wikipedia.org/wiki/Triangle) found by [Eugenio Calabi](https://en.wikipedia.org/wiki/Eugenio_Calabi).

It is the unique triangle that has 3 different placements for the largest [square](https://en.wikipedia.org/wiki/Square) that it contains, and is not the [equilateral triangle](https://en.wikipedia.org/wiki/Equilateral_triangle).[[1]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-1) It is an [isosceles](https://en.wikipedia.org/wiki/Isosceles) triangle which is [obtuse](https://en.wikipedia.org/wiki/Obtuse_triangle) with an [irrational](https://en.wikipedia.org/wiki/Irrational_number) but [algebraic](https://en.wikipedia.org/wiki/Algebraic_number) ratio between the lengths of its sides and its base.[[2]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-FOOTNOTEStewart200415-2)[[3]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-3)[[4]](https://en.wikipedia.org/wiki/Calabi_triangle#cite_note-Wolfram-4)

Consider the largest square that can be placed in an arbitrary triangle. It may be that such a square could be positioned in the triangle in more than one way. In the [equilateral triangle](https://en.wikipedia.org/wiki/Equilateral_triangle), the largest such square can be positioned in three different ways. Calabi found that there is exactly one other case, and so it is named the Calabi triangle.
