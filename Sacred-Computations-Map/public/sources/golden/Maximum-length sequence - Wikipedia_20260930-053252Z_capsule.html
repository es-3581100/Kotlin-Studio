A **maximum-length sequence** (**MLS**) is a type of [pseudorandom binary sequence](https://en.wikipedia.org/wiki/Pseudorandom_binary_sequence).

They are bit sequences generated using maximal [linear-feedback shift registers](https://en.wikipedia.org/wiki/Linear-feedback_shift_register) and are so called because they are [periodic](https://en.wikipedia.org/wiki/Periodic_function) and reproduce every [binary sequence](https://en.wikipedia.org/wiki/Binary_sequence) (except the zero vector) that can be represented by the shift registers (i.e., for length-*m* registers they produce a sequence of length 2*m* − 1). An MLS is also sometimes called an *n*-**sequence** or an *m*-**sequence**. MLSs are [spectrally flat](https://en.wikipedia.org/wiki/Frequency_spectrum), with the exception of a near-zero DC term.

These sequences may be represented as coefficients of [primitive](https://en.wikipedia.org/wiki/Primitive_polynomial_(field_theory))[[1]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-1) polynomials in a [polynomial ring](https://en.wikipedia.org/wiki/Polynomial_ring) over [Z/2Z](https://en.wikipedia.org/wiki/Congruence_subgroup).

Practical applications for MLS include measuring [impulse responses](https://en.wikipedia.org/wiki/Impulse_response) (e.g., of room [reverberation](https://en.wikipedia.org/wiki/Reverberation) or arrival times from towed sources in the ocean[[2]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-2)). They are also used as a basis for deriving pseudo-random sequences in digital communication systems that employ [direct-sequence spread spectrum](https://en.wikipedia.org/wiki/Direct-sequence_spread_spectrum) and [frequency-hopping spread spectrum](https://en.wikipedia.org/wiki/Frequency-hopping_spread_spectrum) [transmission systems](https://en.wikipedia.org/wiki/Transmission_system), and in the efficient design of some [fMRI](https://en.wikipedia.org/wiki/Functional_magnetic_resonance_imaging) experiments.[[3]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-buracas-3)

## Generation

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=1)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/0/01/MLS_shiftregisters_L4.png/500px-MLS_shiftregisters_L4.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:MLS_shiftregisters_L4.png)Figure 1: The next value of register *a*3 in a feedback shift register of length 4 is determined by the modulo-2 sum of *a*0 and *a*1.

MLS are generated using maximal [linear-feedback shift registers](https://en.wikipedia.org/wiki/Linear-feedback_shift_register). An MLS-generating system with a shift register of length 4 is shown in Fig. 1. It can be expressed using the following recursive relation:

       {     a  3   [ n + 1 ] =  a  0   [ n ] +  a  1   [ n ]      a  2   [ n + 1 ] =  a  3   [ n ]      a  1   [ n + 1 ] =  a  2   [ n ]      a  0   [ n + 1 ] =  a  1   [ n ]         {\displaystyle {\begin{cases}a_{3}[n+1]=a_{0}[n]+a_{1}[n]\\a_{2}[n+1]=a_{3}[n]\\a_{1}[n+1]=a_{2}[n]\\a_{0}[n+1]=a_{1}[n]\end{cases}}}

where *n* is the time index and     +   {\displaystyle +}   represents [modulo-2](https://en.wikipedia.org/wiki/Modular_arithmetic) addition. For bit values 0 = FALSE or 1 = TRUE, this is equivalent to the XOR operation.

As MLS are periodic and shift registers cycle through every possible binary value (with the exception of the zero vector), registers can be initialized to any state, with the exception of the zero vector.

### Polynomial interpretation

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=2)]

A [polynomial](https://en.wikipedia.org/wiki/Polynomial) over [GF(2)](https://en.wikipedia.org/wiki/Galois_field) can be associated with the linear-feedback shift register. It has degree of the length of the shift register, and has coefficients that are either 0 or 1, corresponding to the taps of the register that feed the [xor](https://en.wikipedia.org/wiki/Xor) gate. For example, the polynomial corresponding to Figure 1 is      x  4   + x + 1   {\displaystyle x^{4}+x+1}  .

A necessary and sufficient condition for the sequence generated by a LFSR to be maximal length is that its corresponding polynomial be [primitive](https://en.wikipedia.org/wiki/Primitive_polynomial_(field_theory)).

### Implementation

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=3)]

MLS are inexpensive to implement in hardware or software, and relatively low-order feedback shift registers can generate long sequences; a sequence generated using a shift register of length 20 is 220 − 1 samples long (1,048,575 samples).

## Properties of maximum-length sequences

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=4)]

MLS have the following properties, as formulated by [Solomon Golomb](https://en.wikipedia.org/wiki/Solomon_Golomb).[[4]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-golumb-4)

### Balance property

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=5)]

The occurrence of 0 and 1 in the sequence should be approximately the same. More precisely, in a maximum-length sequence of length      2  n   − 1   {\displaystyle 2^{n}-1}   there are      2  n − 1     {\displaystyle 2^{n-1}}   ones and      2  n − 1   − 1   {\displaystyle 2^{n-1}-1}   zeros. The number of ones equals the number of zeros plus one, since the state containing only zeros cannot occur.

### Run property

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=6)]

A "run" is a sub-sequence of consecutive "1"s or consecutive "0"s within the MLS concerned. The number of runs is the number of such sub-sequences. [*[vague](https://en.wikipedia.org/wiki/Wikipedia:Vagueness)*]

Of all the "runs" (consisting of "1"s or "0"s) in the sequence :

- One half of the runs are of length 1.
- One quarter of the runs are of length 2.
- One eighth of the runs are of length 3.
- ... etc. ...

### Correlation property

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=7)]

The circular [autocorrelation](https://en.wikipedia.org/wiki/Autocorrelation) of an MLS is a [Kronecker delta](https://en.wikipedia.org/wiki/Kronecker_delta) function[[5]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-5)[[6]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-6) (with DC offset and time delay, depending on implementation). For the ±1 convention, i.e., bit value 1 is assigned     s = + 1   {\displaystyle s=+1}   and bit value 0     s = − 1   {\displaystyle s=-1}  , mapping XOR to the negative of the product:

R ( n ) =   1 N    ∑  m = 1   N   s [ m ]   s  ∗   [ m + n  ]  N   =   {    1    if   n = 0 ,     −   1 N      if   0 < n < N .         {\displaystyle R(n)={\frac {1}{N}}\sum _{m=1}^{N}s[m]\,s^{*}[m+n]_{N}={\begin{cases}1&{\text{if }}n=0,\\-{\frac {1}{N}}&{\text{if }}0<n<N.\end{cases}}}

where      s  ∗     {\displaystyle s^{*}}   represents the [complex conjugate](https://en.wikipedia.org/wiki/Complex_conjugate) and     [ m + n  ]  N     {\displaystyle [m+n]_{N}}   represents a [circular shift](https://en.wikipedia.org/wiki/Circular_shift).

The linear autocorrelation of an MLS approximates a Kronecker delta.

## Extraction of impulse responses

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=8)]

If a [linear time invariant](https://en.wikipedia.org/wiki/LTI_system_theory) (LTI) system's impulse response is to be measured using a MLS, the response can be extracted from the measured system output *y*[*n*] by taking its circular [cross-correlation](https://en.wikipedia.org/wiki/Cross-correlation) with the MLS. This is because the [autocorrelation](https://en.wikipedia.org/wiki/Autocorrelation) of a MLS is 1 for zero-lag, and nearly zero (−1/*N* where *N* is the sequence length) for all other lags; in other words, the autocorrelation of the MLS can be said to approach unit impulse function as MLS length increases.

If the impulse response of a system is *h*[*n*] and the MLS is *s*[*n*], then

     y [ n ] = ( h ∗ s ) [ n ] .    {\displaystyle y[n]=(h*s)[n].\,}

Taking the cross-correlation with respect to *s*[*n*] of both sides,

      φ  s y   = h [ n ] ∗  φ  s s      {\displaystyle \varphi _{sy}=h[n]*\varphi _{ss}\,}

and assuming that φ*ss* is an impulse (valid for long sequences)

     h [ n ] =  φ  s y   .    {\displaystyle h[n]=\varphi _{sy}.\,}

Any signal with an impulsive autocorrelation can be used for this purpose, but signals with high [crest factor](https://en.wikipedia.org/wiki/Crest_factor), such as the impulse itself, produce impulse responses with poor [signal-to-noise ratio](https://en.wikipedia.org/wiki/Signal-to-noise_ratio). It is commonly assumed that the MLS would then be the ideal signal, as it consists of only full-scale values and its digital crest factor is the minimum, 0 dB.[[7]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-7)[[8]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-8) However, after [analog reconstruction](https://en.wikipedia.org/wiki/Digital-to-analog_converter), the sharp discontinuities in the signal produce strong intersample peaks, degrading the crest factor by 4-8 dB or more, increasing with signal length, making it worse than a sine sweep.[[9]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-9) Other signals have been designed with minimal crest factor, though it is unknown if it can be improved beyond 3 dB.[[10]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-10)

## Relationship to Hadamard transform

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=9)]

Cohn and Lempel[[11]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-cohn-11) showed the relationship of the MLS to the [Hadamard transform](https://en.wikipedia.org/wiki/Hadamard_transform). This relationship allows the [correlation](https://en.wikipedia.org/wiki/Correlation) of an MLS to be computed in a fast algorithm similar to the [FFT](https://en.wikipedia.org/wiki/Fast_Fourier_transform).

A **maximum-length sequence** (**MLS**) is a type of [pseudorandom binary sequence](https://en.wikipedia.org/wiki/Pseudorandom_binary_sequence).

They are bit sequences generated using maximal [linear-feedback shift registers](https://en.wikipedia.org/wiki/Linear-feedback_shift_register) and are so called because they are [periodic](https://en.wikipedia.org/wiki/Periodic_function) and reproduce every [binary sequence](https://en.wikipedia.org/wiki/Binary_sequence) (except the zero vector) that can be represented by the shift registers (i.e., for length-*m* registers they produce a sequence of length 2*m* − 1). An MLS is also sometimes called an *n*-**sequence** or an *m*-**sequence**. MLSs are [spectrally flat](https://en.wikipedia.org/wiki/Frequency_spectrum), with the exception of a near-zero DC term.

These sequences may be represented as coefficients of [primitive](https://en.wikipedia.org/wiki/Primitive_polynomial_(field_theory))[[1]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-1) polynomials in a [polynomial ring](https://en.wikipedia.org/wiki/Polynomial_ring) over [Z/2Z](https://en.wikipedia.org/wiki/Congruence_subgroup).

Practical applications for MLS include measuring [impulse responses](https://en.wikipedia.org/wiki/Impulse_response) (e.g., of room [reverberation](https://en.wikipedia.org/wiki/Reverberation) or arrival times from towed sources in the ocean[[2]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-2)). They are also used as a basis for deriving pseudo-random sequences in digital communication systems that employ [direct-sequence spread spectrum](https://en.wikipedia.org/wiki/Direct-sequence_spread_spectrum) and [frequency-hopping spread spectrum](https://en.wikipedia.org/wiki/Frequency-hopping_spread_spectrum) [transmission systems](https://en.wikipedia.org/wiki/Transmission_system), and in the efficient design of some [fMRI](https://en.wikipedia.org/wiki/Functional_magnetic_resonance_imaging) experiments.[[3]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-buracas-3)

Generation

# Generation

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=1)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/0/01/MLS_shiftregisters_L4.png/500px-MLS_shiftregisters_L4.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:MLS_shiftregisters_L4.png)Figure 1: The next value of register *a*3 in a feedback shift register of length 4 is determined by the modulo-2 sum of *a*0 and *a*1.

MLS are generated using maximal [linear-feedback shift registers](https://en.wikipedia.org/wiki/Linear-feedback_shift_register). An MLS-generating system with a shift register of length 4 is shown in Fig. 1. It can be expressed using the following recursive relation:

       {     a  3   [ n + 1 ] =  a  0   [ n ] +  a  1   [ n ]      a  2   [ n + 1 ] =  a  3   [ n ]      a  1   [ n + 1 ] =  a  2   [ n ]      a  0   [ n + 1 ] =  a  1   [ n ]         {\displaystyle {\begin{cases}a_{3}[n+1]=a_{0}[n]+a_{1}[n]\\a_{2}[n+1]=a_{3}[n]\\a_{1}[n+1]=a_{2}[n]\\a_{0}[n+1]=a_{1}[n]\end{cases}}}

where *n* is the time index and     +   {\displaystyle +}   represents [modulo-2](https://en.wikipedia.org/wiki/Modular_arithmetic) addition. For bit values 0 = FALSE or 1 = TRUE, this is equivalent to the XOR operation.

As MLS are periodic and shift registers cycle through every possible binary value (with the exception of the zero vector), registers can be initialized to any state, with the exception of the zero vector.

Polynomial interpretation

# Polynomial interpretation

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=2)]

A [polynomial](https://en.wikipedia.org/wiki/Polynomial) over [GF(2)](https://en.wikipedia.org/wiki/Galois_field) can be associated with the linear-feedback shift register. It has degree of the length of the shift register, and has coefficients that are either 0 or 1, corresponding to the taps of the register that feed the [xor](https://en.wikipedia.org/wiki/Xor) gate. For example, the polynomial corresponding to Figure 1 is      x  4   + x + 1   {\displaystyle x^{4}+x+1}  .

A necessary and sufficient condition for the sequence generated by a LFSR to be maximal length is that its corresponding polynomial be [primitive](https://en.wikipedia.org/wiki/Primitive_polynomial_(field_theory)).

Implementation

# Implementation

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=3)]

MLS are inexpensive to implement in hardware or software, and relatively low-order feedback shift registers can generate long sequences; a sequence generated using a shift register of length 20 is 220 − 1 samples long (1,048,575 samples).

Properties of maximum-length sequences

# Properties of maximum-length sequences

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=4)]

MLS have the following properties, as formulated by [Solomon Golomb](https://en.wikipedia.org/wiki/Solomon_Golomb).[[4]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-golumb-4)

Balance property

# Balance property

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=5)]

The occurrence of 0 and 1 in the sequence should be approximately the same. More precisely, in a maximum-length sequence of length      2  n   − 1   {\displaystyle 2^{n}-1}   there are      2  n − 1     {\displaystyle 2^{n-1}}   ones and      2  n − 1   − 1   {\displaystyle 2^{n-1}-1}   zeros. The number of ones equals the number of zeros plus one, since the state containing only zeros cannot occur.

Run property

# Run property

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=6)]

A "run" is a sub-sequence of consecutive "1"s or consecutive "0"s within the MLS concerned. The number of runs is the number of such sub-sequences. [*[vague](https://en.wikipedia.org/wiki/Wikipedia:Vagueness)*]

Of all the "runs" (consisting of "1"s or "0"s) in the sequence :

- One half of the runs are of length 1.
- One quarter of the runs are of length 2.
- One eighth of the runs are of length 3.
- ... etc. ...

Correlation property

# Correlation property

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=7)]

The circular [autocorrelation](https://en.wikipedia.org/wiki/Autocorrelation) of an MLS is a [Kronecker delta](https://en.wikipedia.org/wiki/Kronecker_delta) function[[5]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-5)[[6]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-6) (with DC offset and time delay, depending on implementation). For the ±1 convention, i.e., bit value 1 is assigned     s = + 1   {\displaystyle s=+1}   and bit value 0     s = − 1   {\displaystyle s=-1}  , mapping XOR to the negative of the product:

R ( n ) =   1 N    ∑  m = 1   N   s [ m ]   s  ∗   [ m + n  ]  N   =   {    1    if   n = 0 ,     −   1 N      if   0 < n < N .         {\displaystyle R(n)={\frac {1}{N}}\sum _{m=1}^{N}s[m]\,s^{*}[m+n]_{N}={\begin{cases}1&{\text{if }}n=0,\\-{\frac {1}{N}}&{\text{if }}0<n<N.\end{cases}}}

where      s  ∗     {\displaystyle s^{*}}   represents the [complex conjugate](https://en.wikipedia.org/wiki/Complex_conjugate) and     [ m + n  ]  N     {\displaystyle [m+n]_{N}}   represents a [circular shift](https://en.wikipedia.org/wiki/Circular_shift).

The linear autocorrelation of an MLS approximates a Kronecker delta.

Extraction of impulse responses

# Extraction of impulse responses

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=8)]

If a [linear time invariant](https://en.wikipedia.org/wiki/LTI_system_theory) (LTI) system's impulse response is to be measured using a MLS, the response can be extracted from the measured system output *y*[*n*] by taking its circular [cross-correlation](https://en.wikipedia.org/wiki/Cross-correlation) with the MLS. This is because the [autocorrelation](https://en.wikipedia.org/wiki/Autocorrelation) of a MLS is 1 for zero-lag, and nearly zero (−1/*N* where *N* is the sequence length) for all other lags; in other words, the autocorrelation of the MLS can be said to approach unit impulse function as MLS length increases.

If the impulse response of a system is *h*[*n*] and the MLS is *s*[*n*], then

     y [ n ] = ( h ∗ s ) [ n ] .    {\displaystyle y[n]=(h*s)[n].\,}

Taking the cross-correlation with respect to *s*[*n*] of both sides,

      φ  s y   = h [ n ] ∗  φ  s s      {\displaystyle \varphi _{sy}=h[n]*\varphi _{ss}\,}

and assuming that φ*ss* is an impulse (valid for long sequences)

     h [ n ] =  φ  s y   .    {\displaystyle h[n]=\varphi _{sy}.\,}

Any signal with an impulsive autocorrelation can be used for this purpose, but signals with high [crest factor](https://en.wikipedia.org/wiki/Crest_factor), such as the impulse itself, produce impulse responses with poor [signal-to-noise ratio](https://en.wikipedia.org/wiki/Signal-to-noise_ratio). It is commonly assumed that the MLS would then be the ideal signal, as it consists of only full-scale values and its digital crest factor is the minimum, 0 dB.[[7]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-7)[[8]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-8) However, after [analog reconstruction](https://en.wikipedia.org/wiki/Digital-to-analog_converter), the sharp discontinuities in the signal produce strong intersample peaks, degrading the crest factor by 4-8 dB or more, increasing with signal length, making it worse than a sine sweep.[[9]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-9) Other signals have been designed with minimal crest factor, though it is unknown if it can be improved beyond 3 dB.[[10]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-10)

Relationship to Hadamard transform

# Relationship to Hadamard transform

[[edit](https://en.wikipedia.org/w/index.php?title=Maximum-length_sequence&action=edit&section=9)]

Cohn and Lempel[[11]](https://en.wikipedia.org/wiki/Maximum-length_sequence#cite_note-cohn-11) showed the relationship of the MLS to the [Hadamard transform](https://en.wikipedia.org/wiki/Hadamard_transform). This relationship allows the [correlation](https://en.wikipedia.org/wiki/Correlation) of an MLS to be computed in a fast algorithm similar to the [FFT](https://en.wikipedia.org/wiki/Fast_Fourier_transform).
