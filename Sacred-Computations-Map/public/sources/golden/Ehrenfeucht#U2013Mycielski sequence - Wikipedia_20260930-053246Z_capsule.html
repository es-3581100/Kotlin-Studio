# Ehrenfeucht–Mycielski sequence

- [Français](https://fr.wikipedia.org/wiki/Suite_d%27Ehrenfeucht-Mycielski)
 [Edit links](https://www.wikidata.org/wiki/Special:EntityPage/Q5348613#sitelinks-wikipedia)                          From Wikipedia, the free encyclopedia

The **Ehrenfeucht–Mycielski sequence** is a recursively defined sequence of [binary digits](https://en.wikipedia.org/wiki/Binary_digits) with [pseudorandom](https://en.wikipedia.org/wiki/Pseudorandom) properties, defined by [Andrzej Ehrenfeucht](https://en.wikipedia.org/wiki/Andrzej_Ehrenfeucht) and [Jan Mycielski](https://en.wikipedia.org/wiki/Jan_Mycielski) ([1992](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#CITEREFEhrenfeuchtMycielski1992)).

## Definition

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=1)]

The sequence starts with the single bit 0; each successive digit is formed by finding the longest suffix of the sequence that also occurs earlier within the sequence, and complementing the bit following the most recent earlier occurrence of that suffix. (The empty string is a suffix and prefix of every string.) For example, the first few steps of this construction process are:[[1]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-oeis-1)

1. 0: initial bit
2. 01: the suffix "" of "0" occurs earlier, most-recently followed by a 0, so add 1
3. 010: the suffix "" of "01" occurs earlier, most-recently followed by a 1, so add 0
4. 0100: the suffix "0" of "010" occurs earlier, most-recently followed by a 1, so add 0
5. 01001: the suffix "0" of "0100" occurs earlier, most-recently followed by a 0, so add 1
6. 010011: the suffix "01" of "01001" occurs earlier, most-recently followed by a 0, so add 1
7. 0100110: the suffix "1" of "010011" occurs earlier, most-recently followed by a 1, so add 0

The first few digits of the sequence are:[[1]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-oeis-1)

 010011010111000100001111...

## Algorithms

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=2)]

A naive [algorithm](https://en.wikipedia.org/wiki/Algorithm) that generates each bit in the sequence by comparing each suffix with the entire previous sequence could take as much as     O (  n  3   )   {\displaystyle O(n^{3})}   time to generate the first     n   {\displaystyle n}   bits of the sequence. However, using a data structure related to a [suffix tree](https://en.wikipedia.org/wiki/Suffix_tree), the sequence can be generated much more efficiently, in [constant time](https://en.wikipedia.org/wiki/Constant_time) per generated digit.[[2]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-hs09-2)

## Universality

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=3)]

The sequence is [disjunctive](https://en.wikipedia.org/wiki/Disjunctive_sequence), meaning that every finite subsequence of bits occurs contiguously, infinitely often within the sequence.[[3]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-em92-3) More explicitly, the position by which every subsequence of length     i   {\displaystyle i}   can be guaranteed to have occurred at least     j   {\displaystyle j}   times is at most     A ( 4 i , j )   {\displaystyle A(4i,j)}   where     A   {\displaystyle A}   is the [Ackermann function](https://en.wikipedia.org/wiki/Ackermann_function).[[2]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-hs09-2) Experimentally, however, each subsequence appears much earlier in this sequence than this upper bound would suggest: the position by which all length-    i   {\displaystyle i}   sequences occur, up to the limit of experimental testing, is close to the minimum possible value it could be,      2  i   + i   {\displaystyle 2^{i}+i}  , the position by which a [de Bruijn sequence](https://en.wikipedia.org/wiki/De_Bruijn_sequence) contains all length-    i   {\displaystyle i}   substrings.[[4]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-s03-4)

## Normality

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=4)]  Unsolved problem in mathematics Is the binary number 0.01001101... normal? [More unsolved problems in mathematics](https://en.wikipedia.org/wiki/List_of_unsolved_problems_in_mathematics)

[Ehrenfeucht & Mycielski (1992)](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#CITEREFEhrenfeuchtMycielski1992) conjecture that the numbers of 0 and 1 bits each converge to a limiting density of 1/2. That is, if     f ( i )   {\displaystyle f(i)}   denotes the number of 0 bits in the first     i   {\displaystyle i}   positions of the Ehrenfeucht–Mycielski sequence, then it should be the case that      lim  i → ∞      f ( i )  i   =   1 2   .   {\displaystyle \lim _{i\rightarrow \infty }{\frac {f(i)}{i}}={\frac {1}{2}}.}   More strongly, [I. J. Good](https://en.wikipedia.org/wiki/I._J._Good) suggests that the [convergence rate](https://en.wikipedia.org/wiki/Convergence_rate) of this limit should be significantly faster than that of a [random binary sequence](https://en.wikipedia.org/wiki/Random_sequence), for which (by the [law of the iterated logarithm](https://en.wikipedia.org/wiki/Law_of_the_iterated_logarithm))[[3]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-em92-3)        f ( i )  i   =   1 2   + O  (     log ⁡ log ⁡ i  i    )  .   {\displaystyle {\frac {f(i)}{i}}={\frac {1}{2}}+O\left({\sqrt {\frac {\log \log i}{i}}}\right).}   The Ehrenfeucht–Mycielski balance conjecture suggests that the binary number 0.01001101... (the number having the Ehrenfeucht–Mycielski sequence as its sequence of binary digits after the binary point) may be a [normal number](https://en.wikipedia.org/wiki/Normal_number) in [base 2](https://en.wikipedia.org/wiki/Base_2). As of 2009 this conjecture remains unproven;[[2]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-hs09-2) however, it is known that every limit point of the sequence of values     f ( i )  /  i   {\displaystyle f(i)/i}   lies between 1/4 and 3/4 inclusive.[[5]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-ks07-5)

# Ehrenfeucht–Mycielski sequence

- [Français](https://fr.wikipedia.org/wiki/Suite_d%27Ehrenfeucht-Mycielski)
 [Edit links](https://www.wikidata.org/wiki/Special:EntityPage/Q5348613#sitelinks-wikipedia)                          From Wikipedia, the free encyclopedia

The **Ehrenfeucht–Mycielski sequence** is a recursively defined sequence of [binary digits](https://en.wikipedia.org/wiki/Binary_digits) with [pseudorandom](https://en.wikipedia.org/wiki/Pseudorandom) properties, defined by [Andrzej Ehrenfeucht](https://en.wikipedia.org/wiki/Andrzej_Ehrenfeucht) and [Jan Mycielski](https://en.wikipedia.org/wiki/Jan_Mycielski) ([1992](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#CITEREFEhrenfeuchtMycielski1992)).

Definition

# Definition

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=1)]

The sequence starts with the single bit 0; each successive digit is formed by finding the longest suffix of the sequence that also occurs earlier within the sequence, and complementing the bit following the most recent earlier occurrence of that suffix. (The empty string is a suffix and prefix of every string.) For example, the first few steps of this construction process are:[[1]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-oeis-1)

1. 0: initial bit
2. 01: the suffix "" of "0" occurs earlier, most-recently followed by a 0, so add 1
3. 010: the suffix "" of "01" occurs earlier, most-recently followed by a 1, so add 0
4. 0100: the suffix "0" of "010" occurs earlier, most-recently followed by a 1, so add 0
5. 01001: the suffix "0" of "0100" occurs earlier, most-recently followed by a 0, so add 1
6. 010011: the suffix "01" of "01001" occurs earlier, most-recently followed by a 0, so add 1
7. 0100110: the suffix "1" of "010011" occurs earlier, most-recently followed by a 1, so add 0

The first few digits of the sequence are:[[1]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-oeis-1)

 010011010111000100001111...

Algorithms

# Algorithms

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=2)]

A naive [algorithm](https://en.wikipedia.org/wiki/Algorithm) that generates each bit in the sequence by comparing each suffix with the entire previous sequence could take as much as     O (  n  3   )   {\displaystyle O(n^{3})}   time to generate the first     n   {\displaystyle n}   bits of the sequence. However, using a data structure related to a [suffix tree](https://en.wikipedia.org/wiki/Suffix_tree), the sequence can be generated much more efficiently, in [constant time](https://en.wikipedia.org/wiki/Constant_time) per generated digit.[[2]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-hs09-2)

Universality

# Universality

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=3)]

The sequence is [disjunctive](https://en.wikipedia.org/wiki/Disjunctive_sequence), meaning that every finite subsequence of bits occurs contiguously, infinitely often within the sequence.[[3]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-em92-3) More explicitly, the position by which every subsequence of length     i   {\displaystyle i}   can be guaranteed to have occurred at least     j   {\displaystyle j}   times is at most     A ( 4 i , j )   {\displaystyle A(4i,j)}   where     A   {\displaystyle A}   is the [Ackermann function](https://en.wikipedia.org/wiki/Ackermann_function).[[2]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-hs09-2) Experimentally, however, each subsequence appears much earlier in this sequence than this upper bound would suggest: the position by which all length-    i   {\displaystyle i}   sequences occur, up to the limit of experimental testing, is close to the minimum possible value it could be,      2  i   + i   {\displaystyle 2^{i}+i}  , the position by which a [de Bruijn sequence](https://en.wikipedia.org/wiki/De_Bruijn_sequence) contains all length-    i   {\displaystyle i}   substrings.[[4]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-s03-4)

Normality

# Normality

[[edit](https://en.wikipedia.org/w/index.php?title=Ehrenfeucht%E2%80%93Mycielski_sequence&action=edit&section=4)]  Unsolved problem in mathematics Is the binary number 0.01001101... normal? [More unsolved problems in mathematics](https://en.wikipedia.org/wiki/List_of_unsolved_problems_in_mathematics)

[Ehrenfeucht & Mycielski (1992)](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#CITEREFEhrenfeuchtMycielski1992) conjecture that the numbers of 0 and 1 bits each converge to a limiting density of 1/2. That is, if     f ( i )   {\displaystyle f(i)}   denotes the number of 0 bits in the first     i   {\displaystyle i}   positions of the Ehrenfeucht–Mycielski sequence, then it should be the case that      lim  i → ∞      f ( i )  i   =   1 2   .   {\displaystyle \lim _{i\rightarrow \infty }{\frac {f(i)}{i}}={\frac {1}{2}}.}   More strongly, [I. J. Good](https://en.wikipedia.org/wiki/I._J._Good) suggests that the [convergence rate](https://en.wikipedia.org/wiki/Convergence_rate) of this limit should be significantly faster than that of a [random binary sequence](https://en.wikipedia.org/wiki/Random_sequence), for which (by the [law of the iterated logarithm](https://en.wikipedia.org/wiki/Law_of_the_iterated_logarithm))[[3]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-em92-3)        f ( i )  i   =   1 2   + O  (     log ⁡ log ⁡ i  i    )  .   {\displaystyle {\frac {f(i)}{i}}={\frac {1}{2}}+O\left({\sqrt {\frac {\log \log i}{i}}}\right).}   The Ehrenfeucht–Mycielski balance conjecture suggests that the binary number 0.01001101... (the number having the Ehrenfeucht–Mycielski sequence as its sequence of binary digits after the binary point) may be a [normal number](https://en.wikipedia.org/wiki/Normal_number) in [base 2](https://en.wikipedia.org/wiki/Base_2). As of 2009 this conjecture remains unproven;[[2]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-hs09-2) however, it is known that every limit point of the sequence of values     f ( i )  /  i   {\displaystyle f(i)/i}   lies between 1/4 and 3/4 inclusive.[[5]](https://en.wikipedia.org/wiki/Ehrenfeucht%E2%80%93Mycielski_sequence#cite_note-ks07-5)
