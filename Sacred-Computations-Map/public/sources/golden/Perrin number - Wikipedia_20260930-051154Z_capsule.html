In mathematics, the **Perrin numbers** are a doubly infinite [constant-recursive](https://en.wikipedia.org/wiki/Constant-recursive_sequence) [integer sequence](https://en.wikipedia.org/wiki/Integer_sequence) with [characteristic equation](https://en.wikipedia.org/wiki/Characteristic_equation_(calculus)) *x*3 = *x* + 1. The Perrin numbers, named after the French engineer [Raoul Perrin](https://en.wikipedia.org/wiki/Raoul_Perrin?action=edit&redlink=1) [[fr](https://fr.wikipedia.org/wiki/Raoul%20Perrin)], bear the same relationship to the [Padovan sequence](https://en.wikipedia.org/wiki/Padovan_sequence) as the [Lucas numbers](https://en.wikipedia.org/wiki/Lucas_numbers) do to the [Fibonacci sequence](https://en.wikipedia.org/wiki/Fibonacci_sequence).

### History

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=2)]

In 1876 the sequence and its equation were initially mentioned by [Édouard Lucas](https://en.wikipedia.org/wiki/%C3%89douard_Lucas), who noted that the index *n* divides term P(n) if *n* is prime.[[5]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-5) In 1899 [Raoul Perrin](https://en.wikipedia.org/wiki/Raoul_Perrin?action=edit&redlink=1) [[fr](https://fr.wikipedia.org/wiki/Raoul_Perrin)] asked if there were any counterexamples to this property.[[6]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-6) The first P(n) divisible by composite index *n* was found only in 1982 by William Adams and [Daniel Shanks](https://en.wikipedia.org/wiki/Daniel_Shanks).[[7]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-7) They presented a detailed investigation of the sequence, with a sequel appearing four years later.[[8]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-8)

## Properties

The Perrin sequence also satisfies the recurrence relation     P ( n ) = P ( n − 1 ) + P ( n − 5 ) .   {\displaystyle P(n)=P(n-1)+P(n-5).}   Starting from this and the defining recurrence, one can create an infinite number of further relations, for example     P ( n ) = P ( n − 3 ) + P ( n − 4 ) + P ( n − 5 ) .   {\displaystyle P(n)=P(n-3)+P(n-4)+P(n-5).}

The [generating function](https://en.wikipedia.org/wiki/Generating_function) of the Perrin sequence is

        3 −  x  2     1 −  x  2   −  x  3      =  ∑  n = 0   ∞   P ( n )   x  n     {\displaystyle {\frac {3-x^{2}}{1-x^{2}-x^{3}}}=\sum _{n=0}^{\infty }P(n)\,x^{n}}

The sequence is related to sums of [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficient) by

     P ( n ) = n ×  ∑  k = ⌊ ( n + 2 )  /  3 ⌋   ⌊ n  /  2 ⌋      (   k  n − 2 k    )     /  k ,   {\displaystyle P(n)=n\times \sum _{k=\lfloor (n+2)/3\rfloor }^{\lfloor n/2\rfloor }{\binom {k}{n-2k}}/k,}  [[1]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-A001608-1)

Perrin numbers can be expressed in terms of partial sums

         P ( n + 5 ) − 2    =  ∑  k = 0   n   P ( k )     P ( 2 n + 3 )    =  ∑  k = 0   n   P ( 2 k )     5 − P ( 4 − n )    =  ∑  k = 0   n   P ( − k )     3 − P ( 1 − 2 n )    =  ∑  k = 0   n   P ( − 2 k ) .       {\displaystyle {\begin{aligned}P(n+5)-2&=\sum _{k=0}^{n}P(k)\\P(2n+3)&=\sum _{k=0}^{n}P(2k)\\5-P(4-n)&=\sum _{k=0}^{n}P(-k)\\3-P(1-2n)&=\sum _{k=0}^{n}P(-2k).\end{aligned}}}

The Perrin numbers are obtained as integral powers n ≥ 0 of the [matrix](https://en.wikipedia.org/wiki/Matrix_(mathematics))

        (    0   1   0     0   0   1     1   1   0    )    n     (    3     0     2    )   =   (    P ( n )     P ( n + 1 )     P ( n + 2 )    )   ,   {\displaystyle {\begin{pmatrix}0&1&0\\0&0&1\\1&1&0\end{pmatrix}}^{n}{\begin{pmatrix}3\\0\\2\end{pmatrix}}={\begin{pmatrix}P(n)\\P(n+1)\\P(n+2)\end{pmatrix}},}

and its [inverse](https://en.wikipedia.org/wiki/Invertible_matrix)

        (    − 1   0   1     1   0   0     0   1   0    )    n     (    3     0     2    )   =   (    P ( − n )     P ( 1 − n )     P ( 2 − n )    )   .   {\displaystyle {\begin{pmatrix}-1&0&1\\1&0&0\\0&1&0\end{pmatrix}}^{n}{\begin{pmatrix}3\\0\\2\end{pmatrix}}={\begin{pmatrix}P(-n)\\P(1-n)\\P(2-n)\end{pmatrix}}.}

The Perrin analogue of the [Simson identity](https://en.wikipedia.org/wiki/Cassini_and_Catalan_identities) for [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number) is given by the determinant

       |    P ( n + 2 )   P ( n + 1 )   P ( n )     P ( n + 1 )   P ( n )   P ( n − 1 )     P ( n )   P ( n − 1 )   P ( n − 2 )    |   = − 23.   {\displaystyle {\begin{vmatrix}P(n+2)&P(n+1)&P(n)\\P(n+1)&P(n)&P(n-1)\\P(n)&P(n-1)&P(n-2)\end{vmatrix}}=-23.}

The number of different [maximal independent sets](https://en.wikipedia.org/wiki/Maximal_independent_set) in an *n*-vertex [cycle graph](https://en.wikipedia.org/wiki/Cycle_graph) is counted by the *n*th Perrin number for n ≥ 2.[[9]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-9)

### Binet formula

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=4)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/9/9a/Perrin_function_real.svg/500px-Perrin_function_real.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Perrin_function_real.svg)The Perrin function extends the sequence to real numbers.

The [solution](https://en.wikipedia.org/wiki/Linear_recurrence_with_constant_coefficients#General_solution) of the recurrence     P ( n ) = P ( n − 2 ) + P ( n − 3 )   {\displaystyle P(n)=P(n-2)+P(n-3)}   can be written in terms of the [roots](https://en.wikipedia.org/wiki/Cubic_equation#Cardano's_formula) of [characteristic equation](https://en.wikipedia.org/wiki/Characteristic_equation_(calculus))      x  3   − x − 1 = 0   {\displaystyle x^{3}-x-1=0}  . If the three solutions are [real](https://en.wikipedia.org/wiki/Real_number) root ⁠    α   {\displaystyle \alpha }  ⁠ (with approximate value 1.324718 and known as the [plastic ratio](https://en.wikipedia.org/wiki/Plastic_ratio)) and [complex conjugate](https://en.wikipedia.org/wiki/Complex_conjugate) roots ⁠    β   {\displaystyle \beta }  ⁠ and ⁠    γ   {\displaystyle \gamma }  ⁠, the Perrin numbers can be computed with the [Binet formula](https://en.wikipedia.org/wiki/Lucas_sequence#Explicit_expressions)     P ( n ) =  α  n   +  β  n   +  γ  n   ,   {\displaystyle P(n)=\alpha ^{n}+\beta ^{n}+\gamma ^{n},}   which also holds for negative *n*.

The [polar form](https://en.wikipedia.org/wiki/Polar_coordinate_system) is     P ( n ) =  α  n   + 2 cos ⁡ ( n  θ )    α  − n     ,   {\displaystyle P(n)=\alpha ^{n}+2\cos(n\,\theta ){\sqrt {\alpha ^{-n}}},}   with     θ = arccos ⁡ ( −    α  3      /  2 ) .   {\displaystyle \theta =\arccos(-{\sqrt {\alpha ^{3}}}/2).}   Since      lim  n → ∞    α  − n   = 0 ,   {\displaystyle \lim _{n\to \infty }\alpha ^{-n}=0,}   the formula reduces to either the first or the second term successively for large positive or negative *n*, and numbers with negative subscripts oscillate. Provided *α* is computed to sufficient precision, these formulas can be used to calculate Perrin numbers for large *n*.

Expanding the identity      P  2   ( n ) = (  α  n   +  β  n   +  γ  n    )  2     {\displaystyle P^{2}(n)=(\alpha ^{n}+\beta ^{n}+\gamma ^{n})^{2}}   gives the important index-doubling rule     P ( 2 n ) =  P  2   ( n ) − 2 P ( − n ) ,   {\displaystyle P(2n)=P^{2}(n)-2P(-n),}   by which the forward and reverse parts of the sequence are linked.

### Prime index *p* divides *P(p)*

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=5)]

If the characteristic equation of the sequence is written as     f ( x ) =  x  3   −  σ  1    x  2   +  σ  2   x −  σ  3     {\displaystyle f(x)=x^{3}-\sigma _{1}x^{2}+\sigma _{2}x-\sigma _{3}}   then the coefficients ⁠     σ  k     {\displaystyle \sigma _{k}}  ⁠ can be expressed in terms of roots     α , β , γ   {\displaystyle \alpha ,\beta ,\gamma }   with [Vieta's formulas](https://en.wikipedia.org/wiki/Vieta's_formulas):

          σ  1      = α + β + γ     = 0      σ  2      = α β + α γ + β γ     = − 1      σ  3      = α β γ     = 1.       {\displaystyle {\begin{alignedat}{3}\sigma _{1}&=\alpha +\beta +\gamma &&=0\\\sigma _{2}&=\alpha \beta +\alpha \gamma +\beta \gamma &&=-1\\\sigma _{3}&=\alpha \beta \gamma &&=1.\end{alignedat}}}

These integer valued functions are the [elementary symmetric polynomials](https://en.wikipedia.org/wiki/Elementary_symmetric_polynomials) in     α , β , γ .   {\displaystyle \alpha ,\beta ,\gamma .}

- The [fundamental theorem on symmetric polynomials](https://en.wikipedia.org/wiki/Symmetric_polynomial#Relation_with_the_roots_of_a_monic_univariate_polynomial) states that every symmetric polynomial in the complex roots of monic ⁠    f   {\displaystyle f}  ⁠ can be represented as another polynomial function in the integer coefficients of ⁠    f .   {\displaystyle f.}  ⁠
- The analogue of [Lucas's theorem](https://en.wikipedia.org/wiki/Lucas's_theorem) for [multinomial coefficients](https://en.wikipedia.org/wiki/Multinomial_theorem)        p !   i ! j ! k !      {\displaystyle {\frac {p!}{i!j!k!}}}   says that if ⁠    i , j , k < p   {\displaystyle i,j,k<p}  ⁠ then        (   p  i , j , k    )      {\displaystyle {\binom {p}{i,j,k}}}   is divisible by prime ⁠    p .   {\displaystyle p.}  ⁠

Given integers ⁠    a , b , c   {\displaystyle a,b,c}  ⁠ and ⁠    n > 0 ,   {\displaystyle n>0,}  ⁠

     ( a + b + c  )  n   =  ∑  i + j + k = n      (   n  i , j , k    )     a  i    b  j    c  k   .   {\displaystyle (a+b+c)^{n}=\sum _{i+j+k=n}{\binom {n}{i,j,k}}a^{i}b^{j}c^{k}.}

Rearrange into symmetric [monomial](https://en.wikipedia.org/wiki/Monomial) summands, [permuting](https://en.wikipedia.org/wiki/Permutation) exponents i, j, k:

     ( a + b + c  )  n   − (  a  n   +  b  n   +  c  n   ) =   {\displaystyle (a+b+c)^{n}-(a^{n}+b^{n}+c^{n})=}        ∑     i ≤ j ≤ k    < n     i + j + k    = n         (   n  i , j , k    )     ∑  π ( i , j , k )    a  i    b  j    c  k   .   {\displaystyle \sum _{\begin{aligned}i\leq j\leq k&<n\\i+j+k&=n\end{aligned}}{\binom {n}{i,j,k}}\sum _{\pi (i,j,k)}a^{i}b^{j}c^{k}.}

Substitute prime ⁠    p   {\displaystyle p}  ⁠ for power ⁠    n   {\displaystyle n}  ⁠ and complex roots     α , β , γ   {\displaystyle \alpha ,\beta ,\gamma }   for integers ⁠    a , b , c   {\displaystyle a,b,c}  ⁠ and compute representations in terms of      σ  1   ,  σ  2   ,  σ  3     {\displaystyle \sigma _{1},\sigma _{2},\sigma _{3}}   for all symmetric polynomial functions. For example,     ( α + β + γ  )  p     {\displaystyle (\alpha +\beta +\gamma )^{p}}   is      σ  1   p   = 0   {\displaystyle \sigma _{1}^{p}=0}   and the [power sum](https://en.wikipedia.org/wiki/Power_sum_symmetric_polynomial)      α  p   +  β  p   +  γ  p   = P ( p )   {\displaystyle \alpha ^{p}+\beta ^{p}+\gamma ^{p}=P(p)}   can be expressed in the coefficients ⁠     σ  k     {\displaystyle \sigma _{k}}  ⁠ with [Newton's recursive scheme](https://en.wikipedia.org/wiki/Newton's_identities). It follows that the identity has integer terms and both sides divisible by prime ⁠    p .   {\displaystyle p.}  ⁠

To show that prime ⁠    p   {\displaystyle p}  ⁠ divides ⁠    P ( − p ) + 1   {\displaystyle P(-p)+1}  ⁠ in the reverse sequence, the characteristic equation has to be [reflected](https://en.wikipedia.org/wiki/Reciprocal_polynomial). The roots are then      α  − 1   ,  β  − 1   ,  γ  − 1   ,   {\displaystyle \alpha ^{-1},\beta ^{-1},\gamma ^{-1},}   the coefficients      σ  1   = − 1 ,  σ  2   = 0 ,  σ  3   = 1 ,   {\displaystyle \sigma _{1}=-1,\sigma _{2}=0,\sigma _{3}=1,}   and the same reasoning applies.

## Perrin primality test

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=6)]

>
> Query 1484.  The curious proposition of Chinese origin which is the subject of query 1401[10] would provide, if it is true, a more practical criterium than Wilson's theorem for verifying whether a given number m is prime or not; it would suffice to calculate the residues with respect to m of successive terms of the recurrence sequence un = 3un−1 − 2un−2 with initial values u0 =−1, u1 = 0.[11]
> I have found another recurrence sequence that seems to possess the same property; it is the one whose general term is vn = vn−2 + vn−3 with initial values v0 = 3, v1 = 0, v2 = 2. It is easy to demonstrate that vn  is divisible by n, if n is prime; I have verified, up to fairly high values of n, that in the opposite case it is not; but it would be interesting to know if this is really so, especially since the sequence vn  gives much less rapidly increasing numbers than the sequence un  (for n = 17, for example, one finds un = 131070, vn = 119), which leads to simpler calculations when n is a large number.
> The same proof, applicable to one of the sequences, will undoubtedly bear upon the other, if the stated property is true for both: it is only a matter of discovering it.[12]
>

The Perrin sequence has the [Fermat property](https://en.wikipedia.org/wiki/Fermat's_little_theorem): if ⁠    p   {\displaystyle p}  ⁠ is [prime](https://en.wikipedia.org/wiki/Prime_number),     P ( p ) ≡ P ( 1 ) ≡ 0   ( mod  p )  .   {\textstyle P(p)\equiv P(1)\equiv 0{\pmod {p}}.}   However, the [converse](https://en.wikipedia.org/wiki/Converse_(logic)) is not true: some [composite](https://en.wikipedia.org/wiki/Composite_number) ⁠    n   {\displaystyle n}  ⁠ may still divide ⁠    P ( n ) .   {\displaystyle P(n).}  ⁠ A number with this property is called a Perrin [pseudoprime](https://en.wikipedia.org/wiki/Pseudoprime).

The question of the existence of Perrin pseudoprimes was considered by Malo and Jarden,[[13]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-13) but none were known until Adams and Shanks found the smallest one,     271441 =  521  2     {\displaystyle 271441=521^{2}}   (the number P(271441) has 33150 decimal digits).[[14]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-14) Jon Grantham later proved that there are infinitely many Perrin pseudoprimes.[[15]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-15)

The seventeen Perrin pseudoprimes below 109 are
 271441, 904631, 16532714, 24658561, 27422714, 27664033, 46672291, 102690901, 130944133, 196075949, 214038533, 517697641, 545670533, 801123451, 855073301, 903136901, 970355431.[[16]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-16)

Adams and Shanks noted that primes also satisfy the congruence     P ( − p ) ≡ P ( − 1 ) ≡ − 1   ( mod  p )  .   {\textstyle P(-p)\equiv P(-1)\equiv -1{\pmod {p}}.}   Composites for which both properties hold are called restricted Perrin pseudoprimes. There are only nine such numbers below 109.[[17]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-17)[[18]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-18)[[19]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-19)

While Perrin pseudoprimes are rare, they overlap with [Fermat pseudoprimes](https://en.wikipedia.org/wiki/Fermat_pseudoprime). Of the above seventeen numbers, four are base 2 Fermatians as well. In contrast, the [Lucas pseudoprimes](https://en.wikipedia.org/wiki/Lucas_pseudoprime) are anti-correlated.[[20]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-20) Presumably, combining the Perrin and Lucas tests should make a [primality test](https://en.wikipedia.org/wiki/Primality_test) as strong as the reliable [BPSW test](https://en.wikipedia.org/wiki/Baillie%E2%80%93PSW_primality_test) which has no known pseudoprimes – though at higher computational cost.

### Pseudocode

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=7)]

The 1982 Adams and Shanks     O ( log ⁡ n )   {\displaystyle O(\log n)}   Perrin primality test.[[21]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-21)

Two integer arrays u(3) and v(3) are initialized to the lowest terms of the Perrin sequence, with positive indices t = 0, 1, 2 in u( ) and negative indices t = 0,−1,−2 in v( ).

The main [double-and-add](https://en.wikipedia.org/wiki/Addition_chain#Methods_for_computing_addition_chains) loop, originally devised to run on an [HP-41C](https://en.wikipedia.org/wiki/HP-41C) pocket calculator, computes P(n) mod n and the reverse P(−n) mod n at the cost of six modular squarings for each bit of n.

The subscripts of the Perrin numbers are doubled using the identity P(2t) = P2(t) − 2P(−t). The resulting gaps between P(±2t) and P(±2t ± 2) are closed by applying the defining relation P(t) = P(t − 2) + P(t − 3).

```
Initial values
let int u(0):= 3, u(1):= 0, u(2):= 2
let int v(0):= 3, v(1):=−1, v(2):= 1

Test odd positive number n
input int n

set int h:= most significant bit of n

for k:= h − 1 downto 0

  Double the indices of
  the six Perrin numbers.
  for i = 0, 1, 2
    temp:= u(i)^2 − 2v(i) (mod n)
    v(i):= v(i)^2 − 2u(i) (mod n)
    u(i):= temp
  endfor

  Copy P(2t + 2) and P(−2t − 2)
  to the array ends and use
  in the if-statement below.
  u(3):= u(2)
  v(3):= v(2)

  Overwrite P(2t ± 2) with P(2t ± 1)
  temp:= u(2) − u(1)
  u(2):= u(0) + temp
  u(0):= temp

  Overwrite P(−2t ± 2) with P(−2t ± 1)
  temp:= v(0) − v(1)
  v(0):= v(2) + temp
  v(2):= temp

  if n has bit k set then
    Increase the indices of
    both Perrin triples by 1.
    for i = 0, 1, 2
      u(i):= u(i + 1)
      v(i):= v(i + 1)
    endfor
  endif

endfor

Result
print v(2), v(1), v(0)
print u(0), u(1), u(2)
```

Successively P(−n − 1), P(−n), P(−n + 1) and P(n − 1), P(n), P(n + 1) (mod n).

If P(−n) = −1 and P(n) = 0 then *n* is a [probable prime](https://en.wikipedia.org/wiki/Probable_prime), that is: actually prime or a restricted Perrin pseudoprime.

Shanks *et al.* observed that for all restricted pseudoprimes they found, the final state of the above six registers (the "signature" of *n*) equals the initial state 1,−1,3, 3,0,2.[[22]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-22) The same occurs with ≈ 1**/**6 of all primes, so the two sets cannot be distinguished on the strength of this test alone.[[23]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-23) For those cases, they recommend to also use the [Narayana-Lucas sister sequence](https://en.wikipedia.org/wiki/Supergolden_ratio#Narayana_sequence) with recurrence relation A(n) = A(n − 1) + A(n − 3) and initial values

```
u(0):= 3, u(1):= 1, u(2):= 1
v(0):= 3, v(1):= 0, v(2):=−2
```

The same doubling rule applies and the formulas for filling the gaps are

```
temp:= u(0) + u(1)
u(0):= u(2) − temp
u(2):= temp

temp:= v(2) + v(1)
v(2):= v(0) − temp
v(0):= temp
```

Here, *n* is a probable prime if A(−n) = 0 and A(n) = 1.

Kurtz *et al.* found no overlap between the odd pseudoprimes for the two sequences below 50∙109 and supposed that 2,277,740,968,903 = 1067179 ∙ 2134357 is the smallest composite number to pass both tests.[[24]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-24)

If the [third-order Pell-Lucas recurrence](https://en.wikipedia.org/wiki/Supersilver_ratio#Third-order_Pell_sequences) A(n) = 2A(n − 1) + A(n − 3) is used as well, this bound will be pushed up to 4,057,052,731,496,380,171 = 1424263447 ∙ 2848526893.[[25]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-25)

Additionally, roots of the doubling rule-congruence      x  2   − 2 x ≡ 3 = P ( 0 )   ( mod  n )     {\displaystyle x^{2}-2x\equiv 3=P(0){\pmod {n}}\,}   other than −1 or 3 expose composite numbers, like non-trivial square roots of 1 in the [Miller-Rabin test](https://en.wikipedia.org/wiki/Miller%E2%80%93Rabin_primality_test).[[26]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-26) This reduces the number of restricted pseudoprimes for each sequence by roughly one-third and is especially efficient in detecting [Carmichael numbers](https://en.wikipedia.org/wiki/Carmichael_number).[[27]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-27)

The least strong restricted Perrin pseudoprime is 46672291 and the above two bounds expand to successively 173,536,465,910,671 and 79,720,990,309,209,574,421.[[28]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-28)

In mathematics, the **Perrin numbers** are a doubly infinite [constant-recursive](https://en.wikipedia.org/wiki/Constant-recursive_sequence) [integer sequence](https://en.wikipedia.org/wiki/Integer_sequence) with [characteristic equation](https://en.wikipedia.org/wiki/Characteristic_equation_(calculus)) *x*3 = *x* + 1. The Perrin numbers, named after the French engineer [Raoul Perrin](https://en.wikipedia.org/wiki/Raoul_Perrin?action=edit&redlink=1) [[fr](https://fr.wikipedia.org/wiki/Raoul%20Perrin)], bear the same relationship to the [Padovan sequence](https://en.wikipedia.org/wiki/Padovan_sequence) as the [Lucas numbers](https://en.wikipedia.org/wiki/Lucas_numbers) do to the [Fibonacci sequence](https://en.wikipedia.org/wiki/Fibonacci_sequence).

     P ( n ) = P ( n + 3 ) − P ( n + 1 )    for    n < 0.   {\displaystyle P(n)=P(n+3)-P(n+1){\mbox{ for }}n<0.}

History

# History

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=2)]

In 1876 the sequence and its equation were initially mentioned by [Édouard Lucas](https://en.wikipedia.org/wiki/%C3%89douard_Lucas), who noted that the index *n* divides term P(n) if *n* is prime.[[5]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-5) In 1899 [Raoul Perrin](https://en.wikipedia.org/wiki/Raoul_Perrin?action=edit&redlink=1) [[fr](https://fr.wikipedia.org/wiki/Raoul_Perrin)] asked if there were any counterexamples to this property.[[6]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-6) The first P(n) divisible by composite index *n* was found only in 1982 by William Adams and [Daniel Shanks](https://en.wikipedia.org/wiki/Daniel_Shanks).[[7]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-7) They presented a detailed investigation of the sequence, with a sequel appearing four years later.[[8]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-8)

Properties

# Properties

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=3)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/5/5c/Perrin_function_Newton_map.png/500px-Perrin_function_Newton_map.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Perrin_function_Newton_map.png)A Perrin microcosm: the [escape time algorithm](https://en.wikipedia.org/wiki/Plotting_algorithms_for_the_Mandelbrot_set#Escape_time_algorithm) is applied to the [Newton map](https://en.wikipedia.org/wiki/Newton_fractal) of the [entire](https://en.wikipedia.org/wiki/Entire_function) [Perrin function](https://en.wikipedia.org/wiki/Perrin_number#Pfun) F(z) around [critical point](https://en.wikipedia.org/wiki/Critical_point_(mathematics)) z = 1.225432 with viewport width 0.05320. The [basins of attraction](https://en.wikipedia.org/wiki/Attractor#Basins_of_attraction) emanating from the centre correspond to the infinite number of real (left) and complex roots (right) F(z) = 0.

The Perrin sequence also satisfies the recurrence relation     P ( n ) = P ( n − 1 ) + P ( n − 5 ) .   {\displaystyle P(n)=P(n-1)+P(n-5).}   Starting from this and the defining recurrence, one can create an infinite number of further relations, for example     P ( n ) = P ( n − 3 ) + P ( n − 4 ) + P ( n − 5 ) .   {\displaystyle P(n)=P(n-3)+P(n-4)+P(n-5).}

The [generating function](https://en.wikipedia.org/wiki/Generating_function) of the Perrin sequence is

        3 −  x  2     1 −  x  2   −  x  3      =  ∑  n = 0   ∞   P ( n )   x  n     {\displaystyle {\frac {3-x^{2}}{1-x^{2}-x^{3}}}=\sum _{n=0}^{\infty }P(n)\,x^{n}}

The sequence is related to sums of [binomial coefficients](https://en.wikipedia.org/wiki/Binomial_coefficient) by

     P ( n ) = n ×  ∑  k = ⌊ ( n + 2 )  /  3 ⌋   ⌊ n  /  2 ⌋      (   k  n − 2 k    )     /  k ,   {\displaystyle P(n)=n\times \sum _{k=\lfloor (n+2)/3\rfloor }^{\lfloor n/2\rfloor }{\binom {k}{n-2k}}/k,}  [[1]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-A001608-1)

The Perrin numbers are obtained as integral powers n ≥ 0 of the [matrix](https://en.wikipedia.org/wiki/Matrix_(mathematics))

        (    0   1   0     0   0   1     1   1   0    )    n     (    3     0     2    )   =   (    P ( n )     P ( n + 1 )     P ( n + 2 )    )   ,   {\displaystyle {\begin{pmatrix}0&1&0\\0&0&1\\1&1&0\end{pmatrix}}^{n}{\begin{pmatrix}3\\0\\2\end{pmatrix}}={\begin{pmatrix}P(n)\\P(n+1)\\P(n+2)\end{pmatrix}},}

and its [inverse](https://en.wikipedia.org/wiki/Invertible_matrix)

        (    − 1   0   1     1   0   0     0   1   0    )    n     (    3     0     2    )   =   (    P ( − n )     P ( 1 − n )     P ( 2 − n )    )   .   {\displaystyle {\begin{pmatrix}-1&0&1\\1&0&0\\0&1&0\end{pmatrix}}^{n}{\begin{pmatrix}3\\0\\2\end{pmatrix}}={\begin{pmatrix}P(-n)\\P(1-n)\\P(2-n)\end{pmatrix}}.}

The number of different [maximal independent sets](https://en.wikipedia.org/wiki/Maximal_independent_set) in an *n*-vertex [cycle graph](https://en.wikipedia.org/wiki/Cycle_graph) is counted by the *n*th Perrin number for n ≥ 2.[[9]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-9)

Binet formula

# Binet formula

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=4)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/9/9a/Perrin_function_real.svg/500px-Perrin_function_real.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Perrin_function_real.svg)The Perrin function extends the sequence to real numbers.

The [solution](https://en.wikipedia.org/wiki/Linear_recurrence_with_constant_coefficients#General_solution) of the recurrence     P ( n ) = P ( n − 2 ) + P ( n − 3 )   {\displaystyle P(n)=P(n-2)+P(n-3)}   can be written in terms of the [roots](https://en.wikipedia.org/wiki/Cubic_equation#Cardano's_formula) of [characteristic equation](https://en.wikipedia.org/wiki/Characteristic_equation_(calculus))      x  3   − x − 1 = 0   {\displaystyle x^{3}-x-1=0}  . If the three solutions are [real](https://en.wikipedia.org/wiki/Real_number) root ⁠    α   {\displaystyle \alpha }  ⁠ (with approximate value 1.324718 and known as the [plastic ratio](https://en.wikipedia.org/wiki/Plastic_ratio)) and [complex conjugate](https://en.wikipedia.org/wiki/Complex_conjugate) roots ⁠    β   {\displaystyle \beta }  ⁠ and ⁠    γ   {\displaystyle \gamma }  ⁠, the Perrin numbers can be computed with the [Binet formula](https://en.wikipedia.org/wiki/Lucas_sequence#Explicit_expressions)     P ( n ) =  α  n   +  β  n   +  γ  n   ,   {\displaystyle P(n)=\alpha ^{n}+\beta ^{n}+\gamma ^{n},}   which also holds for negative *n*.

The [polar form](https://en.wikipedia.org/wiki/Polar_coordinate_system) is     P ( n ) =  α  n   + 2 cos ⁡ ( n  θ )    α  − n     ,   {\displaystyle P(n)=\alpha ^{n}+2\cos(n\,\theta ){\sqrt {\alpha ^{-n}}},}   with     θ = arccos ⁡ ( −    α  3      /  2 ) .   {\displaystyle \theta =\arccos(-{\sqrt {\alpha ^{3}}}/2).}   Since      lim  n → ∞    α  − n   = 0 ,   {\displaystyle \lim _{n\to \infty }\alpha ^{-n}=0,}   the formula reduces to either the first or the second term successively for large positive or negative *n*, and numbers with negative subscripts oscillate. Provided *α* is computed to sufficient precision, these formulas can be used to calculate Perrin numbers for large *n*.

Prime index *p* divides *P(p)*

# Prime index *p* divides *P(p)*

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=5)]

If the characteristic equation of the sequence is written as     f ( x ) =  x  3   −  σ  1    x  2   +  σ  2   x −  σ  3     {\displaystyle f(x)=x^{3}-\sigma _{1}x^{2}+\sigma _{2}x-\sigma _{3}}   then the coefficients ⁠     σ  k     {\displaystyle \sigma _{k}}  ⁠ can be expressed in terms of roots     α , β , γ   {\displaystyle \alpha ,\beta ,\gamma }   with [Vieta's formulas](https://en.wikipedia.org/wiki/Vieta's_formulas):

          σ  1      = α + β + γ     = 0      σ  2      = α β + α γ + β γ     = − 1      σ  3      = α β γ     = 1.       {\displaystyle {\begin{alignedat}{3}\sigma _{1}&=\alpha +\beta +\gamma &&=0\\\sigma _{2}&=\alpha \beta +\alpha \gamma +\beta \gamma &&=-1\\\sigma _{3}&=\alpha \beta \gamma &&=1.\end{alignedat}}}

These integer valued functions are the [elementary symmetric polynomials](https://en.wikipedia.org/wiki/Elementary_symmetric_polynomials) in     α , β , γ .   {\displaystyle \alpha ,\beta ,\gamma .}

- The [fundamental theorem on symmetric polynomials](https://en.wikipedia.org/wiki/Symmetric_polynomial#Relation_with_the_roots_of_a_monic_univariate_polynomial) states that every symmetric polynomial in the complex roots of monic ⁠    f   {\displaystyle f}  ⁠ can be represented as another polynomial function in the integer coefficients of ⁠    f .   {\displaystyle f.}  ⁠
- The analogue of [Lucas's theorem](https://en.wikipedia.org/wiki/Lucas's_theorem) for [multinomial coefficients](https://en.wikipedia.org/wiki/Multinomial_theorem)        p !   i ! j ! k !      {\displaystyle {\frac {p!}{i!j!k!}}}   says that if ⁠    i , j , k < p   {\displaystyle i,j,k<p}  ⁠ then        (   p  i , j , k    )      {\displaystyle {\binom {p}{i,j,k}}}   is divisible by prime ⁠    p .   {\displaystyle p.}  ⁠

Given integers ⁠    a , b , c   {\displaystyle a,b,c}  ⁠ and ⁠    n > 0 ,   {\displaystyle n>0,}  ⁠

     ( a + b + c  )  n   =  ∑  i + j + k = n      (   n  i , j , k    )     a  i    b  j    c  k   .   {\displaystyle (a+b+c)^{n}=\sum _{i+j+k=n}{\binom {n}{i,j,k}}a^{i}b^{j}c^{k}.}

Rearrange into symmetric [monomial](https://en.wikipedia.org/wiki/Monomial) summands, [permuting](https://en.wikipedia.org/wiki/Permutation) exponents i, j, k:

     ( a + b + c  )  n   − (  a  n   +  b  n   +  c  n   ) =   {\displaystyle (a+b+c)^{n}-(a^{n}+b^{n}+c^{n})=}        ∑     i ≤ j ≤ k    < n     i + j + k    = n         (   n  i , j , k    )     ∑  π ( i , j , k )    a  i    b  j    c  k   .   {\displaystyle \sum _{\begin{aligned}i\leq j\leq k&<n\\i+j+k&=n\end{aligned}}{\binom {n}{i,j,k}}\sum _{\pi (i,j,k)}a^{i}b^{j}c^{k}.}

Substitute prime ⁠    p   {\displaystyle p}  ⁠ for power ⁠    n   {\displaystyle n}  ⁠ and complex roots     α , β , γ   {\displaystyle \alpha ,\beta ,\gamma }   for integers ⁠    a , b , c   {\displaystyle a,b,c}  ⁠ and compute representations in terms of      σ  1   ,  σ  2   ,  σ  3     {\displaystyle \sigma _{1},\sigma _{2},\sigma _{3}}   for all symmetric polynomial functions. For example,     ( α + β + γ  )  p     {\displaystyle (\alpha +\beta +\gamma )^{p}}   is      σ  1   p   = 0   {\displaystyle \sigma _{1}^{p}=0}   and the [power sum](https://en.wikipedia.org/wiki/Power_sum_symmetric_polynomial)      α  p   +  β  p   +  γ  p   = P ( p )   {\displaystyle \alpha ^{p}+\beta ^{p}+\gamma ^{p}=P(p)}   can be expressed in the coefficients ⁠     σ  k     {\displaystyle \sigma _{k}}  ⁠ with [Newton's recursive scheme](https://en.wikipedia.org/wiki/Newton's_identities). It follows that the identity has integer terms and both sides divisible by prime ⁠    p .   {\displaystyle p.}  ⁠

To show that prime ⁠    p   {\displaystyle p}  ⁠ divides ⁠    P ( − p ) + 1   {\displaystyle P(-p)+1}  ⁠ in the reverse sequence, the characteristic equation has to be [reflected](https://en.wikipedia.org/wiki/Reciprocal_polynomial). The roots are then      α  − 1   ,  β  − 1   ,  γ  − 1   ,   {\displaystyle \alpha ^{-1},\beta ^{-1},\gamma ^{-1},}   the coefficients      σ  1   = − 1 ,  σ  2   = 0 ,  σ  3   = 1 ,   {\displaystyle \sigma _{1}=-1,\sigma _{2}=0,\sigma _{3}=1,}   and the same reasoning applies.

Perrin primality test

# Perrin primality test

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=6)]

>
> Query 1484.  The curious proposition of Chinese origin which is the subject of query 1401[10] would provide, if it is true, a more practical criterium than Wilson's theorem for verifying whether a given number m is prime or not; it would suffice to calculate the residues with respect to m of successive terms of the recurrence sequence un = 3un−1 − 2un−2 with initial values u0 =−1, u1 = 0.[11]
> I have found another recurrence sequence that seems to possess the same property; it is the one whose general term is vn = vn−2 + vn−3 with initial values v0 = 3, v1 = 0, v2 = 2. It is easy to demonstrate that vn  is divisible by n, if n is prime; I have verified, up to fairly high values of n, that in the opposite case it is not; but it would be interesting to know if this is really so, especially since the sequence vn  gives much less rapidly increasing numbers than the sequence un  (for n = 17, for example, one finds un = 131070, vn = 119), which leads to simpler calculations when n is a large number.
> The same proof, applicable to one of the sequences, will undoubtedly bear upon the other, if the stated property is true for both: it is only a matter of discovering it.[12]
>

The Perrin sequence has the [Fermat property](https://en.wikipedia.org/wiki/Fermat's_little_theorem): if ⁠    p   {\displaystyle p}  ⁠ is [prime](https://en.wikipedia.org/wiki/Prime_number),     P ( p ) ≡ P ( 1 ) ≡ 0   ( mod  p )  .   {\textstyle P(p)\equiv P(1)\equiv 0{\pmod {p}}.}   However, the [converse](https://en.wikipedia.org/wiki/Converse_(logic)) is not true: some [composite](https://en.wikipedia.org/wiki/Composite_number) ⁠    n   {\displaystyle n}  ⁠ may still divide ⁠    P ( n ) .   {\displaystyle P(n).}  ⁠ A number with this property is called a Perrin [pseudoprime](https://en.wikipedia.org/wiki/Pseudoprime).

The question of the existence of Perrin pseudoprimes was considered by Malo and Jarden,[[13]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-13) but none were known until Adams and Shanks found the smallest one,     271441 =  521  2     {\displaystyle 271441=521^{2}}   (the number P(271441) has 33150 decimal digits).[[14]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-14) Jon Grantham later proved that there are infinitely many Perrin pseudoprimes.[[15]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-15)

The seventeen Perrin pseudoprimes below 109 are
 271441, 904631, 16532714, 24658561, 27422714, 27664033, 46672291, 102690901, 130944133, 196075949, 214038533, 517697641, 545670533, 801123451, 855073301, 903136901, 970355431.[[16]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-16)

Adams and Shanks noted that primes also satisfy the congruence     P ( − p ) ≡ P ( − 1 ) ≡ − 1   ( mod  p )  .   {\textstyle P(-p)\equiv P(-1)\equiv -1{\pmod {p}}.}   Composites for which both properties hold are called restricted Perrin pseudoprimes. There are only nine such numbers below 109.[[17]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-17)[[18]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-18)[[19]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-19)

While Perrin pseudoprimes are rare, they overlap with [Fermat pseudoprimes](https://en.wikipedia.org/wiki/Fermat_pseudoprime). Of the above seventeen numbers, four are base 2 Fermatians as well. In contrast, the [Lucas pseudoprimes](https://en.wikipedia.org/wiki/Lucas_pseudoprime) are anti-correlated.[[20]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-20) Presumably, combining the Perrin and Lucas tests should make a [primality test](https://en.wikipedia.org/wiki/Primality_test) as strong as the reliable [BPSW test](https://en.wikipedia.org/wiki/Baillie%E2%80%93PSW_primality_test) which has no known pseudoprimes – though at higher computational cost.

Pseudocode

# Pseudocode

[[edit](https://en.wikipedia.org/w/index.php?title=Perrin_number&action=edit&section=7)]

The 1982 Adams and Shanks     O ( log ⁡ n )   {\displaystyle O(\log n)}   Perrin primality test.[[21]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-21)

Two integer arrays u(3) and v(3) are initialized to the lowest terms of the Perrin sequence, with positive indices t = 0, 1, 2 in u( ) and negative indices t = 0,−1,−2 in v( ).

The main [double-and-add](https://en.wikipedia.org/wiki/Addition_chain#Methods_for_computing_addition_chains) loop, originally devised to run on an [HP-41C](https://en.wikipedia.org/wiki/HP-41C) pocket calculator, computes P(n) mod n and the reverse P(−n) mod n at the cost of six modular squarings for each bit of n.

The subscripts of the Perrin numbers are doubled using the identity P(2t) = P2(t) − 2P(−t). The resulting gaps between P(±2t) and P(±2t ± 2) are closed by applying the defining relation P(t) = P(t − 2) + P(t − 3).

```
Initial values
let int u(0):= 3, u(1):= 0, u(2):= 2
let int v(0):= 3, v(1):=−1, v(2):= 1

Test odd positive number n
input int n

set int h:= most significant bit of n

for k:= h − 1 downto 0

  Double the indices of
  the six Perrin numbers.
  for i = 0, 1, 2
    temp:= u(i)^2 − 2v(i) (mod n)
    v(i):= v(i)^2 − 2u(i) (mod n)
    u(i):= temp
  endfor

  Copy P(2t + 2) and P(−2t − 2)
  to the array ends and use
  in the if-statement below.
  u(3):= u(2)
  v(3):= v(2)

  Overwrite P(2t ± 2) with P(2t ± 1)
  temp:= u(2) − u(1)
  u(2):= u(0) + temp
  u(0):= temp

  Overwrite P(−2t ± 2) with P(−2t ± 1)
  temp:= v(0) − v(1)
  v(0):= v(2) + temp
  v(2):= temp

  if n has bit k set then
    Increase the indices of
    both Perrin triples by 1.
    for i = 0, 1, 2
      u(i):= u(i + 1)
      v(i):= v(i + 1)
    endfor
  endif

endfor

Result
print v(2), v(1), v(0)
print u(0), u(1), u(2)
```

Successively P(−n − 1), P(−n), P(−n + 1) and P(n − 1), P(n), P(n + 1) (mod n).

If P(−n) = −1 and P(n) = 0 then *n* is a [probable prime](https://en.wikipedia.org/wiki/Probable_prime), that is: actually prime or a restricted Perrin pseudoprime.

Shanks *et al.* observed that for all restricted pseudoprimes they found, the final state of the above six registers (the "signature" of *n*) equals the initial state 1,−1,3, 3,0,2.[[22]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-22) The same occurs with ≈ 1**/**6 of all primes, so the two sets cannot be distinguished on the strength of this test alone.[[23]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-23) For those cases, they recommend to also use the [Narayana-Lucas sister sequence](https://en.wikipedia.org/wiki/Supergolden_ratio#Narayana_sequence) with recurrence relation A(n) = A(n − 1) + A(n − 3) and initial values

```
u(0):= 3, u(1):= 1, u(2):= 1
v(0):= 3, v(1):= 0, v(2):=−2
```

The same doubling rule applies and the formulas for filling the gaps are

```
temp:= u(0) + u(1)
u(0):= u(2) − temp
u(2):= temp

temp:= v(2) + v(1)
v(2):= v(0) − temp
v(0):= temp
```

Here, *n* is a probable prime if A(−n) = 0 and A(n) = 1.

Kurtz *et al.* found no overlap between the odd pseudoprimes for the two sequences below 50∙109 and supposed that 2,277,740,968,903 = 1067179 ∙ 2134357 is the smallest composite number to pass both tests.[[24]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-24)

If the [third-order Pell-Lucas recurrence](https://en.wikipedia.org/wiki/Supersilver_ratio#Third-order_Pell_sequences) A(n) = 2A(n − 1) + A(n − 3) is used as well, this bound will be pushed up to 4,057,052,731,496,380,171 = 1424263447 ∙ 2848526893.[[25]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-25)

Additionally, roots of the doubling rule-congruence      x  2   − 2 x ≡ 3 = P ( 0 )   ( mod  n )     {\displaystyle x^{2}-2x\equiv 3=P(0){\pmod {n}}\,}   other than −1 or 3 expose composite numbers, like non-trivial square roots of 1 in the [Miller-Rabin test](https://en.wikipedia.org/wiki/Miller%E2%80%93Rabin_primality_test).[[26]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-26) This reduces the number of restricted pseudoprimes for each sequence by roughly one-third and is especially efficient in detecting [Carmichael numbers](https://en.wikipedia.org/wiki/Carmichael_number).[[27]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-27)

The least strong restricted Perrin pseudoprime is 46672291 and the above two bounds expand to successively 173,536,465,910,671 and 79,720,990,309,209,574,421.[[28]](https://en.wikipedia.org/wiki/Perrin_number#cite_note-28)
