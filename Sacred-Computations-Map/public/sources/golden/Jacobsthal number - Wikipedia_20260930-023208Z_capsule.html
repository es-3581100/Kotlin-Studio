In [mathematics](https://en.wikipedia.org/wiki/Mathematics), the **Jacobsthal numbers** are an [integer sequence](https://en.wikipedia.org/wiki/Integer_sequence) named after the [German](https://en.wikipedia.org/wiki/Germany) mathematician [Ernst Jacobsthal](https://en.wikipedia.org/wiki/Ernst_Jacobsthal). Like the related [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number), they are a specific type of [Lucas sequence](https://en.wikipedia.org/wiki/Lucas_sequence)      U  n   ( P , Q )   {\displaystyle U_{n}(P,Q)}   for which *P* = 1, and *Q* = −2[[1]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-mathworld-1)—and are defined by a similar [recurrence relation](https://en.wikipedia.org/wiki/Recurrence_relation): in simple terms, the sequence starts with 0 and 1, then each following number is found by adding the number before it to twice the number before that. The first Jacobsthal numbers are:

 [0](https://en.wikipedia.org/wiki/0_(number)), [1](https://en.wikipedia.org/wiki/1_(number)), 1, [3](https://en.wikipedia.org/wiki/3_(number)), [5](https://en.wikipedia.org/wiki/5_(number)), [11](https://en.wikipedia.org/wiki/11_(number)), [21](https://en.wikipedia.org/wiki/21_(number)), [43](https://en.wikipedia.org/wiki/43_(number)), [85](https://en.wikipedia.org/wiki/85_(number)), [171](https://en.wikipedia.org/wiki/171_(number)), 341, 683, 1365, 2731, 5461, 10923, 21845, 43691, 87381, 174763, 349525, … (sequence [A001045](https://oeis.org/A001045) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences))

A **Jacobsthal prime** is a **Jacobsthal number** that is also [prime](https://en.wikipedia.org/wiki/Prime_number). The first Jacobsthal primes are:

 3, 5, 11, 43, 683, 2731, 43691, 174763, 2796203, 715827883, 2932031007403, 768614336404564651, 201487636602438195784363, 845100400152152934331135470251, 56713727820156410577229101238628035243, … (sequence [A049883](https://oeis.org/A049883) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences))

## Jacobsthal numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Jacobsthal_number&action=edit&section=1)]

Jacobsthal numbers are defined by the recurrence relation:

      J  n   =   {    0     if    n = 0 ;     1     if    n = 1 ;      J  n − 1   + 2  J  n − 2       if    n > 1.         {\displaystyle J_{n}={\begin{cases}0&{\mbox{if }}n=0;\\1&{\mbox{if }}n=1;\\J_{n-1}+2J_{n-2}&{\mbox{if }}n>1.\\\end{cases}}}

The next Jacobsthal number is also given by the recursion formula

      J  n + 1   = 2  J  n   + ( − 1  )  n   ,   {\displaystyle J_{n+1}=2J_{n}+(-1)^{n},}

or by

      J  n + 1   =  2  n   −  J  n   .   {\displaystyle J_{n+1}=2^{n}-J_{n}.}

The second recursion formula above is also satisfied by the [powers of 2](https://en.wikipedia.org/wiki/Powers_of_2).

The Jacobsthal number at a specific point in the sequence may be calculated directly using the closed-form equation:[[2]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-oeis_jl-2)

      J  n   =     2  n   − ( − 1  )  n    3   .   {\displaystyle J_{n}={\frac {2^{n}-(-1)^{n}}{3}}.}

The [generating function](https://en.wikipedia.org/wiki/Generating_function) for the Jacobsthal numbers is

       x  ( 1 + x ) ( 1 − 2 x )    .   {\displaystyle {\frac {x}{(1+x)(1-2x)}}.}

The sum of the [reciprocals](https://en.wikipedia.org/wiki/Multiplicative_inverse) of the Jacobsthal numbers is approximately 2.7186, slightly larger than [e](https://en.wikipedia.org/wiki/E_(mathematical_constant)).

The Jacobsthal numbers can be extended to negative indices using the recurrence relation or the explicit formula, giving

      J  − n   = ( − 1  )  n + 1    J  n    /   2  n     {\displaystyle J_{-n}=(-1)^{n+1}J_{n}/2^{n}}   (see [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A077925](https://oeis.org/A077925))

The following identities holds

      2  n   (  J  − n   +  J  n   ) = 3  J  n   2     {\displaystyle 2^{n}(J_{-n}+J_{n})=3J_{n}^{2}}   (see [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A139818](https://oeis.org/A139818))      J  n   =  F  n   +  ∑  i = 0   n − 2    J  i    F  n − i − 1     {\displaystyle J_{n}=F_{n}+\sum _{i=0}^{n-2}J_{i}F_{n-i-1}}   where      F  n     {\displaystyle F_{n}}   is the *nth* Fibonacci number.

## Jacobsthal–Lucas numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Jacobsthal_number&action=edit&section=2)]

Jacobsthal–Lucas numbers represent the complementary Lucas sequence      V  n   ( 1 , − 2 )   {\displaystyle V_{n}(1,-2)}  . They satisfy the same recurrence relation as Jacobsthal numbers but have different initial values:

      j  n   =   {    2     if    n = 0 ;     1     if    n = 1 ;      j  n − 1   + 2  j  n − 2       if    n > 1.         {\displaystyle j_{n}={\begin{cases}2&{\mbox{if }}n=0;\\1&{\mbox{if }}n=1;\\j_{n-1}+2j_{n-2}&{\mbox{if }}n>1.\\\end{cases}}}

The following Jacobsthal–Lucas number also satisfies:[[2]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-oeis_jl-2)

      j  n + 1   = 2  j  n   − 3 ( − 1  )  n   .    {\displaystyle j_{n+1}=2j_{n}-3(-1)^{n}.\,}

The Jacobsthal–Lucas number at a specific point in the sequence may be calculated directly using the closed-form equation:[[2]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-oeis_jl-2)

      j  n   =  2  n   + ( − 1  )  n   .    {\displaystyle j_{n}=2^{n}+(-1)^{n}.\,}

The first Jacobsthal–Lucas numbers are:

 [2](https://en.wikipedia.org/wiki/2_(number)), [1](https://en.wikipedia.org/wiki/1_(number)), [5](https://en.wikipedia.org/wiki/5_(number)), [7](https://en.wikipedia.org/wiki/7_(number)), [17](https://en.wikipedia.org/wiki/17_(number)), [31](https://en.wikipedia.org/wiki/31_(number)), [65](https://en.wikipedia.org/wiki/65_(number)), [127](https://en.wikipedia.org/wiki/127_(number)), [257](https://en.wikipedia.org/wiki/257_(number)), [511](https://en.wikipedia.org/wiki/511_(number)), 1025, 2047, 4097, [8191](https://en.wikipedia.org/wiki/8191_(number)), 16385, 32767, [65537](https://en.wikipedia.org/wiki/65,537), 131071, 262145, 524287, 1048577, … (sequence [A014551](https://oeis.org/A014551) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)).

In [mathematics](https://en.wikipedia.org/wiki/Mathematics), the **Jacobsthal numbers** are an [integer sequence](https://en.wikipedia.org/wiki/Integer_sequence) named after the [German](https://en.wikipedia.org/wiki/Germany) mathematician [Ernst Jacobsthal](https://en.wikipedia.org/wiki/Ernst_Jacobsthal). Like the related [Fibonacci numbers](https://en.wikipedia.org/wiki/Fibonacci_number), they are a specific type of [Lucas sequence](https://en.wikipedia.org/wiki/Lucas_sequence)      U  n   ( P , Q )   {\displaystyle U_{n}(P,Q)}   for which *P* = 1, and *Q* = −2[[1]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-mathworld-1)—and are defined by a similar [recurrence relation](https://en.wikipedia.org/wiki/Recurrence_relation): in simple terms, the sequence starts with 0 and 1, then each following number is found by adding the number before it to twice the number before that. The first Jacobsthal numbers are:

 [0](https://en.wikipedia.org/wiki/0_(number)), [1](https://en.wikipedia.org/wiki/1_(number)), 1, [3](https://en.wikipedia.org/wiki/3_(number)), [5](https://en.wikipedia.org/wiki/5_(number)), [11](https://en.wikipedia.org/wiki/11_(number)), [21](https://en.wikipedia.org/wiki/21_(number)), [43](https://en.wikipedia.org/wiki/43_(number)), [85](https://en.wikipedia.org/wiki/85_(number)), [171](https://en.wikipedia.org/wiki/171_(number)), 341, 683, 1365, 2731, 5461, 10923, 21845, 43691, 87381, 174763, 349525, … (sequence [A001045](https://oeis.org/A001045) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences))

A **Jacobsthal prime** is a **Jacobsthal number** that is also [prime](https://en.wikipedia.org/wiki/Prime_number). The first Jacobsthal primes are:

 3, 5, 11, 43, 683, 2731, 43691, 174763, 2796203, 715827883, 2932031007403, 768614336404564651, 201487636602438195784363, 845100400152152934331135470251, 56713727820156410577229101238628035243, … (sequence [A049883](https://oeis.org/A049883) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences))

Jacobsthal numbers

# Jacobsthal numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Jacobsthal_number&action=edit&section=1)]

Jacobsthal numbers are defined by the recurrence relation:

      J  n   =   {    0     if    n = 0 ;     1     if    n = 1 ;      J  n − 1   + 2  J  n − 2       if    n > 1.         {\displaystyle J_{n}={\begin{cases}0&{\mbox{if }}n=0;\\1&{\mbox{if }}n=1;\\J_{n-1}+2J_{n-2}&{\mbox{if }}n>1.\\\end{cases}}}

The next Jacobsthal number is also given by the recursion formula

      J  n + 1   = 2  J  n   + ( − 1  )  n   ,   {\displaystyle J_{n+1}=2J_{n}+(-1)^{n},}

or by

      J  n + 1   =  2  n   −  J  n   .   {\displaystyle J_{n+1}=2^{n}-J_{n}.}

The second recursion formula above is also satisfied by the [powers of 2](https://en.wikipedia.org/wiki/Powers_of_2).

The Jacobsthal number at a specific point in the sequence may be calculated directly using the closed-form equation:[[2]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-oeis_jl-2)

      J  n   =     2  n   − ( − 1  )  n    3   .   {\displaystyle J_{n}={\frac {2^{n}-(-1)^{n}}{3}}.}

The [generating function](https://en.wikipedia.org/wiki/Generating_function) for the Jacobsthal numbers is

       x  ( 1 + x ) ( 1 − 2 x )    .   {\displaystyle {\frac {x}{(1+x)(1-2x)}}.}

The sum of the [reciprocals](https://en.wikipedia.org/wiki/Multiplicative_inverse) of the Jacobsthal numbers is approximately 2.7186, slightly larger than [e](https://en.wikipedia.org/wiki/E_(mathematical_constant)).

The Jacobsthal numbers can be extended to negative indices using the recurrence relation or the explicit formula, giving

      J  − n   = ( − 1  )  n + 1    J  n    /   2  n     {\displaystyle J_{-n}=(-1)^{n+1}J_{n}/2^{n}}   (see [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A077925](https://oeis.org/A077925))

The following identities holds

      2  n   (  J  − n   +  J  n   ) = 3  J  n   2     {\displaystyle 2^{n}(J_{-n}+J_{n})=3J_{n}^{2}}   (see [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences): [A139818](https://oeis.org/A139818))      J  n   =  F  n   +  ∑  i = 0   n − 2    J  i    F  n − i − 1     {\displaystyle J_{n}=F_{n}+\sum _{i=0}^{n-2}J_{i}F_{n-i-1}}   where      F  n     {\displaystyle F_{n}}   is the *nth* Fibonacci number.

Jacobsthal–Lucas numbers

# Jacobsthal–Lucas numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Jacobsthal_number&action=edit&section=2)]

Jacobsthal–Lucas numbers represent the complementary Lucas sequence      V  n   ( 1 , − 2 )   {\displaystyle V_{n}(1,-2)}  . They satisfy the same recurrence relation as Jacobsthal numbers but have different initial values:

      j  n   =   {    2     if    n = 0 ;     1     if    n = 1 ;      j  n − 1   + 2  j  n − 2       if    n > 1.         {\displaystyle j_{n}={\begin{cases}2&{\mbox{if }}n=0;\\1&{\mbox{if }}n=1;\\j_{n-1}+2j_{n-2}&{\mbox{if }}n>1.\\\end{cases}}}

The following Jacobsthal–Lucas number also satisfies:[[2]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-oeis_jl-2)

      j  n + 1   = 2  j  n   − 3 ( − 1  )  n   .    {\displaystyle j_{n+1}=2j_{n}-3(-1)^{n}.\,}

The Jacobsthal–Lucas number at a specific point in the sequence may be calculated directly using the closed-form equation:[[2]](https://en.wikipedia.org/wiki/Jacobsthal_number#cite_note-oeis_jl-2)

      j  n   =  2  n   + ( − 1  )  n   .    {\displaystyle j_{n}=2^{n}+(-1)^{n}.\,}

The first Jacobsthal–Lucas numbers are:

 [2](https://en.wikipedia.org/wiki/2_(number)), [1](https://en.wikipedia.org/wiki/1_(number)), [5](https://en.wikipedia.org/wiki/5_(number)), [7](https://en.wikipedia.org/wiki/7_(number)), [17](https://en.wikipedia.org/wiki/17_(number)), [31](https://en.wikipedia.org/wiki/31_(number)), [65](https://en.wikipedia.org/wiki/65_(number)), [127](https://en.wikipedia.org/wiki/127_(number)), [257](https://en.wikipedia.org/wiki/257_(number)), [511](https://en.wikipedia.org/wiki/511_(number)), 1025, 2047, 4097, [8191](https://en.wikipedia.org/wiki/8191_(number)), 16385, 32767, [65537](https://en.wikipedia.org/wiki/65,537), 131071, 262145, 524287, 1048577, … (sequence [A014551](https://oeis.org/A014551) in the [OEIS](https://en.wikipedia.org/wiki/On-Line_Encyclopedia_of_Integer_Sequences)).
