# Source Code Inspection[¶](https://docs.sympy.org/dev/modules/utilities/source.html#module-sympy.utilities.source)

This module adds several functions for interactive source code inspection.

   sympy.utilities.source.get_class(*lookup_view*)[[source]](https://github.com/sympy/sympy/blob/2d283a82d15f2b46beff7be5399546c79613c445/sympy/utilities/source.py#L7-L22)[¶](https://docs.sympy.org/dev/modules/utilities/source.html#sympy.utilities.source.get_class)

Convert a string version of a class name to the object.

For example, get_class(‘sympy.core.Basic’) will return class Basic located in module sympy.core

    sympy.utilities.source.get_mod_func(*callback*)[[source]](https://github.com/sympy/sympy/blob/2d283a82d15f2b46beff7be5399546c79613c445/sympy/utilities/source.py#L25-L41)[¶](https://docs.sympy.org/dev/modules/utilities/source.html#sympy.utilities.source.get_mod_func)

splits the string path to a class into a string path to the module and the name of the class.

Examples

```
>>> from sympy.utilities.source import get_mod_func
>>> get_mod_func('sympy.core.basic.Basic')
('sympy.core.basic', 'Basic')
```
