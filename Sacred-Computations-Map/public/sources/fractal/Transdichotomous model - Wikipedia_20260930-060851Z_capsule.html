# Transdichotomous model

 [Add links](https://www.wikidata.org/wiki/Special:EntityPage/Q7833959#sitelinks-wikipedia)                          From Wikipedia, the free encyclopedia   Theoretical model of computation

In [computational complexity theory](https://en.wikipedia.org/wiki/Computational_complexity_theory), and more specifically in the [analysis of algorithms](https://en.wikipedia.org/wiki/Analysis_of_algorithms) with [integer](https://en.wikipedia.org/wiki/Integer) data, the **transdichotomous model** is a variation of the [random-access machine](https://en.wikipedia.org/wiki/Random-access_machine) in which the machine [word size](https://en.wikipedia.org/wiki/Word_size) is assumed to match the problem size. The model was proposed by [Michael Fredman](https://en.wikipedia.org/wiki/Michael_Fredman) and [Dan Willard](https://en.wikipedia.org/wiki/Dan_Willard),[[1]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-1) who chose its name "because the dichotomy between the machine model and the problem size is crossed in a reasonable manner."[[2]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-2)

In a problem such as [integer sorting](https://en.wikipedia.org/wiki/Integer_sorting) in which there are n integers to be sorted, the transdichotomous model assumes that each integer may be stored in a single word of computer memory, that operations on single words take constant time per operation, and that the number of bits that can be stored in a single word is at least log2*n*. The goal of complexity analysis in this model is to find time bounds that depend only on n and not on the actual size of the input values or the machine words.[[3]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-cp1-3)[[4]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-4) In modeling integer computation, it is necessary to assume that machine words are limited in size, because models with unlimited precision are unreasonably powerful (able to solve [PSPACE-complete](https://en.wikipedia.org/wiki/PSPACE-complete) problems in polynomial time).[[5]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-5) The transdichotomous model makes a minimal assumption of this type: that there is some limit, and that the limit is large enough to allow random-access indexing into the input data.[[3]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-cp1-3)

As well as its application to integer sorting, the transdichotomous model has also been applied to the design of [priority queues](https://en.wikipedia.org/wiki/Priority_queue)[[6]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-6) and to problems in [computational geometry](https://en.wikipedia.org/wiki/Computational_geometry)[[3]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-cp1-3) and [graph algorithms](https://en.wikipedia.org/wiki/Graph_algorithm).[[7]](https://en.wikipedia.org/wiki/Transdichotomous_model#cite_note-7)
