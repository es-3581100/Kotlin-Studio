**Fractint** (originally **FRACT386**) is a [freeware](https://en.wikipedia.org/wiki/Freeware) [computer program](https://en.wikipedia.org/wiki/Computer_program) to render and display many kinds of [fractals](https://en.wikipedia.org/wiki/Fractal). The program originated on [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS), then was ported to the [Atari ST](https://en.wikipedia.org/wiki/Atari_ST), [Linux](https://en.wikipedia.org/wiki/Linux), and [Macintosh](https://en.wikipedia.org/wiki/Mac_(computer)). During the early 1990s, Fractint was the definitive fractal generating program for personal computers.[[1]](https://en.wikipedia.org/wiki/Fractint#cite_note-1)

The name is a [portmanteau](https://en.wikipedia.org/wiki/Portmanteau) of *fractal* and *[integer](https://en.wikipedia.org/wiki/Integer)*, since the first versions of Fractint used only integer arithmetic (also known as [fixed-point arithmetic](https://en.wikipedia.org/wiki/Fixed-point_arithmetic)), for faster rendering on computers without math [coprocessors](https://en.wikipedia.org/wiki/Coprocessor). Since then, [floating-point arithmetic](https://en.wikipedia.org/wiki/Floating-point_arithmetic) and [arbitrary-precision arithmetic](https://en.wikipedia.org/wiki/Arbitrary-precision_arithmetic) modes have been added.

FractInt can draw most kinds of fractals that have appeared in the literature. It also has a few "fractal types" that are not strictly speaking fractals, but may be more accurately described as [display hacks](https://en.wikipedia.org/wiki/Display_hack). These include [cellular automata](https://en.wikipedia.org/wiki/Cellular_automaton).

## Development

[[edit](https://en.wikipedia.org/w/index.php?title=Fractint&action=edit&section=1)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/f/f4/Mandelbrot_palette_colour_editing_with_Fractint.png/250px-Mandelbrot_palette_colour_editing_with_Fractint.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Mandelbrot_palette_colour_editing_with_Fractint.png)A Mandelbrot fractal with Fractint's colour palette editor (version 20.0 in DOSBOX 0.72) [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/7/7c/Fract027.jpg/250px-Fract027.jpg?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Fract027.jpg)One portion of the Mandelbrot set at extreme magnification, showing how the set [contains near copies of itself](https://en.wikipedia.org/wiki/Self-similarity)

Fractint originally appeared in 1988 as FRACT386, a computer program for rendering fractals very quickly on the [Intel 80386](https://en.wikipedia.org/wiki/Intel_80386) processor using integer arithmetic. The 80386 requires the [Intel 80387](https://en.wikipedia.org/wiki/Intel_80387) coprocessor to natively support floating point math, which was rare in [IBM PC compatibles](https://en.wikipedia.org/wiki/IBM_PC_compatible).

Early versions of FRACT386 were written by Bert Tyler, who based it on a [Mandelbrot](https://en.wikipedia.org/wiki/Mandelbrot_set) generator for a TI-based processor that used integer math and decided to try programming something similar for his 386 machine.[[2]](https://en.wikipedia.org/wiki/Fractint#cite_note-FractalCreations-2)

In February 1989, the program was renamed Fractint. In July 1990, it was ported to the [Atari ST](https://en.wikipedia.org/wiki/Atari_ST), with the math routines rewritten in [Motorola 68000](https://en.wikipedia.org/wiki/Motorola_68000) assembly language by Howard Chu.[*[citation needed](https://en.wikipedia.org/wiki/Wikipedia:Citation_needed)*]

## Forks

[[edit](https://en.wikipedia.org/w/index.php?title=Fractint&action=edit&section=2)]

There are two notable forks of FRACTINT: ManPWin and Iterated Dynamics. [ManPWin](http://www.deleeuw.com.au/) is a fork based on WinFract 18 with [source code on github](https://github.com/PaulTheLionHeart/manpwin). [Iterated Dynamics](https://legalizeadulthood.github.io/iterated-dynamics/) is a fork based on FRACTINT 20.04 patch level 4, with [source code on github](https://github.com/LegalizeAdulthood/iterated-dynamics).

**Fractint** (originally **FRACT386**) is a [freeware](https://en.wikipedia.org/wiki/Freeware) [computer program](https://en.wikipedia.org/wiki/Computer_program) to render and display many kinds of [fractals](https://en.wikipedia.org/wiki/Fractal). The program originated on [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS), then was ported to the [Atari ST](https://en.wikipedia.org/wiki/Atari_ST), [Linux](https://en.wikipedia.org/wiki/Linux), and [Macintosh](https://en.wikipedia.org/wiki/Mac_(computer)). During the early 1990s, Fractint was the definitive fractal generating program for personal computers.[[1]](https://en.wikipedia.org/wiki/Fractint#cite_note-1)

The name is a [portmanteau](https://en.wikipedia.org/wiki/Portmanteau) of *fractal* and *[integer](https://en.wikipedia.org/wiki/Integer)*, since the first versions of Fractint used only integer arithmetic (also known as [fixed-point arithmetic](https://en.wikipedia.org/wiki/Fixed-point_arithmetic)), for faster rendering on computers without math [coprocessors](https://en.wikipedia.org/wiki/Coprocessor). Since then, [floating-point arithmetic](https://en.wikipedia.org/wiki/Floating-point_arithmetic) and [arbitrary-precision arithmetic](https://en.wikipedia.org/wiki/Arbitrary-precision_arithmetic) modes have been added.

FractInt can draw most kinds of fractals that have appeared in the literature. It also has a few "fractal types" that are not strictly speaking fractals, but may be more accurately described as [display hacks](https://en.wikipedia.org/wiki/Display_hack). These include [cellular automata](https://en.wikipedia.org/wiki/Cellular_automaton).

Development

# Development

[[edit](https://en.wikipedia.org/w/index.php?title=Fractint&action=edit&section=1)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/f/f4/Mandelbrot_palette_colour_editing_with_Fractint.png/250px-Mandelbrot_palette_colour_editing_with_Fractint.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Mandelbrot_palette_colour_editing_with_Fractint.png)A Mandelbrot fractal with Fractint's colour palette editor (version 20.0 in DOSBOX 0.72) [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/7/7c/Fract027.jpg/250px-Fract027.jpg?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Fract027.jpg)One portion of the Mandelbrot set at extreme magnification, showing how the set [contains near copies of itself](https://en.wikipedia.org/wiki/Self-similarity)

Fractint originally appeared in 1988 as FRACT386, a computer program for rendering fractals very quickly on the [Intel 80386](https://en.wikipedia.org/wiki/Intel_80386) processor using integer arithmetic. The 80386 requires the [Intel 80387](https://en.wikipedia.org/wiki/Intel_80387) coprocessor to natively support floating point math, which was rare in [IBM PC compatibles](https://en.wikipedia.org/wiki/IBM_PC_compatible).

Early versions of FRACT386 were written by Bert Tyler, who based it on a [Mandelbrot](https://en.wikipedia.org/wiki/Mandelbrot_set) generator for a TI-based processor that used integer math and decided to try programming something similar for his 386 machine.[[2]](https://en.wikipedia.org/wiki/Fractint#cite_note-FractalCreations-2)

In February 1989, the program was renamed Fractint. In July 1990, it was ported to the [Atari ST](https://en.wikipedia.org/wiki/Atari_ST), with the math routines rewritten in [Motorola 68000](https://en.wikipedia.org/wiki/Motorola_68000) assembly language by Howard Chu.[*[citation needed](https://en.wikipedia.org/wiki/Wikipedia:Citation_needed)*]

Forks

# Forks

[[edit](https://en.wikipedia.org/w/index.php?title=Fractint&action=edit&section=2)]

There are two notable forks of FRACTINT: ManPWin and Iterated Dynamics. [ManPWin](http://www.deleeuw.com.au/) is a fork based on WinFract 18 with [source code on github](https://github.com/PaulTheLionHeart/manpwin). [Iterated Dynamics](https://legalizeadulthood.github.io/iterated-dynamics/) is a fork based on FRACTINT 20.04 patch level 4, with [source code on github](https://github.com/LegalizeAdulthood/iterated-dynamics).
