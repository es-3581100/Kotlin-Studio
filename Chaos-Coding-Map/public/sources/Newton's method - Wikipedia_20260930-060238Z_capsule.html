 [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/8/83/Methode_newton.png/250px-Methode_newton.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Methode_newton.png)An illustration of Newton's method

In [numerical analysis](https://en.wikipedia.org/wiki/Numerical_analysis), the **Newton–Raphson method**, also kown simply as **Newton's method**, named after [Isaac Newton](https://en.wikipedia.org/wiki/Isaac_Newton) and [Joseph Raphson](https://en.wikipedia.org/wiki/Joseph_Raphson), is a [root-finding algorithm](https://en.wikipedia.org/wiki/Root-finding_algorithm) which produces successively better [approximations](https://en.wikipedia.org/wiki/Numerical_analysis) to the [roots](https://en.wikipedia.org/wiki/Root_of_a_function) (or zeroes) of a [real](https://en.wikipedia.org/wiki/Real_number)-valued [function](https://en.wikipedia.org/wiki/Function_(mathematics)). The most basic version starts with a [real-valued function](https://en.wikipedia.org/wiki/Real-valued_function) f, its [derivative](https://en.wikipedia.org/wiki/Derivative) f′, and an initial guess x0 for a [root](https://en.wikipedia.org/wiki/Zero_of_a_function) of f. If f satisfies certain assumptions and the initial guess is close, then

x  1   =  x  0   −    f (  x  0   )    f ′  (  x  0   )      {\displaystyle x_{1}=x_{0}-{\frac {f(x_{0})}{f'(x_{0})}}}

is a better approximation of the root than x0. Geometrically, (x1, 0) is the [x-intercept](https://en.wikipedia.org/wiki/X-intercept) of the [tangent](https://en.wikipedia.org/wiki/Tangent) to the [graph](https://en.wikipedia.org/wiki/Graph_of_a_function) of f at (x0, f(x0)): that is, the improved guess, x1, is the unique root of the [linear approximation](https://en.wikipedia.org/wiki/Linear_approximation) of f at the initial guess, x0. The process is repeated as

x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )      {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}}

until a sufficiently precise value is reached. The number of correct digits roughly doubles with each step. This algorithm is first in the class of [Householder's methods](https://en.wikipedia.org/wiki/Householder's_method), and was succeeded by [Halley's method](https://en.wikipedia.org/wiki/Halley's_method). The method can also be extended to [complex functions](https://en.wikipedia.org/wiki/Complex-valued_function) and to [systems of equations](https://en.wikipedia.org/wiki/Systems_of_equations).

## Description

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=1)]

The purpose of Newton's method is to find a root of a function. The idea is to start with an initial guess near a root, approximate the function by its [tangent line](https://en.wikipedia.org/wiki/Tangent_line) near the guess, and then take the root of the linear approximation as a next guess at the function's root. This will typically be closer to the function's root than the previous guess, and the method can be [iterated](https://en.wikipedia.org/wiki/Iterative_method).

 [![Illustration of Newton's method](https://thumb.wikimedia.org/wikipedia/commons/thumb/8/8c/Newton_iteration.svg/500px-Newton_iteration.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Newton_iteration.svg)xn+1 is a better approximation than xn for the root x of the function f (blue curve).

The best [linear approximation](https://en.wikipedia.org/wiki/Linear_approximation) to an arbitrary [differentiable function](https://en.wikipedia.org/wiki/Differentiable_function)     f ( x )   {\displaystyle f(x)}   near the point     x =  x  n     {\displaystyle x=x_{n}}   is the tangent line to the curve, with equation

f ( x ) ≈ f (  x  n   ) +  f ′  (  x  n   ) ( x −  x  n   ) .   {\displaystyle f(x)\approx f(x_{n})+f'(x_{n})(x-x_{n}).}

The root of this linear function, the place where it intercepts the ⁠    x   {\displaystyle x}  ⁠-axis, can be taken as a closer approximate root ⁠     x  n + 1     {\displaystyle x_{n+1}}  ⁠ if      f ′  (  x  n   ) ≠ 0   {\displaystyle f'(x_{n})\neq 0}  :

x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}.}

 [![Illustration of Newton's method](https://thumb.wikimedia.org/wikipedia/commons/thumb/e/e0/NewtonIteration_Ani.gif/500px-NewtonIteration_Ani.gif?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:NewtonIteration_Ani.gif)Iteration typically improves the approximation.

The process can be started with any arbitrary initial guess ⁠     x  0     {\displaystyle x_{0}}  ⁠, though it will generally require fewer iterations to converge if the guess is close to one of the function's roots. The method will usually converge if ⁠     f ′  (  x  0   ) ≠ 0   {\displaystyle f'(x_{0})\neq 0}  ⁠. Furthermore, for a root of [multiplicity](https://en.wikipedia.org/wiki/Multiplicity_(mathematics)) 1, the convergence is at least quadratic (see *[Rate of convergence](https://en.wikipedia.org/wiki/Rate_of_convergence)*) in some sufficiently small [neighbourhood](https://en.wikipedia.org/wiki/Neighbourhood_(mathematics)) of the root: the number of correct digits of the approximation roughly doubles with each additional step. More details can be found in *[§ Analysis](https://en.wikipedia.org/wiki/Newton's_method#Analysis)* below.

[Householder's methods](https://en.wikipedia.org/wiki/Householder's_method) are similar but have higher order for even faster convergence. However, the extra computations required for each step can slow down the overall performance relative to Newton's method, particularly if ⁠    f   {\displaystyle f}  ⁠ or its derivatives are computationally expensive to evaluate.

## History

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=2)]

In the [Old Babylonian](https://en.wikipedia.org/wiki/Babylonian_mathematics) period (19th–16th century BCE), the side of a square of known area could be effectively approximated, and this is conjectured to have been done using a special case of Newton's method, [described algebraically below](https://en.wikipedia.org/wiki/Newton's_method#Use_of_Newton's_method_to_compute_square_roots), by iteratively improving an initial estimate; an equivalent method can be found in [Hero of Alexandria](https://en.wikipedia.org/wiki/Hero_of_Alexandria)'s *Metrica* (1st–2nd century CE), so is often called *[Heron's method](https://en.wikipedia.org/wiki/Heron's_method)*.[[1]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-1) [Jamshīd al-Kāshī](https://en.wikipedia.org/wiki/Jamsh%C4%ABd_al-K%C4%81sh%C4%AB) used a method to solve xP − N = 0 to find roots of *N*, a method that was algebraically equivalent to Newton's method, and a similar method was found in *Trigonometria Britannica*, published by [Henry Briggs](https://en.wikipedia.org/wiki/Henry_Briggs_(mathematician)) in 1633.[[2]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:1-2) His method first appeared in his 1427 publication *Miftāḥ al-Ḥisāb* (*The Key to Arithmetic*). Al-Kāshī's work was founded on the earlier contributions of the polymath [al-Bīrūnī](https://en.wikipedia.org/wiki/Al-B%C4%ABr%C5%ABn%C4%AB) (973–1048) and the mathematician [Sharaf al-Dīn al-Ṭūsī](https://en.wikipedia.org/wiki/Sharaf_al-D%C4%ABn_al-%E1%B9%AC%C5%ABs%C4%AB) (1135–1213). The contributions of al-Kāshī remained largely unknown to the Western scientific community for centuries, until the work of [François Viète](https://en.wikipedia.org/wiki/Fran%C3%A7ois_Vi%C3%A8te) (1540–1603). In 1600, Viète rediscovered a technique similar to al-Kāshī's in the context of solving scalar polynomial equations of degree six.[[3]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-arxiv|2205.11033-3)

The method that laid the groundwork for what is now the modern Newton's method which would be developed by [Joseph Raphson](https://en.wikipedia.org/wiki/Joseph_Raphson) and [Thomas Simpson](https://en.wikipedia.org/wiki/Thomas_Simpson) first appeared in [Isaac Newton](https://en.wikipedia.org/wiki/Isaac_Newton)'s work in *[De analysi per aequationes numero terminorum infinitas](https://en.wikipedia.org/wiki/De_analysi_per_aequationes_numero_terminorum_infinitas)* (written in 1669, published in 1711 by [William Jones](https://en.wikipedia.org/wiki/William_Jones_(mathematician))) and in *De metodis fluxionum et serierum infinitarum* (written in 1671, translated and published as *[Method of Fluxions](https://en.wikipedia.org/wiki/Method_of_Fluxions)* in 1736 by [John Colson](https://en.wikipedia.org/wiki/John_Colson)).[[4]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:0-4)[[2]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:1-2)[[5]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-5) However, while Newton gave the basic ideas, his method differs from the modern method given above. He applied the method only to polynomials, starting with an initial root estimate and extracting a sequence of error corrections. He used each correction to rewrite the polynomial in terms of the remaining error, and then solved for a new correction by neglecting higher-degree terms. He did not explicitly connect the method with derivatives or present a general formula. Newton applied this method to both numerical and algebraic problems, producing [Taylor series](https://en.wikipedia.org/wiki/Taylor_series) in the latter case. Despite this, in the later second and third editions of Newton's 1687 *[Philosophiæ Naturalis Principia Mathematica](https://en.wikipedia.org/wiki/Philosophi%C3%A6_Naturalis_Principia_Mathematica)*, he did apply his method in an iterative manner to a nonpolynomial equation, specifically [Kepler's equation](https://en.wikipedia.org/wiki/Kepler's_equation), which were the first published uses of Newton's method in this form by him.[[2]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:1-2)

Newton may have derived his method from a similar, less precise method by mathematician Viète, however, the two methods are not the same.[[4]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:0-4) The essence of Viète's own method can be found in the work of the mathematician [Sharaf al-Din al-Tusi](https://en.wikipedia.org/wiki/Sharaf_al-Din_al-Tusi).[[6]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-6)

The Japanese mathematician [Seki Kōwa](https://en.wikipedia.org/wiki/Seki_K%C5%8Dwa) used a form of Newton's method in the 1680s to solve single-variable equations, though the connection with [calculus](https://en.wikipedia.org/wiki/Calculus) was missing.[[7]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-7)

Newton's method was first published in 1685 in *A Treatise of Algebra both Historical and Practical* by [John Wallis](https://en.wikipedia.org/wiki/John_Wallis).[[8]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-8) In 1690, Raphson published a simplified description in *Analysis aequationum universalis*.[[9]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-9) Raphson also applied the method only to polynomials, but he avoided Newton's tedious rewriting process by extracting each successive correction from the original polynomial. This allowed him to derive a reusable iterative expression for each problem. Finally, in 1740, Simpson described Newton's method as an iterative method for solving general nonlinear equations using calculus, essentially giving the description above. In the same publication, Simpson also gives the generalization to systems of two equations and notes that Newton's method can be used for solving optimization problems by setting the gradient to zero.

[Arthur Cayley](https://en.wikipedia.org/wiki/Arthur_Cayley) in 1879 in *The Newton–Fourier imaginary problem* was the first to notice the difficulties in generalizing Newton's method to complex roots of polynomials with degree greater than 2 and complex initial values. This opened the way to the study of the [theory of iterations](https://en.wikipedia.org/wiki/Julia_set) of rational functions.

## Practical considerations

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=3)]

Newton's method is a powerful technique—if the derivative of the function at the root is nonzero, then the [convergence](https://en.wikipedia.org/wiki/Rate_of_convergence) is at least quadratic: as the method converges on the root, the difference between the root and the approximation is squared (the number of accurate digits roughly doubles) at each step. However, there are some difficulties with the method.

### Difficulty in calculating the derivative of a function

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=4)]

Newton's method requires that the derivative can be calculated directly. An analytical expression for the derivative may not be easily obtainable or could be expensive to evaluate. In these situations, it may be appropriate to approximate the derivative by using the slope of a line through two nearby points on the function. Using this approximation would result in something like the [secant method](https://en.wikipedia.org/wiki/Secant_method) whose convergence is slower than that of Newton's method.

### Failure of the method to converge to the root

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=5)]

It is important to review the [proof of quadratic convergence](https://en.wikipedia.org/wiki/Newton's_method#Proof_of_quadratic_convergence_for_Newton's_iterative_method) of Newton's method before implementing it. Specifically, one should review the assumptions made in the proof. For situations where the method fails to converge, it is because the assumptions made in this proof are not met.

For example, [in some cases](https://en.wikipedia.org/wiki/Newton's_method#Divergence_even_when_initialization_is_close_to_the_root), if the first derivative is not well behaved in the neighborhood of a particular root, then it is possible that Newton's method will fail to converge no matter where the initialization is set. In some cases, Newton's method can be stabilized by using [successive over-relaxation](https://en.wikipedia.org/wiki/Successive_over-relaxation#Other_applications_of_the_method), or the speed of convergence can be increased by using the same method.

In a robust implementation of Newton's method, it is common to place limits on the number of iterations, bound the solution to an interval known to contain the root, and combine the method with a more robust root finding method.

### Slow convergence for roots of multiplicity greater than 1

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=6)]

If the root being sought has [multiplicity](https://en.wikipedia.org/wiki/Multiplicity_(mathematics)#Multiplicity_of_a_root_of_a_polynomial) greater than one, the convergence rate is merely linear (errors reduced by a constant factor at each step) unless special steps are taken. When there are two or more roots that are close together then it may take many iterations before the iterates get close enough to one of them for the quadratic convergence to be apparent. However, if the multiplicity m of the root is known, the following modified algorithm preserves the quadratic convergence rate:[[10]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-10)

x  n + 1   =  x  n   − m    f (  x  n   )    f ′  (  x  n   )    .   {\displaystyle x_{n+1}=x_{n}-m{\frac {f(x_{n})}{f'(x_{n})}}.}

This is equivalent to using [successive over-relaxation](https://en.wikipedia.org/wiki/Successive_over-relaxation#Other_applications_of_the_method). On the other hand, if the multiplicity m of the root is not known, it is possible to estimate m after carrying out one or two iterations, and then use that value to increase the rate of convergence.

If the multiplicity m of the root is finite then g(x) = ⁠f(x)/f′(x)⁠ will have a root at the same location with multiplicity 1. Applying Newton's method to find the root of g(x) recovers quadratic convergence in many cases although it generally involves the second derivative of f(x). In a particularly simple case, if f(x) = xm then g(x) = ⁠x/m⁠ and Newton's method finds the root in a single iteration with

x  n + 1   =  x  n   −    g (  x  n   )    g ′  (  x  n   )    =  x  n   −        x  n   m      1 m    = 0  .   {\displaystyle x_{n+1}=x_{n}-{\frac {g(x_{n})}{g'(x_{n})}}=x_{n}-{\frac {\;{\frac {x_{n}}{m}}\;}{\frac {1}{m}}}=0\,.}

### Slow convergence

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=7)]

The function *f*(*x*) = *x*2 has a root at 0.[[11]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-dennis-11) Since f is continuously differentiable at its root, the theory guarantees that Newton's method as initialized sufficiently close to the root will converge. However, since the derivative *f* ′ is zero at the root, quadratic convergence is not ensured by the theory. In this particular example, the Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =   1 2    x  n   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}={\frac {1}{2}}x_{n}.}

It is visible from this that Newton's method could be initialized anywhere and converge to zero, but at only a linear rate. If initialized at 1, dozens of iterations would be required before ten digits of accuracy are achieved.

The function *f*(*x*) = *x* + *x*4/3 also has a root at 0, where it is continuously differentiable. Although the first derivative *f* ′ is nonzero at the root, the second derivative *f* ′′ is nonexistent there, so that quadratic convergence cannot be guaranteed. In fact the Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =    x  n   4  /  3    3 + 4  x  n   1  /  3      ≈  x  n   ⋅    x  n   1  /  3   3   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}={\frac {x_{n}^{4/3}}{3+4x_{n}^{1/3}}}\approx x_{n}\cdot {\frac {x_{n}^{1/3}}{3}}.}

From this, it can be seen that the rate of convergence is superlinear but subquadratic. While the convergence on the left is superlinear, the order of magnitude is only multiplied by about 4/3 from row to row (0,1,2,4,5,7,10,13,...).

The rate of convergence is distinguished from the number of iterations required to reach a given accuracy. For example, the function *f*(*x*) = *x*20 − 1 has a root at 1. ### Convergence dependent on initialization

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=8)]

The function *f*(*x*) = *x*(1 + *x*2)−1/2 has a root at 0. The Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −     x  n   ( 1 +  x  n   2    )  − 1  /  2     ( 1 +  x  n   2    )  − 3  /  2      = −  x  n   3   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}(1+x_{n}^{2})^{-1/2}}{(1+x_{n}^{2})^{-3/2}}}=-x_{n}^{3}.}

From this, it can be seen that there are three possible phenomena for a Newton iteration. If initialized strictly between ±1, the Newton iteration will converge (super-)quadratically to 0; if initialized exactly at 1 or −1, the Newton iteration will oscillate endlessly between ±1; if initialized anywhere else, the Newton iteration will diverge.[[13]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-13) This same trichotomy occurs for *f*(*x*) = arctan *x*.[[11]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-dennis-11)

In cases where the function in question has multiple roots, it can be difficult to control, via choice of initialization, which root (if any) is identified by Newton's method. For example, the function *f*(*x*) = *x*(*x*2 − 1)(*x* − 3)e−(*x* − 1)2/2 has roots at −1, 0, 1, and 3.[[14]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-FOOTNOTES%C3%BCliMayers2003-14) If initialized at −1.488, the Newton iteration converges to 0; if initialized at −1.487, it diverges to ∞; if initialized at −1.486, it converges to −1; if initialized at −1.485, it diverges to −∞; if initialized at −1.4843, it converges to 3; if initialized at −1.484, it converges to 1. This kind of subtle dependence on initialization is not uncommon; it is frequently studied in the [complex plane](https://en.wikipedia.org/wiki/Complex_plane) in the form of the [Newton fractal](https://en.wikipedia.org/wiki/Newton_fractal).

### Divergence even when initialization is close to the root

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=9)]

Consider the problem of finding a root of *f*(*x*) = *x*1/3. The Newton iteration is

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −    x  n   1  /  3      1 3    x  n   − 2  /  3      = − 2  x  n   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}^{1/3}}{{\frac {1}{3}}x_{n}^{-2/3}}}=-2x_{n}.}

Unless Newton's method is initialized at the exact root 0, it is seen that the sequence of iterates will fail to converge. For example, even if initialized at the reasonably accurate guess of 0.001, the first several iterates are −0.002, 0.004, −0.008, 0.016, reaching 1048.58, −2097.15, ... by the 20th iterate. This failure of convergence is not contradicted by the analytic theory, since in this case f is not differentiable at its root.

In the above example, failure of convergence is reflected by the failure of *f*(*x**n*) to get closer to zero as n increases, as well as by the fact that successive iterates are growing further and further apart. However, the function *f*(*x*) = *x*1/3e−*x*2 also has a root at 0. The Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n    (  1 −   3  1 − 6  x  n   2       )  .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}\left(1-{\frac {3}{1-6x_{n}^{2}}}\right).}

In this example, where again f is not differentiable at the root, any Newton iteration not starting exactly at the root will diverge, but with both *x**n* + 1 − *x**n* and *f*(*x**n*) converging to zero.[[15]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-judd-15) This is seen in the following table showing the iterates with initialization 1:

  *x**n* *f*(*x**n*)  10.36788  1.69.0416 × 10−2  1.93422.9556 × 10−2  2.20481.0076 × 10−2  2.43963.5015 × 10−3  2.65051.2307 × 10−3  2.84374.3578 × 10−4  3.02321.5513 × 10−4

Although the convergence of *x**n* + 1 − *x**n* in this case is not very rapid, it can be proved from the iteration formula. This example highlights the possibility that a stopping criterion for Newton's method based only on the smallness of *x**n* + 1 − *x**n* and *f*(*x**n*) might falsely identify a root.

### Oscillatory behavior

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=10)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/f/f1/NewtonsMethodConvergenceFailure.svg/500px-NewtonsMethodConvergenceFailure.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:NewtonsMethodConvergenceFailure.svg)The tangent lines of x3 − 2x + 2 at 0 and 1 intersect the x-axis at 1 and 0 respectively, illustrating why Newton's method oscillates between these values for some starting points.

It is easy to find situations for which Newton's method oscillates endlessly between two distinct values. For example, for Newton's method as applied to a function f to oscillate between 0 and 1, it is only necessary that the tangent line to f at 0 intersects the x-axis at 1 and that the tangent line to f at 1 intersects the x-axis at 0.[[15]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-judd-15) This is the case, for example, if *f*(*x*) = *x*3 − 2*x* + 2. For this function, it is even the case that Newton's iteration as initialized sufficiently close to 0 or 1 will *asymptotically* oscillate between these values. For example, Newton's method as initialized at 0.99 yields iterates 0.99, −0.06317, 1.00628, 0.03651, 1.00196, 0.01162, 1.00020, 0.00120, 1.000002, and so on. This behavior is present despite the presence of a root of f approximately equal to −1.76929.

### Undefinedness of Newton's method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=11)]

In some cases, it is not even possible to perform the Newton iteration. For example, if *f*(*x*) = *x*2 − 1, then the Newton iteration is defined by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −     x  n   2   − 1   2  x  n      =     x  n   2   + 1   2  x  n      .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}^{2}-1}{2x_{n}}}={\frac {x_{n}^{2}+1}{2x_{n}}}.}

So Newton's method cannot be initialized at 0, since this would make *x*1 undefined. Geometrically, this is because the tangent line to f at 0 is horizontal (i.e. *f* ′(0) = 0), never intersecting the *x*-axis.

Even if the initialization is selected so that the Newton iteration can begin, the same phenomenon can block the iteration from being indefinitely continued.

If f has an incomplete domain, it is possible for Newton's method to send the iterates outside of the domain, so that it is impossible to continue the iteration.[[15]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-judd-15) For example, the [natural logarithm](https://en.wikipedia.org/wiki/Natural_logarithm) function *f*(*x*) = ln *x* has a root at 1, and is defined only for positive x. Newton's iteration in this case is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   ( 1 − ln ⁡  x  n   ) .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}(1-\ln x_{n}).}

So if the iteration is initialized at e, the next iterate is 0; if the iteration is initialized at a value larger than e, then the next iterate is negative. In either case, the method cannot be continued.

## Analysis

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=12)]

Suppose that the function f has a zero at α, i.e., f(α) = 0, and f is differentiable in a [neighborhood](https://en.wikipedia.org/wiki/Topological_neighborhood) of α.

If f is continuously differentiable and its derivative is nonzero at α, then there exists a [neighborhood](https://en.wikipedia.org/wiki/Topological_neighborhood) of α such that for all starting values x0 in that neighborhood, the [sequence](https://en.wikipedia.org/wiki/Sequence) (xn) will [converge](https://en.wikipedia.org/wiki/Limit_of_a_sequence) to α.[[16]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-16)

If f is continuously differentiable, its derivative is nonzero at α, *and* it has a [second derivative](https://en.wikipedia.org/wiki/Second_derivative) at α, then the convergence is quadratic or faster. If the second derivative is not 0 at α then the convergence is merely quadratic. If the third derivative exists and is bounded in a neighborhood of α, then:

Δ  x  i + 1   =     f ″  ( α )   2  f ′  ( α )      (  Δ  x  i    )   2   + O   (  Δ  x  i    )   3    ,   {\displaystyle \Delta x_{i+1}={\frac {f''(\alpha )}{2f'(\alpha )}}\left(\Delta x_{i}\right)^{2}+O\left(\Delta x_{i}\right)^{3}\,,}

where

Δ  x  i   ≜  x  i   − α  .   {\displaystyle \Delta x_{i}\triangleq x_{i}-\alpha \,.}

If the derivative is 0 at α, then the convergence is usually only linear. Specifically, if f is twice continuously differentiable, f′(α) = 0 and f″(α) ≠ 0, then there exists a neighborhood of α such that, for all starting values x0 in that neighborhood, the sequence of iterates converges linearly, with [rate](https://en.wikipedia.org/wiki/Rate_of_convergence) ⁠1/2⁠.[[17]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-17) Alternatively, if f′(α) = 0 and f′(x) ≠ 0 for x ≠ α, x in a [neighborhood](https://en.wikipedia.org/wiki/Topological_neighborhood) U of α, α being a zero of [multiplicity](https://en.wikipedia.org/wiki/Multiplicity_(mathematics)) r, and if f ∈ Cr(U), then there exists a neighborhood of α such that, for all starting values x0 in that neighborhood, the sequence of iterates converges linearly.

However, even linear convergence is not guaranteed in pathological situations.

In practice, these results are local, and the neighborhood of convergence is not known in advance. But there are also some results on global convergence: for instance, given a right neighborhood U+ of α, if f is twice differentiable in U+ and if f′ ≠ 0, f · f″ > 0 in U+, then, for each x0 in U+ the sequence xk is monotonically decreasing to α.

### Proof of quadratic convergence for Newton's iterative method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=13)]

According to [Taylor's theorem](https://en.wikipedia.org/wiki/Taylor's_theorem), any function f(x) which has a continuous second derivative can be represented by an expansion about a point that is close to a root of f(x). Suppose this root is α. Then the expansion of f(α) about xn is:

     f ( α ) = f (  x  n   ) +  f ′  (  x  n   ) ( α −  x  n   ) +  R  1      {\displaystyle f(\alpha )=f(x_{n})+f'(x_{n})(\alpha -x_{n})+R_{1}\,}    [1](https://en.wikipedia.org/wiki/Newton's_method#math_1)

where the [Lagrange form of the Taylor series expansion remainder](https://en.wikipedia.org/wiki/Lagrange_remainder) is

R  1   =   1  2 !     f ″  (  ξ  n   )   (  α −  x  n    )   2    ,   {\displaystyle R_{1}={\frac {1}{2!}}f''(\xi _{n})\left(\alpha -x_{n}\right)^{2}\,,}

where ξn is in between xn and α.

Since α is the root, (**[1](https://en.wikipedia.org/wiki/Newton's_method#math_1)**) becomes:

     0 = f ( α ) = f (  x  n   ) +  f ′  (  x  n   ) ( α −  x  n   ) +    1 2     f ″  (  ξ  n   )   (  α −  x  n    )   2      {\displaystyle 0=f(\alpha )=f(x_{n})+f'(x_{n})(\alpha -x_{n})+{\tfrac {1}{2}}f''(\xi _{n})\left(\alpha -x_{n}\right)^{2}\,}    [2](https://en.wikipedia.org/wiki/Newton's_method#math_2)

Dividing equation (**[2](https://en.wikipedia.org/wiki/Newton's_method#math_2)**) by f′(xn) and rearranging gives

        f (  x  n   )    f ′  (  x  n   )    +  (  α −  x  n    )  =    −  f ″  (  ξ  n   )   2  f ′  (  x  n   )      (  α −  x  n    )   2     {\displaystyle {\frac {f(x_{n})}{f'(x_{n})}}+\left(\alpha -x_{n}\right)={\frac {-f''(\xi _{n})}{2f'(x_{n})}}\left(\alpha -x_{n}\right)^{2}}    [3](https://en.wikipedia.org/wiki/Newton's_method#math_3)

Remembering that xn + 1 is defined by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )     ,   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}\,,}    [4](https://en.wikipedia.org/wiki/Newton's_method#math_4)

one finds that

α −  x  n + 1    ⏟     ε  n + 1     =    −  f ″  (  ξ  n   )   2  f ′  (  x  n   )      (      α −  x  n    ⏟     ε  n      )   2    .   {\displaystyle \underbrace {\alpha -x_{n+1}} _{\varepsilon _{n+1}}={\frac {-f''(\xi _{n})}{2f'(x_{n})}}{(\,\underbrace {\alpha -x_{n}} _{\varepsilon _{n}}\,)}^{2}\,.}

That is,

      ε  n + 1   =    −  f ″  (  ξ  n   )   2  f ′  (  x  n   )    ⋅  ε  n   2    .   {\displaystyle \varepsilon _{n+1}={\frac {-f''(\xi _{n})}{2f'(x_{n})}}\cdot \varepsilon _{n}^{2}\,.}    [5](https://en.wikipedia.org/wiki/Newton's_method#math_5)

Taking the absolute value of both sides gives

      |   ε  n + 1    |  =    |   f ″  (  ξ  n   )  |   2  |   f ′  (  x  n   )  |     ⋅  ε  n   2    .   {\displaystyle \left|{\varepsilon _{n+1}}\right|={\frac {\left|f''(\xi _{n})\right|}{2\left|f'(x_{n})\right|}}\cdot \varepsilon _{n}^{2}\,.}    [6](https://en.wikipedia.org/wiki/Newton's_method#math_6)

Equation (**[6](https://en.wikipedia.org/wiki/Newton's_method#math_6)**) shows that the [order of convergence](https://en.wikipedia.org/wiki/Order_of_convergence) is at least quadratic if the following conditions are satisfied:

1. f′(x) ≠ 0; for all x ∈ I, where I is the interval [α − |ε0|, α + |ε0|];
2. f″(x) is continuous, for all x ∈ I;
3. M |ε0| < 1

where M is given by

M =   1 2    (   sup  x ∈ I   |  f ″  ( x ) |  )   (   sup  x ∈ I     1  |  f ′  ( x ) |     )  .    {\displaystyle M={\frac {1}{2}}\left(\sup _{x\in I}\vert f''(x)\vert \right)\left(\sup _{x\in I}{\frac {1}{\vert f'(x)\vert }}\right).\,}

If these conditions hold,

|  ε  n + 1   | ≤ M ⋅  ε  n   2    .   {\displaystyle \vert \varepsilon _{n+1}\vert \leq M\cdot \varepsilon _{n}^{2}\,.}

### Fourier conditions

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=14)]

Suppose that *f*(*x*) is a [concave function](https://en.wikipedia.org/wiki/Concave_function) on an interval, which is [strictly increasing](https://en.wikipedia.org/wiki/Strictly_increasing). If it is negative at the left endpoint and positive at the right endpoint, the [intermediate value theorem](https://en.wikipedia.org/wiki/Intermediate_value_theorem) guarantees that there is a zero ζ of f somewhere in the interval. From geometrical principles, it can be seen that the Newton iteration *x**i* starting at the left endpoint is [monotonically increasing](https://en.wikipedia.org/wiki/Monotonic_function) and convergent, necessarily to ζ.[[18]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-ostrowski-18)

[Joseph Fourier](https://en.wikipedia.org/wiki/Joseph_Fourier) introduced a modification of Newton's method starting at the right endpoint:

      y  i + 1   =  y  i   −    f (  y  i   )    f ′  (  x  i   )    .   {\displaystyle y_{i+1}=y_{i}-{\frac {f(y_{i})}{f'(x_{i})}}.}

This sequence is monotonically decreasing and convergent. By passing to the limit in this definition, it can be seen that the limit of *y**i* must also be the zero ζ.[[18]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-ostrowski-18)

So, in the case of a concave increasing function with a zero, initialization is largely irrelevant. Newton iteration starting anywhere left of the zero will converge, as will Fourier's modified Newton iteration starting anywhere right of the zero. The accuracy at any step of the iteration can be determined directly from the difference between the location of the iteration from the left and the location of the iteration from the right. If f is twice continuously differentiable, it can be proved using [Taylor's theorem](https://en.wikipedia.org/wiki/Taylor's_theorem) that

      lim  i → ∞       y  i + 1   −  x  i + 1     (  y  i   −  x  i    )  2      = −   1 2       f ″  ( ζ )    f ′  ( ζ )    ,   {\displaystyle \lim _{i\to \infty }{\frac {y_{i+1}-x_{i+1}}{(y_{i}-x_{i})^{2}}}=-{\frac {1}{2}}{\frac {f''(\zeta )}{f'(\zeta )}},}

showing that this difference in locations converges quadratically to zero.[[18]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-ostrowski-18)

All of the above can be extended to systems of equations in multiple variables, although in that context the relevant concepts of [monotonicity](https://en.wikipedia.org/wiki/Monotonicity) and concavity are more subtle to formulate.[[19]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-19) In the case of single equations in a single variable, the above monotonic convergence of Newton's method can also be generalized to replace concavity by positivity or negativity conditions on an arbitrary higher-order derivative of f. However, in this generalization, Newton's iteration is modified so as to be based on [Taylor polynomials](https://en.wikipedia.org/wiki/Taylor_polynomial) rather than the [tangent line](https://en.wikipedia.org/wiki/Tangent_line). In the case of concavity, this modification coincides with the standard Newton method.[[20]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-20)

### Use of Newton's method to compute square roots

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=17)]

Newton's method is one of many known [methods of computing square roots](https://en.wikipedia.org/wiki/Methods_of_computing_square_roots). Given a positive number a, the problem of finding a number x such that *x*2 = *a* is equivalent to finding a root of the function *f*(*x*) = *x*2 − *a*. The Newton iteration defined by this function is given by[[21]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-21)

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −     x  n   2   − a   2  x  n      =   1 2    (   x  n   +   a  x  n      )    {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}^{2}-a}{2x_{n}}}={\frac {1}{2}}\left(x_{n}+{\frac {a}{x_{n}}}\right)}  .

This happens to coincide with the ["Babylonian" method of finding square roots](https://en.wikipedia.org/wiki/Methods_of_computing_square_roots#Heron's_method), which consists of replacing an approximate root *x**n* by the [arithmetic mean](https://en.wikipedia.org/wiki/Arithmetic_mean) of xn and a⁄xn. ### Systems of equations

#### k variables, k functions

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=21)]

One may also use Newton's method to solve systems of k equations, which amounts to finding the (simultaneous) zeroes of k continuously differentiable functions     f :   R   k   →  R  .   {\displaystyle f:\mathbb {R} ^{k}\to \mathbb {R} .}   This is equivalent to finding the zeroes of a single vector-valued function     F :   R   k   →   R   k   .   {\displaystyle F:\mathbb {R} ^{k}\to \mathbb {R} ^{k}.}   In the formulation given above, the scalars xn are replaced by vectors **x**n and instead of dividing the function f(xn) by its derivative f′(xn) one instead has to left multiply the function F(**x**n) by the inverse of its k × k [Jacobian matrix](https://en.wikipedia.org/wiki/Jacobian_matrix) JF(**x**n).[[22]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:3-22)[[23]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-23) This results in the expression

x   n + 1   =   x   n   −  J  F   (   x   n    )  − 1   F (   x   n   ) .   {\displaystyle \mathbf {x} _{n+1}=\mathbf {x} _{n}-J_{F}(\mathbf {x} _{n})^{-1}F(\mathbf {x} _{n}).}

or, by solving the [system of linear equations](https://en.wikipedia.org/wiki/System_of_linear_equations)

J  F   (   x   n   ) (   x   n + 1   −   x   n   ) = − F (   x   n   )   {\displaystyle J_{F}(\mathbf {x} _{n})(\mathbf {x} _{n+1}-\mathbf {x} _{n})=-F(\mathbf {x} _{n})}

for the unknown **x**n + 1 − **x**n.[[24]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-24)

#### k variables, m equations, with m > k

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=22)]

The k-dimensional variant of Newton's method can be used to solve systems of greater than k (nonlinear) equations as well if the algorithm uses the [generalized inverse](https://en.wikipedia.org/wiki/Generalized_inverse) of the non-square [Jacobian](https://en.wikipedia.org/wiki/Jacobian_matrix_and_determinant) matrix J+ = (JTJ)−1JT instead of the inverse of J. If the [nonlinear system](https://en.wikipedia.org/wiki/System_of_nonlinear_equations) has no solution, the method attempts to find a solution in the [non-linear least squares](https://en.wikipedia.org/wiki/Non-linear_least_squares) sense. See [Gauss–Newton algorithm](https://en.wikipedia.org/wiki/Gauss%E2%80%93Newton_algorithm) for more information.

### Complex functions

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=24)] Main article: [Newton fractal](https://en.wikipedia.org/wiki/Newton_fractal) [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/b/bf/Newtroot_1_0_0_0_0_m1.png/250px-Newtroot_1_0_0_0_0_m1.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Newtroot_1_0_0_0_0_m1.png)Basins of attraction for x5 − 1 = 0; darker means more iterations to converge.

When dealing with [complex functions](https://en.wikipedia.org/wiki/Complex_analysis), Newton's method can be directly applied to find their zeroes.[[26]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-26) Each zero has a [basin of attraction](https://en.wikipedia.org/wiki/Basin_of_attraction) in the complex plane, the set of all starting values that cause the method to converge to that particular zero. These sets can be mapped as in the image shown. For many complex functions, the boundaries of the basins of attraction are [fractals](https://en.wikipedia.org/wiki/Fractal).

In some cases there are regions in the complex plane which are not in any of these basins of attraction, meaning the iterates do not converge. For example,[[27]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-27) if one uses a real initial condition to seek a root of x2 + 1, all subsequent iterates will be real numbers and so the iterations cannot converge to either root, since both roots are non-real. In this case [almost all](https://en.wikipedia.org/wiki/Almost_all) real initial conditions lead to [chaotic behavior](https://en.wikipedia.org/wiki/Chaos_theory), while some initial conditions iterate either to infinity or to repeating cycles of any finite length.

Curt McMullen has shown that for any possible purely iterative algorithm similar to Newton's method, the algorithm will diverge on some open regions of the complex plane when applied to some polynomial of degree 4 or higher. However, McMullen gave a generally convergent algorithm for polynomials of degree 3.[[28]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-28) Furthermore, Hubbard, Schleicher and Sutherland constructed a universal set of starting points for Newton's method: for every degree d, there exists an explicitly constructible set of approximately 1.11 *d* (log *d*)2 points such that, for any suitably normalized polynomial of degree d, each root is found by Newton iteration started from at least one point of the set.[[29]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-29)

### In a Banach space

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=25)]

Another generalization is Newton's method to find a root of a [functional](https://en.wikipedia.org/wiki/Functional_(mathematics)) F defined in a [Banach space](https://en.wikipedia.org/wiki/Banach_space). In this case the formulation is

X  n + 1   =  X  n   −   (    F ′  (  X  n   )    )    − 1   F (  X  n   ) ,    {\displaystyle X_{n+1}=X_{n}-{\bigl (}F'(X_{n}){\bigr )}^{-1}F(X_{n}),\,}

where F′(Xn) is the [Fréchet derivative](https://en.wikipedia.org/wiki/Fr%C3%A9chet_derivative) computed at Xn. One needs the Fréchet derivative to be boundedly invertible at each Xn in order for the method to be applicable. A condition for existence of and convergence to a root is given by the [Newton–Kantorovich theorem](https://en.wikipedia.org/wiki/Kantorovich_theorem).[[30]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-30)

#### Nash–Moser iteration

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=26)] Further information: [Nash–Moser theorem](https://en.wikipedia.org/wiki/Nash%E2%80%93Moser_theorem)

In the 1950s, [John Nash](https://en.wikipedia.org/wiki/John_Forbes_Nash_Jr.) developed a version of the Newton's method to apply to the problem of constructing [isometric embeddings](https://en.wikipedia.org/wiki/Isometric_embedding) of general [Riemannian manifolds](https://en.wikipedia.org/wiki/Riemannian_manifold) in [Euclidean space](https://en.wikipedia.org/wiki/Euclidean_space). The *loss of derivatives* problem, present in this context, made the standard Newton iteration inapplicable, since it could not be continued indefinitely (much less converge). Nash's solution involved the introduction of [smoothing](https://en.wikipedia.org/wiki/Smoothing) operators into the iteration. He was able to prove the convergence of his smoothed Newton method, for the purpose of proving an [implicit function theorem](https://en.wikipedia.org/wiki/Implicit_function_theorem) for isometric embeddings. In the 1960s, [Jürgen Moser](https://en.wikipedia.org/wiki/J%C3%BCrgen_Moser) showed that Nash's methods were flexible enough to apply to problems beyond isometric embedding, particularly in [celestial mechanics](https://en.wikipedia.org/wiki/Celestial_mechanics). Since then, a number of mathematicians, including [Mikhael Gromov](https://en.wikipedia.org/wiki/Mikhael_Gromov_(mathematician)) and [Richard Hamilton](https://en.wikipedia.org/wiki/Richard_S._Hamilton), have found generalized abstract versions of the Nash–Moser theory.[[31]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-31)[[32]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-32) In Hamilton's formulation, the Nash–Moser theorem forms a generalization of the Banach space Newton method which takes place in certain [Fréchet spaces](https://en.wikipedia.org/wiki/Fr%C3%A9chet_space).

### Quasi-Newton methods

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=28)]

When the Jacobian is unavailable or too expensive to compute at every iteration, a [quasi-Newton method](https://en.wikipedia.org/wiki/Quasi-Newton_method) can be used.

### Chebyshev's third-order method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=29)] Main article: [Chebyshev iteration](https://en.wikipedia.org/wiki/Chebyshev_iteration)

Since higher-order Taylor expansions offer more accurate local approximations of a function f, it is reasonable to ask why Newton’s method relies only on a second-order Taylor approximation. In the 19th century, Russian mathematician Pafnuty Chebyshev explored this idea by developing a variant of Newton’s method that used cubic approximations.[[33]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-33)[[34]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-34)[[35]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-35)

### Over p-adic numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=30)]

In p-adic analysis, the standard method to show a polynomial equation in one variable has a p-adic root is [Hensel's lemma](https://en.wikipedia.org/wiki/Hensel's_lemma), which uses the recursion from Newton's method on the p-adic numbers. Because of the more stable behavior of addition and multiplication in the p-adic numbers compared to the real numbers (specifically, the unit ball in the p-adics is a ring), convergence in Hensel's lemma can be guaranteed under much simpler hypotheses than in the classical Newton's method on the real line.

Newton's method can be generalized with the [q-analog](https://en.wikipedia.org/wiki/Q-analog) of the usual derivative.[[36]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-36)

### Modified Newton methods

#### Maehly's procedure

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=33)]

A nonlinear equation has multiple solutions in general. But if the initial value is not appropriate, Newton's method may not converge to the desired solution or may converge to the same solution found earlier. When we have already found N solutions of     f ( x ) = 0   {\displaystyle f(x)=0}  , then the next root can be found by applying Newton's method to the next equation:[[37]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-37)[[38]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-38)

F ( x ) =    f ( x )    ∏  i = 1   N   ( x −  x  i   )    = 0.   {\displaystyle F(x)={\frac {f(x)}{\prod _{i=1}^{N}(x-x_{i})}}=0.}

This method is applied to obtain zeros of the [Bessel function](https://en.wikipedia.org/wiki/Bessel_function) of the second kind.[[39]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-39)

#### Hirano's modified Newton method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=34)]

Hirano's modified Newton method is a modification conserving the convergence of Newton method and avoiding unstableness.[[40]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-40) It is developed to solve complex polynomials.

#### Interval Newton's method

Combining Newton's method with [interval arithmetic](https://en.wikipedia.org/wiki/Interval_arithmetic) is very useful in some contexts. This provides a stopping criterion that is more reliable than the usual ones (which are a small value of the function or a small variation of the variable between consecutive iterations). Also, this may detect cases where Newton's method converges theoretically but diverges numerically because of an insufficient [floating-point precision](https://en.wikipedia.org/wiki/Floating-point_arithmetic) (this is typically the case for polynomials of large degree, where a very small change of the variable may change dramatically the value of the function; see [Wilkinson's polynomial](https://en.wikipedia.org/wiki/Wilkinson's_polynomial)).[[41]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-41)[[42]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-42)

Consider f → C1(X), where X is a real interval, and suppose that we have an interval extension F′ of f′, meaning that F′ takes as input an interval Y ⊆ X and outputs an interval F′(Y) such that:

F ′  ( [ y , y ] )    = {  f ′  ( y ) }      F ′  ( Y )    ⊇ {  f ′  ( y ) ∣ y ∈ Y } .       {\displaystyle {\begin{aligned}F'([y,y])&=\{f'(y)\}\\[5pt]F'(Y)&\supseteq \{f'(y)\mid y\in Y\}.\end{aligned}}}

We also assume that 0 ∉ F′(X), so in particular f has at most one root in X. We then define the interval Newton operator by:

N ( Y ) = m −    f ( m )    F ′  ( Y )    =  {     m −    f ( m )  z      |    z ∈  F ′  ( Y )  }    {\displaystyle N(Y)=m-{\frac {f(m)}{F'(Y)}}=\left\{\left.m-{\frac {f(m)}{z}}~\right|~z\in F'(Y)\right\}}

where m ∈ Y. Note that the hypothesis on F′ implies that N(Y) is well defined and is an interval (see [interval arithmetic](https://en.wikipedia.org/wiki/Interval_arithmetic) for further details on interval operations). This naturally leads to the following sequence:

X  0      = X      X  k + 1      = N (  X  k   ) ∩  X  k   .       {\displaystyle {\begin{aligned}X_{0}&=X\\X_{k+1}&=N(X_{k})\cap X_{k}.\end{aligned}}}

The [mean value theorem](https://en.wikipedia.org/wiki/Mean_value_theorem) ensures that if there is a root of f in Xk, then it is also in Xk + 1. Moreover, the hypothesis on F′ ensures that Xk + 1 is at most half the size of Xk when m is the midpoint of Y, so this sequence converges towards [x*, x*], where x* is the root of f in X.

If F′(X) strictly contains 0, the use of extended interval division produces a union of two intervals for N(X); multiple roots are therefore automatically separated and bounded.

## Applications

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=36)]

### Minimization and maximization problems

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=37)] Main article: [Newton's method in optimization](https://en.wikipedia.org/wiki/Newton's_method_in_optimization)

Newton's method can be used to find a minimum or maximum of a function f(x). The derivative is zero at a minimum or maximum, so local minima and maxima can be found by applying Newton's method to the derivative.[[43]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-43) The iteration becomes:

x  n + 1   =  x  n   −     f ′  (  x  n   )    f ″  (  x  n   )    .   {\displaystyle x_{n+1}=x_{n}-{\frac {f'(x_{n})}{f''(x_{n})}}.}

### Multiplicative inverses of numbers and power series

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=38)]

An important application is [Newton–Raphson division](https://en.wikipedia.org/wiki/Division_algorithm#Newton%E2%80%93Raphson_division), which can be used to quickly find the [reciprocal](https://en.wikipedia.org/wiki/Multiplicative_inverse) of a number a, using only multiplication and subtraction, that is to say the number x such that ⁠1/x⁠ = a. We can rephrase that as finding the zero of f(x) = ⁠1/x⁠ − a. We have f′(x) = −⁠1/x2⁠.

Newton's iteration is

x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   +      1  x  n     − a   1  x  n   2      =  x  n   ( 2 − a  x  n   ) .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}+{\frac {{\frac {1}{x_{n}}}-a}{\frac {1}{x_{n}^{2}}}}=x_{n}(2-ax_{n}).}

Therefore, Newton's iteration needs only two multiplications and one subtraction.

This method is also very efficient to compute the multiplicative inverse of a [power series](https://en.wikipedia.org/wiki/Power_series).

### Solving transcendental equations

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=39)]

Many [transcendental equations](https://en.wikipedia.org/wiki/Transcendental_equation) can be solved up to an arbitrary precision by using Newton's method. For example, finding the cumulative [probability density function](https://en.wikipedia.org/wiki/Probability_density_function), such as a [Normal distribution](https://en.wikipedia.org/wiki/Normal_distribution) to fit a known probability generally involves integral functions with no known means to solve in closed form. However, computing the derivatives needed to solve them numerically with Newton's method is generally known, making numerical solutions possible. For an example, see the numerical solution to the [inverse Normal cumulative distribution](https://en.wikipedia.org/wiki/Normal_distribution#Using_the_Taylor_series_and_Newton's_method_for_the_inverse_function).

### Numerical verification for solutions of nonlinear equations

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=40)]

A numerical verification for solutions of nonlinear equations has been established by using Newton's method multiple times and forming a set of solution candidates.[*[citation needed](https://en.wikipedia.org/wiki/Wikipedia:Citation_needed)*]

## Algorithm

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=41)]

The following [pseudocode](https://en.wikipedia.org/wiki/Pseudocode) describes a possible implementation of Newton's method.

```
input:
Real valued function, f
The derivative of the function, f′
An initial guess to the root, x0
The required tolerance, TOL
The maximum number of iterations, MAX_IT
The smallest number we wish to divide by, ε
output:
A value x such that f(x) ≈ 0
x ← x0
for i ← 1 to MAX_IT do
   if |f′(x)| < ε then
       print("Derivative is too close to zero.")
       return
   end if
   xNew ← x - f(x) / f′(x)
   if |xNew - x| < TOL then
       return xNew
   end if
   x ← xNew
end for
print("No solution found.")
```

 [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/8/83/Methode_newton.png/250px-Methode_newton.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Methode_newton.png)An illustration of Newton's method

In [numerical analysis](https://en.wikipedia.org/wiki/Numerical_analysis), the **Newton–Raphson method**, also kown simply as **Newton's method**, named after [Isaac Newton](https://en.wikipedia.org/wiki/Isaac_Newton) and [Joseph Raphson](https://en.wikipedia.org/wiki/Joseph_Raphson), is a [root-finding algorithm](https://en.wikipedia.org/wiki/Root-finding_algorithm) which produces successively better [approximations](https://en.wikipedia.org/wiki/Numerical_analysis) to the [roots](https://en.wikipedia.org/wiki/Root_of_a_function) (or zeroes) of a [real](https://en.wikipedia.org/wiki/Real_number)-valued [function](https://en.wikipedia.org/wiki/Function_(mathematics)). The most basic version starts with a [real-valued function](https://en.wikipedia.org/wiki/Real-valued_function) f, its [derivative](https://en.wikipedia.org/wiki/Derivative) f′, and an initial guess x0 for a [root](https://en.wikipedia.org/wiki/Zero_of_a_function) of f. If f satisfies certain assumptions and the initial guess is close, then

x  1   =  x  0   −    f (  x  0   )    f ′  (  x  0   )      {\displaystyle x_{1}=x_{0}-{\frac {f(x_{0})}{f'(x_{0})}}}

is a better approximation of the root than x0. Geometrically, (x1, 0) is the [x-intercept](https://en.wikipedia.org/wiki/X-intercept) of the [tangent](https://en.wikipedia.org/wiki/Tangent) to the [graph](https://en.wikipedia.org/wiki/Graph_of_a_function) of f at (x0, f(x0)): that is, the improved guess, x1, is the unique root of the [linear approximation](https://en.wikipedia.org/wiki/Linear_approximation) of f at the initial guess, x0. The process is repeated as

x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )      {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}}

until a sufficiently precise value is reached. The number of correct digits roughly doubles with each step. This algorithm is first in the class of [Householder's methods](https://en.wikipedia.org/wiki/Householder's_method), and was succeeded by [Halley's method](https://en.wikipedia.org/wiki/Halley's_method). The method can also be extended to [complex functions](https://en.wikipedia.org/wiki/Complex-valued_function) and to [systems of equations](https://en.wikipedia.org/wiki/Systems_of_equations).

Description

# Description

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=1)]

The purpose of Newton's method is to find a root of a function. The idea is to start with an initial guess near a root, approximate the function by its [tangent line](https://en.wikipedia.org/wiki/Tangent_line) near the guess, and then take the root of the linear approximation as a next guess at the function's root. This will typically be closer to the function's root than the previous guess, and the method can be [iterated](https://en.wikipedia.org/wiki/Iterative_method).

 [![Illustration of Newton's method](https://thumb.wikimedia.org/wikipedia/commons/thumb/8/8c/Newton_iteration.svg/500px-Newton_iteration.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Newton_iteration.svg)xn+1 is a better approximation than xn for the root x of the function f (blue curve).

The best [linear approximation](https://en.wikipedia.org/wiki/Linear_approximation) to an arbitrary [differentiable function](https://en.wikipedia.org/wiki/Differentiable_function)     f ( x )   {\displaystyle f(x)}   near the point     x =  x  n     {\displaystyle x=x_{n}}   is the tangent line to the curve, with equation

f ( x ) ≈ f (  x  n   ) +  f ′  (  x  n   ) ( x −  x  n   ) .   {\displaystyle f(x)\approx f(x_{n})+f'(x_{n})(x-x_{n}).}

The root of this linear function, the place where it intercepts the ⁠    x   {\displaystyle x}  ⁠-axis, can be taken as a closer approximate root ⁠     x  n + 1     {\displaystyle x_{n+1}}  ⁠ if      f ′  (  x  n   ) ≠ 0   {\displaystyle f'(x_{n})\neq 0}  :

x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}.}

 [![Illustration of Newton's method](https://thumb.wikimedia.org/wikipedia/commons/thumb/e/e0/NewtonIteration_Ani.gif/500px-NewtonIteration_Ani.gif?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:NewtonIteration_Ani.gif)Iteration typically improves the approximation.

The process can be started with any arbitrary initial guess ⁠     x  0     {\displaystyle x_{0}}  ⁠, though it will generally require fewer iterations to converge if the guess is close to one of the function's roots. The method will usually converge if ⁠     f ′  (  x  0   ) ≠ 0   {\displaystyle f'(x_{0})\neq 0}  ⁠. Furthermore, for a root of [multiplicity](https://en.wikipedia.org/wiki/Multiplicity_(mathematics)) 1, the convergence is at least quadratic (see *[Rate of convergence](https://en.wikipedia.org/wiki/Rate_of_convergence)*) in some sufficiently small [neighbourhood](https://en.wikipedia.org/wiki/Neighbourhood_(mathematics)) of the root: the number of correct digits of the approximation roughly doubles with each additional step. More details can be found in *[§ Analysis](https://en.wikipedia.org/wiki/Newton's_method#Analysis)* below.

[Householder's methods](https://en.wikipedia.org/wiki/Householder's_method) are similar but have higher order for even faster convergence. However, the extra computations required for each step can slow down the overall performance relative to Newton's method, particularly if ⁠    f   {\displaystyle f}  ⁠ or its derivatives are computationally expensive to evaluate.

History

# History

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=2)]

In the [Old Babylonian](https://en.wikipedia.org/wiki/Babylonian_mathematics) period (19th–16th century BCE), the side of a square of known area could be effectively approximated, and this is conjectured to have been done using a special case of Newton's method, [described algebraically below](https://en.wikipedia.org/wiki/Newton's_method#Use_of_Newton's_method_to_compute_square_roots), by iteratively improving an initial estimate; an equivalent method can be found in [Hero of Alexandria](https://en.wikipedia.org/wiki/Hero_of_Alexandria)'s *Metrica* (1st–2nd century CE), so is often called *[Heron's method](https://en.wikipedia.org/wiki/Heron's_method)*.[[1]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-1) [Jamshīd al-Kāshī](https://en.wikipedia.org/wiki/Jamsh%C4%ABd_al-K%C4%81sh%C4%AB) used a method to solve xP − N = 0 to find roots of *N*, a method that was algebraically equivalent to Newton's method, and a similar method was found in *Trigonometria Britannica*, published by [Henry Briggs](https://en.wikipedia.org/wiki/Henry_Briggs_(mathematician)) in 1633.[[2]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:1-2) His method first appeared in his 1427 publication *Miftāḥ al-Ḥisāb* (*The Key to Arithmetic*). Al-Kāshī's work was founded on the earlier contributions of the polymath [al-Bīrūnī](https://en.wikipedia.org/wiki/Al-B%C4%ABr%C5%ABn%C4%AB) (973–1048) and the mathematician [Sharaf al-Dīn al-Ṭūsī](https://en.wikipedia.org/wiki/Sharaf_al-D%C4%ABn_al-%E1%B9%AC%C5%ABs%C4%AB) (1135–1213). The contributions of al-Kāshī remained largely unknown to the Western scientific community for centuries, until the work of [François Viète](https://en.wikipedia.org/wiki/Fran%C3%A7ois_Vi%C3%A8te) (1540–1603). In 1600, Viète rediscovered a technique similar to al-Kāshī's in the context of solving scalar polynomial equations of degree six.[[3]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-arxiv|2205.11033-3)

The method that laid the groundwork for what is now the modern Newton's method which would be developed by [Joseph Raphson](https://en.wikipedia.org/wiki/Joseph_Raphson) and [Thomas Simpson](https://en.wikipedia.org/wiki/Thomas_Simpson) first appeared in [Isaac Newton](https://en.wikipedia.org/wiki/Isaac_Newton)'s work in *[De analysi per aequationes numero terminorum infinitas](https://en.wikipedia.org/wiki/De_analysi_per_aequationes_numero_terminorum_infinitas)* (written in 1669, published in 1711 by [William Jones](https://en.wikipedia.org/wiki/William_Jones_(mathematician))) and in *De metodis fluxionum et serierum infinitarum* (written in 1671, translated and published as *[Method of Fluxions](https://en.wikipedia.org/wiki/Method_of_Fluxions)* in 1736 by [John Colson](https://en.wikipedia.org/wiki/John_Colson)).[[4]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:0-4)[[2]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:1-2)[[5]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-5) However, while Newton gave the basic ideas, his method differs from the modern method given above. He applied the method only to polynomials, starting with an initial root estimate and extracting a sequence of error corrections. He used each correction to rewrite the polynomial in terms of the remaining error, and then solved for a new correction by neglecting higher-degree terms. He did not explicitly connect the method with derivatives or present a general formula. Newton applied this method to both numerical and algebraic problems, producing [Taylor series](https://en.wikipedia.org/wiki/Taylor_series) in the latter case. Despite this, in the later second and third editions of Newton's 1687 *[Philosophiæ Naturalis Principia Mathematica](https://en.wikipedia.org/wiki/Philosophi%C3%A6_Naturalis_Principia_Mathematica)*, he did apply his method in an iterative manner to a nonpolynomial equation, specifically [Kepler's equation](https://en.wikipedia.org/wiki/Kepler's_equation), which were the first published uses of Newton's method in this form by him.[[2]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:1-2)

Newton may have derived his method from a similar, less precise method by mathematician Viète, however, the two methods are not the same.[[4]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:0-4) The essence of Viète's own method can be found in the work of the mathematician [Sharaf al-Din al-Tusi](https://en.wikipedia.org/wiki/Sharaf_al-Din_al-Tusi).[[6]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-6)

The Japanese mathematician [Seki Kōwa](https://en.wikipedia.org/wiki/Seki_K%C5%8Dwa) used a form of Newton's method in the 1680s to solve single-variable equations, though the connection with [calculus](https://en.wikipedia.org/wiki/Calculus) was missing.[[7]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-7)

Newton's method was first published in 1685 in *A Treatise of Algebra both Historical and Practical* by [John Wallis](https://en.wikipedia.org/wiki/John_Wallis).[[8]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-8) In 1690, Raphson published a simplified description in *Analysis aequationum universalis*.[[9]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-9) Raphson also applied the method only to polynomials, but he avoided Newton's tedious rewriting process by extracting each successive correction from the original polynomial. This allowed him to derive a reusable iterative expression for each problem. Finally, in 1740, Simpson described Newton's method as an iterative method for solving general nonlinear equations using calculus, essentially giving the description above. In the same publication, Simpson also gives the generalization to systems of two equations and notes that Newton's method can be used for solving optimization problems by setting the gradient to zero.

[Arthur Cayley](https://en.wikipedia.org/wiki/Arthur_Cayley) in 1879 in *The Newton–Fourier imaginary problem* was the first to notice the difficulties in generalizing Newton's method to complex roots of polynomials with degree greater than 2 and complex initial values. This opened the way to the study of the [theory of iterations](https://en.wikipedia.org/wiki/Julia_set) of rational functions.

Practical considerations

# Practical considerations

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=3)]

Newton's method is a powerful technique—if the derivative of the function at the root is nonzero, then the [convergence](https://en.wikipedia.org/wiki/Rate_of_convergence) is at least quadratic: as the method converges on the root, the difference between the root and the approximation is squared (the number of accurate digits roughly doubles) at each step. However, there are some difficulties with the method.

Difficulty in calculating the derivative of a function

# Difficulty in calculating the derivative of a function

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=4)]

Newton's method requires that the derivative can be calculated directly. An analytical expression for the derivative may not be easily obtainable or could be expensive to evaluate. In these situations, it may be appropriate to approximate the derivative by using the slope of a line through two nearby points on the function. Using this approximation would result in something like the [secant method](https://en.wikipedia.org/wiki/Secant_method) whose convergence is slower than that of Newton's method.

Failure of the method to converge to the root

# Failure of the method to converge to the root

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=5)]

It is important to review the [proof of quadratic convergence](https://en.wikipedia.org/wiki/Newton's_method#Proof_of_quadratic_convergence_for_Newton's_iterative_method) of Newton's method before implementing it. Specifically, one should review the assumptions made in the proof. For situations where the method fails to converge, it is because the assumptions made in this proof are not met.

For example, [in some cases](https://en.wikipedia.org/wiki/Newton's_method#Divergence_even_when_initialization_is_close_to_the_root), if the first derivative is not well behaved in the neighborhood of a particular root, then it is possible that Newton's method will fail to converge no matter where the initialization is set. In some cases, Newton's method can be stabilized by using [successive over-relaxation](https://en.wikipedia.org/wiki/Successive_over-relaxation#Other_applications_of_the_method), or the speed of convergence can be increased by using the same method.

In a robust implementation of Newton's method, it is common to place limits on the number of iterations, bound the solution to an interval known to contain the root, and combine the method with a more robust root finding method.

Slow convergence for roots of multiplicity greater than 1

# Slow convergence for roots of multiplicity greater than 1

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=6)]

If the root being sought has [multiplicity](https://en.wikipedia.org/wiki/Multiplicity_(mathematics)#Multiplicity_of_a_root_of_a_polynomial) greater than one, the convergence rate is merely linear (errors reduced by a constant factor at each step) unless special steps are taken. When there are two or more roots that are close together then it may take many iterations before the iterates get close enough to one of them for the quadratic convergence to be apparent. However, if the multiplicity m of the root is known, the following modified algorithm preserves the quadratic convergence rate:[[10]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-10)

x  n + 1   =  x  n   − m    f (  x  n   )    f ′  (  x  n   )    .   {\displaystyle x_{n+1}=x_{n}-m{\frac {f(x_{n})}{f'(x_{n})}}.}

This is equivalent to using [successive over-relaxation](https://en.wikipedia.org/wiki/Successive_over-relaxation#Other_applications_of_the_method). On the other hand, if the multiplicity m of the root is not known, it is possible to estimate m after carrying out one or two iterations, and then use that value to increase the rate of convergence.

If the multiplicity m of the root is finite then g(x) = ⁠f(x)/f′(x)⁠ will have a root at the same location with multiplicity 1. Applying Newton's method to find the root of g(x) recovers quadratic convergence in many cases although it generally involves the second derivative of f(x). In a particularly simple case, if f(x) = xm then g(x) = ⁠x/m⁠ and Newton's method finds the root in a single iteration with

x  n + 1   =  x  n   −    g (  x  n   )    g ′  (  x  n   )    =  x  n   −        x  n   m      1 m    = 0  .   {\displaystyle x_{n+1}=x_{n}-{\frac {g(x_{n})}{g'(x_{n})}}=x_{n}-{\frac {\;{\frac {x_{n}}{m}}\;}{\frac {1}{m}}}=0\,.}

Slow convergence

# Slow convergence

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=7)]

The function *f*(*x*) = *x*2 has a root at 0.[[11]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-dennis-11) Since f is continuously differentiable at its root, the theory guarantees that Newton's method as initialized sufficiently close to the root will converge. However, since the derivative *f* ′ is zero at the root, quadratic convergence is not ensured by the theory. In this particular example, the Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =   1 2    x  n   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}={\frac {1}{2}}x_{n}.}

It is visible from this that Newton's method could be initialized anywhere and converge to zero, but at only a linear rate. If initialized at 1, dozens of iterations would be required before ten digits of accuracy are achieved.

The function *f*(*x*) = *x* + *x*4/3 also has a root at 0, where it is continuously differentiable. Although the first derivative *f* ′ is nonzero at the root, the second derivative *f* ′′ is nonexistent there, so that quadratic convergence cannot be guaranteed. In fact the Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =    x  n   4  /  3    3 + 4  x  n   1  /  3      ≈  x  n   ⋅    x  n   1  /  3   3   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}={\frac {x_{n}^{4/3}}{3+4x_{n}^{1/3}}}\approx x_{n}\cdot {\frac {x_{n}^{1/3}}{3}}.}

From this, it can be seen that the rate of convergence is superlinear but subquadratic. While the convergence on the left is superlinear, the order of magnitude is only multiplied by about 4/3 from row to row (0,1,2,4,5,7,10,13,...).

  *x**n* *x* + *x*4/3

The rate of convergence is distinguished from the number of iterations required to reach a given accuracy. For example, the function *f*(*x*) = *x*20 − 1 has a root at 1. Convergence dependent on initialization

# Convergence dependent on initialization

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=8)]

The function *f*(*x*) = *x*(1 + *x*2)−1/2 has a root at 0. The Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −     x  n   ( 1 +  x  n   2    )  − 1  /  2     ( 1 +  x  n   2    )  − 3  /  2      = −  x  n   3   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}(1+x_{n}^{2})^{-1/2}}{(1+x_{n}^{2})^{-3/2}}}=-x_{n}^{3}.}

From this, it can be seen that there are three possible phenomena for a Newton iteration. If initialized strictly between ±1, the Newton iteration will converge (super-)quadratically to 0; if initialized exactly at 1 or −1, the Newton iteration will oscillate endlessly between ±1; if initialized anywhere else, the Newton iteration will diverge.[[13]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-13) This same trichotomy occurs for *f*(*x*) = arctan *x*.[[11]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-dennis-11)

In cases where the function in question has multiple roots, it can be difficult to control, via choice of initialization, which root (if any) is identified by Newton's method. For example, the function *f*(*x*) = *x*(*x*2 − 1)(*x* − 3)e−(*x* − 1)2/2 has roots at −1, 0, 1, and 3.[[14]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-FOOTNOTES%C3%BCliMayers2003-14) If initialized at −1.488, the Newton iteration converges to 0; if initialized at −1.487, it diverges to ∞; if initialized at −1.486, it converges to −1; if initialized at −1.485, it diverges to −∞; if initialized at −1.4843, it converges to 3; if initialized at −1.484, it converges to 1. This kind of subtle dependence on initialization is not uncommon; it is frequently studied in the [complex plane](https://en.wikipedia.org/wiki/Complex_plane) in the form of the [Newton fractal](https://en.wikipedia.org/wiki/Newton_fractal).

Divergence even when initialization is close to the root

# Divergence even when initialization is close to the root

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=9)]

Consider the problem of finding a root of *f*(*x*) = *x*1/3. The Newton iteration is

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −    x  n   1  /  3      1 3    x  n   − 2  /  3      = − 2  x  n   .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}^{1/3}}{{\frac {1}{3}}x_{n}^{-2/3}}}=-2x_{n}.}

Unless Newton's method is initialized at the exact root 0, it is seen that the sequence of iterates will fail to converge. For example, even if initialized at the reasonably accurate guess of 0.001, the first several iterates are −0.002, 0.004, −0.008, 0.016, reaching 1048.58, −2097.15, ... by the 20th iterate. This failure of convergence is not contradicted by the analytic theory, since in this case f is not differentiable at its root.

In the above example, failure of convergence is reflected by the failure of *f*(*x**n*) to get closer to zero as n increases, as well as by the fact that successive iterates are growing further and further apart. However, the function *f*(*x*) = *x*1/3e−*x*2 also has a root at 0. The Newton iteration is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n    (  1 −   3  1 − 6  x  n   2       )  .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}\left(1-{\frac {3}{1-6x_{n}^{2}}}\right).}

In this example, where again f is not differentiable at the root, any Newton iteration not starting exactly at the root will diverge, but with both *x**n* + 1 − *x**n* and *f*(*x**n*) converging to zero.[[15]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-judd-15) This is seen in the following table showing the iterates with initialization 1:

  *x**n* *f*(*x**n*)  10.36788  1.69.0416 × 10−2  1.93422.9556 × 10−2  2.20481.0076 × 10−2  2.43963.5015 × 10−3  2.65051.2307 × 10−3  2.84374.3578 × 10−4  3.02321.5513 × 10−4

Although the convergence of *x**n* + 1 − *x**n* in this case is not very rapid, it can be proved from the iteration formula. This example highlights the possibility that a stopping criterion for Newton's method based only on the smallness of *x**n* + 1 − *x**n* and *f*(*x**n*) might falsely identify a root.

Oscillatory behavior

# Oscillatory behavior

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=10)] [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/f/f1/NewtonsMethodConvergenceFailure.svg/500px-NewtonsMethodConvergenceFailure.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:NewtonsMethodConvergenceFailure.svg)The tangent lines of x3 − 2x + 2 at 0 and 1 intersect the x-axis at 1 and 0 respectively, illustrating why Newton's method oscillates between these values for some starting points.

It is easy to find situations for which Newton's method oscillates endlessly between two distinct values. For example, for Newton's method as applied to a function f to oscillate between 0 and 1, it is only necessary that the tangent line to f at 0 intersects the x-axis at 1 and that the tangent line to f at 1 intersects the x-axis at 0.[[15]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-judd-15) This is the case, for example, if *f*(*x*) = *x*3 − 2*x* + 2. For this function, it is even the case that Newton's iteration as initialized sufficiently close to 0 or 1 will *asymptotically* oscillate between these values. For example, Newton's method as initialized at 0.99 yields iterates 0.99, −0.06317, 1.00628, 0.03651, 1.00196, 0.01162, 1.00020, 0.00120, 1.000002, and so on. This behavior is present despite the presence of a root of f approximately equal to −1.76929.

Undefinedness of Newton's method

# Undefinedness of Newton's method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=11)]

In some cases, it is not even possible to perform the Newton iteration. For example, if *f*(*x*) = *x*2 − 1, then the Newton iteration is defined by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −     x  n   2   − 1   2  x  n      =     x  n   2   + 1   2  x  n      .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}^{2}-1}{2x_{n}}}={\frac {x_{n}^{2}+1}{2x_{n}}}.}

So Newton's method cannot be initialized at 0, since this would make *x*1 undefined. Geometrically, this is because the tangent line to f at 0 is horizontal (i.e. *f* ′(0) = 0), never intersecting the *x*-axis.

Even if the initialization is selected so that the Newton iteration can begin, the same phenomenon can block the iteration from being indefinitely continued.

If f has an incomplete domain, it is possible for Newton's method to send the iterates outside of the domain, so that it is impossible to continue the iteration.[[15]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-judd-15) For example, the [natural logarithm](https://en.wikipedia.org/wiki/Natural_logarithm) function *f*(*x*) = ln *x* has a root at 1, and is defined only for positive x. Newton's iteration in this case is given by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   ( 1 − ln ⁡  x  n   ) .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}(1-\ln x_{n}).}

So if the iteration is initialized at e, the next iterate is 0; if the iteration is initialized at a value larger than e, then the next iterate is negative. In either case, the method cannot be continued.

Analysis

# Analysis

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=12)]

Suppose that the function f has a zero at α, i.e., f(α) = 0, and f is differentiable in a [neighborhood](https://en.wikipedia.org/wiki/Topological_neighborhood) of α.

If f is continuously differentiable and its derivative is nonzero at α, then there exists a [neighborhood](https://en.wikipedia.org/wiki/Topological_neighborhood) of α such that for all starting values x0 in that neighborhood, the [sequence](https://en.wikipedia.org/wiki/Sequence) (xn) will [converge](https://en.wikipedia.org/wiki/Limit_of_a_sequence) to α.[[16]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-16)

If f is continuously differentiable, its derivative is nonzero at α, *and* it has a [second derivative](https://en.wikipedia.org/wiki/Second_derivative) at α, then the convergence is quadratic or faster. If the second derivative is not 0 at α then the convergence is merely quadratic. If the third derivative exists and is bounded in a neighborhood of α, then:

Δ  x  i + 1   =     f ″  ( α )   2  f ′  ( α )      (  Δ  x  i    )   2   + O   (  Δ  x  i    )   3    ,   {\displaystyle \Delta x_{i+1}={\frac {f''(\alpha )}{2f'(\alpha )}}\left(\Delta x_{i}\right)^{2}+O\left(\Delta x_{i}\right)^{3}\,,}

where

Δ  x  i   ≜  x  i   − α  .   {\displaystyle \Delta x_{i}\triangleq x_{i}-\alpha \,.}

If the derivative is 0 at α, then the convergence is usually only linear. Specifically, if f is twice continuously differentiable, f′(α) = 0 and f″(α) ≠ 0, then there exists a neighborhood of α such that, for all starting values x0 in that neighborhood, the sequence of iterates converges linearly, with [rate](https://en.wikipedia.org/wiki/Rate_of_convergence) ⁠1/2⁠.[[17]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-17) Alternatively, if f′(α) = 0 and f′(x) ≠ 0 for x ≠ α, x in a [neighborhood](https://en.wikipedia.org/wiki/Topological_neighborhood) U of α, α being a zero of [multiplicity](https://en.wikipedia.org/wiki/Multiplicity_(mathematics)) r, and if f ∈ Cr(U), then there exists a neighborhood of α such that, for all starting values x0 in that neighborhood, the sequence of iterates converges linearly.

However, even linear convergence is not guaranteed in pathological situations.

In practice, these results are local, and the neighborhood of convergence is not known in advance. But there are also some results on global convergence: for instance, given a right neighborhood U+ of α, if f is twice differentiable in U+ and if f′ ≠ 0, f · f″ > 0 in U+, then, for each x0 in U+ the sequence xk is monotonically decreasing to α.

Proof of quadratic convergence for Newton's iterative method

# Proof of quadratic convergence for Newton's iterative method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=13)]

According to [Taylor's theorem](https://en.wikipedia.org/wiki/Taylor's_theorem), any function f(x) which has a continuous second derivative can be represented by an expansion about a point that is close to a root of f(x). Suppose this root is α. Then the expansion of f(α) about xn is:

     f ( α ) = f (  x  n   ) +  f ′  (  x  n   ) ( α −  x  n   ) +  R  1      {\displaystyle f(\alpha )=f(x_{n})+f'(x_{n})(\alpha -x_{n})+R_{1}\,}    [1](https://en.wikipedia.org/wiki/Newton's_method#math_1)

where the [Lagrange form of the Taylor series expansion remainder](https://en.wikipedia.org/wiki/Lagrange_remainder) is

R  1   =   1  2 !     f ″  (  ξ  n   )   (  α −  x  n    )   2    ,   {\displaystyle R_{1}={\frac {1}{2!}}f''(\xi _{n})\left(\alpha -x_{n}\right)^{2}\,,}

where ξn is in between xn and α.

Since α is the root, (**[1](https://en.wikipedia.org/wiki/Newton's_method#math_1)**) becomes:

     0 = f ( α ) = f (  x  n   ) +  f ′  (  x  n   ) ( α −  x  n   ) +    1 2     f ″  (  ξ  n   )   (  α −  x  n    )   2      {\displaystyle 0=f(\alpha )=f(x_{n})+f'(x_{n})(\alpha -x_{n})+{\tfrac {1}{2}}f''(\xi _{n})\left(\alpha -x_{n}\right)^{2}\,}    [2](https://en.wikipedia.org/wiki/Newton's_method#math_2)

Dividing equation (**[2](https://en.wikipedia.org/wiki/Newton's_method#math_2)**) by f′(xn) and rearranging gives

        f (  x  n   )    f ′  (  x  n   )    +  (  α −  x  n    )  =    −  f ″  (  ξ  n   )   2  f ′  (  x  n   )      (  α −  x  n    )   2     {\displaystyle {\frac {f(x_{n})}{f'(x_{n})}}+\left(\alpha -x_{n}\right)={\frac {-f''(\xi _{n})}{2f'(x_{n})}}\left(\alpha -x_{n}\right)^{2}}    [3](https://en.wikipedia.org/wiki/Newton's_method#math_3)

Remembering that xn + 1 is defined by

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )     ,   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}\,,}    [4](https://en.wikipedia.org/wiki/Newton's_method#math_4)

one finds that

α −  x  n + 1    ⏟     ε  n + 1     =    −  f ″  (  ξ  n   )   2  f ′  (  x  n   )      (      α −  x  n    ⏟     ε  n      )   2    .   {\displaystyle \underbrace {\alpha -x_{n+1}} _{\varepsilon _{n+1}}={\frac {-f''(\xi _{n})}{2f'(x_{n})}}{(\,\underbrace {\alpha -x_{n}} _{\varepsilon _{n}}\,)}^{2}\,.}

That is,

      ε  n + 1   =    −  f ″  (  ξ  n   )   2  f ′  (  x  n   )    ⋅  ε  n   2    .   {\displaystyle \varepsilon _{n+1}={\frac {-f''(\xi _{n})}{2f'(x_{n})}}\cdot \varepsilon _{n}^{2}\,.}    [5](https://en.wikipedia.org/wiki/Newton's_method#math_5)

Taking the absolute value of both sides gives

      |   ε  n + 1    |  =    |   f ″  (  ξ  n   )  |   2  |   f ′  (  x  n   )  |     ⋅  ε  n   2    .   {\displaystyle \left|{\varepsilon _{n+1}}\right|={\frac {\left|f''(\xi _{n})\right|}{2\left|f'(x_{n})\right|}}\cdot \varepsilon _{n}^{2}\,.}    [6](https://en.wikipedia.org/wiki/Newton's_method#math_6)

Equation (**[6](https://en.wikipedia.org/wiki/Newton's_method#math_6)**) shows that the [order of convergence](https://en.wikipedia.org/wiki/Order_of_convergence) is at least quadratic if the following conditions are satisfied:

1. f′(x) ≠ 0; for all x ∈ I, where I is the interval [α − |ε0|, α + |ε0|];
2. f″(x) is continuous, for all x ∈ I;
3. M |ε0| < 1

where M is given by

M =   1 2    (   sup  x ∈ I   |  f ″  ( x ) |  )   (   sup  x ∈ I     1  |  f ′  ( x ) |     )  .    {\displaystyle M={\frac {1}{2}}\left(\sup _{x\in I}\vert f''(x)\vert \right)\left(\sup _{x\in I}{\frac {1}{\vert f'(x)\vert }}\right).\,}

If these conditions hold,

|  ε  n + 1   | ≤ M ⋅  ε  n   2    .   {\displaystyle \vert \varepsilon _{n+1}\vert \leq M\cdot \varepsilon _{n}^{2}\,.}

Fourier conditions

# Fourier conditions

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=14)]

Suppose that *f*(*x*) is a [concave function](https://en.wikipedia.org/wiki/Concave_function) on an interval, which is [strictly increasing](https://en.wikipedia.org/wiki/Strictly_increasing). If it is negative at the left endpoint and positive at the right endpoint, the [intermediate value theorem](https://en.wikipedia.org/wiki/Intermediate_value_theorem) guarantees that there is a zero ζ of f somewhere in the interval. From geometrical principles, it can be seen that the Newton iteration *x**i* starting at the left endpoint is [monotonically increasing](https://en.wikipedia.org/wiki/Monotonic_function) and convergent, necessarily to ζ.[[18]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-ostrowski-18)

[Joseph Fourier](https://en.wikipedia.org/wiki/Joseph_Fourier) introduced a modification of Newton's method starting at the right endpoint:

      y  i + 1   =  y  i   −    f (  y  i   )    f ′  (  x  i   )    .   {\displaystyle y_{i+1}=y_{i}-{\frac {f(y_{i})}{f'(x_{i})}}.}

This sequence is monotonically decreasing and convergent. By passing to the limit in this definition, it can be seen that the limit of *y**i* must also be the zero ζ.[[18]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-ostrowski-18)

So, in the case of a concave increasing function with a zero, initialization is largely irrelevant. Newton iteration starting anywhere left of the zero will converge, as will Fourier's modified Newton iteration starting anywhere right of the zero. The accuracy at any step of the iteration can be determined directly from the difference between the location of the iteration from the left and the location of the iteration from the right. If f is twice continuously differentiable, it can be proved using [Taylor's theorem](https://en.wikipedia.org/wiki/Taylor's_theorem) that

      lim  i → ∞       y  i + 1   −  x  i + 1     (  y  i   −  x  i    )  2      = −   1 2       f ″  ( ζ )    f ′  ( ζ )    ,   {\displaystyle \lim _{i\to \infty }{\frac {y_{i+1}-x_{i+1}}{(y_{i}-x_{i})^{2}}}=-{\frac {1}{2}}{\frac {f''(\zeta )}{f'(\zeta )}},}

showing that this difference in locations converges quadratically to zero.[[18]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-ostrowski-18)

All of the above can be extended to systems of equations in multiple variables, although in that context the relevant concepts of [monotonicity](https://en.wikipedia.org/wiki/Monotonicity) and concavity are more subtle to formulate.[[19]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-19) In the case of single equations in a single variable, the above monotonic convergence of Newton's method can also be generalized to replace concavity by positivity or negativity conditions on an arbitrary higher-order derivative of f. However, in this generalization, Newton's iteration is modified so as to be based on [Taylor polynomials](https://en.wikipedia.org/wiki/Taylor_polynomial) rather than the [tangent line](https://en.wikipedia.org/wiki/Tangent_line). In the case of concavity, this modification coincides with the standard Newton method.[[20]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-20)

Error for n>1 variables

# Use of Newton's method to compute square roots

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=17)]

Newton's method is one of many known [methods of computing square roots](https://en.wikipedia.org/wiki/Methods_of_computing_square_roots). Given a positive number a, the problem of finding a number x such that *x*2 = *a* is equivalent to finding a root of the function *f*(*x*) = *x*2 − *a*. The Newton iteration defined by this function is given by[[21]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-21)

      x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   −     x  n   2   − a   2  x  n      =   1 2    (   x  n   +   a  x  n      )    {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}-{\frac {x_{n}^{2}-a}{2x_{n}}}={\frac {1}{2}}\left(x_{n}+{\frac {a}{x_{n}}}\right)}  .

This happens to coincide with the ["Babylonian" method of finding square roots](https://en.wikipedia.org/wiki/Methods_of_computing_square_roots#Heron's_method), which consists of replacing an approximate root *x**n* by the [arithmetic mean](https://en.wikipedia.org/wiki/Arithmetic_mean) of xn and a⁄xn. By performing this iteration, it is possible to evaluate a square root to any desired accuracy by only using the basic [arithmetic operations](https://en.wikipedia.org/wiki/Arithmetic_operations).

#### k variables, k functions

One may also use Newton's method to solve systems of k equations, which amounts to finding the (simultaneous) zeroes of k continuously differentiable functions     f :   R   k   →  R  .   {\displaystyle f:\mathbb {R} ^{k}\to \mathbb {R} .}   This is equivalent to finding the zeroes of a single vector-valued function     F :   R   k   →   R   k   .   {\displaystyle F:\mathbb {R} ^{k}\to \mathbb {R} ^{k}.}   In the formulation given above, the scalars xn are replaced by vectors **x**n and instead of dividing the function f(xn) by its derivative f′(xn) one instead has to left multiply the function F(**x**n) by the inverse of its k × k [Jacobian matrix](https://en.wikipedia.org/wiki/Jacobian_matrix) JF(**x**n).[[22]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-:3-22)[[23]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-23) This results in the expression

x   n + 1   =   x   n   −  J  F   (   x   n    )  − 1   F (   x   n   ) .   {\displaystyle \mathbf {x} _{n+1}=\mathbf {x} _{n}-J_{F}(\mathbf {x} _{n})^{-1}F(\mathbf {x} _{n}).}

for the unknown **x**n + 1 − **x**n.[[24]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-24)

#### k variables, m equations, with m > k

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=22)]

The k-dimensional variant of Newton's method can be used to solve systems of greater than k (nonlinear) equations as well if the algorithm uses the [generalized inverse](https://en.wikipedia.org/wiki/Generalized_inverse) of the non-square [Jacobian](https://en.wikipedia.org/wiki/Jacobian_matrix_and_determinant) matrix J+ = (JTJ)−1JT instead of the inverse of J. If the [nonlinear system](https://en.wikipedia.org/wiki/System_of_nonlinear_equations) has no solution, the method attempts to find a solution in the [non-linear least squares](https://en.wikipedia.org/wiki/Non-linear_least_squares) sense. See [Gauss–Newton algorithm](https://en.wikipedia.org/wiki/Gauss%E2%80%93Newton_algorithm) for more information.

Complex functions

# Complex functions

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=24)] Main article: [Newton fractal](https://en.wikipedia.org/wiki/Newton_fractal) [![](https://thumb.wikimedia.org/wikipedia/commons/thumb/b/bf/Newtroot_1_0_0_0_0_m1.png/250px-Newtroot_1_0_0_0_0_m1.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Newtroot_1_0_0_0_0_m1.png)Basins of attraction for x5 − 1 = 0; darker means more iterations to converge.

When dealing with [complex functions](https://en.wikipedia.org/wiki/Complex_analysis), Newton's method can be directly applied to find their zeroes.[[26]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-26) Each zero has a [basin of attraction](https://en.wikipedia.org/wiki/Basin_of_attraction) in the complex plane, the set of all starting values that cause the method to converge to that particular zero. These sets can be mapped as in the image shown. For many complex functions, the boundaries of the basins of attraction are [fractals](https://en.wikipedia.org/wiki/Fractal).

In some cases there are regions in the complex plane which are not in any of these basins of attraction, meaning the iterates do not converge. For example,[[27]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-27) if one uses a real initial condition to seek a root of x2 + 1, all subsequent iterates will be real numbers and so the iterations cannot converge to either root, since both roots are non-real. In this case [almost all](https://en.wikipedia.org/wiki/Almost_all) real initial conditions lead to [chaotic behavior](https://en.wikipedia.org/wiki/Chaos_theory), while some initial conditions iterate either to infinity or to repeating cycles of any finite length.

Curt McMullen has shown that for any possible purely iterative algorithm similar to Newton's method, the algorithm will diverge on some open regions of the complex plane when applied to some polynomial of degree 4 or higher. However, McMullen gave a generally convergent algorithm for polynomials of degree 3.[[28]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-28) Furthermore, Hubbard, Schleicher and Sutherland constructed a universal set of starting points for Newton's method: for every degree d, there exists an explicitly constructible set of approximately 1.11 *d* (log *d*)2 points such that, for any suitably normalized polynomial of degree d, each root is found by Newton iteration started from at least one point of the set.[[29]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-29)

In a Banach space

# In a Banach space

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=25)]

Another generalization is Newton's method to find a root of a [functional](https://en.wikipedia.org/wiki/Functional_(mathematics)) F defined in a [Banach space](https://en.wikipedia.org/wiki/Banach_space). In this case the formulation is

X  n + 1   =  X  n   −   (    F ′  (  X  n   )    )    − 1   F (  X  n   ) ,    {\displaystyle X_{n+1}=X_{n}-{\bigl (}F'(X_{n}){\bigr )}^{-1}F(X_{n}),\,}

where F′(Xn) is the [Fréchet derivative](https://en.wikipedia.org/wiki/Fr%C3%A9chet_derivative) computed at Xn. One needs the Fréchet derivative to be boundedly invertible at each Xn in order for the method to be applicable. A condition for existence of and convergence to a root is given by the [Newton–Kantorovich theorem](https://en.wikipedia.org/wiki/Kantorovich_theorem).[[30]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-30)

#### Nash–Moser iteration

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=26)] Further information: [Nash–Moser theorem](https://en.wikipedia.org/wiki/Nash%E2%80%93Moser_theorem)

In the 1950s, [John Nash](https://en.wikipedia.org/wiki/John_Forbes_Nash_Jr.) developed a version of the Newton's method to apply to the problem of constructing [isometric embeddings](https://en.wikipedia.org/wiki/Isometric_embedding) of general [Riemannian manifolds](https://en.wikipedia.org/wiki/Riemannian_manifold) in [Euclidean space](https://en.wikipedia.org/wiki/Euclidean_space). The *loss of derivatives* problem, present in this context, made the standard Newton iteration inapplicable, since it could not be continued indefinitely (much less converge). Nash's solution involved the introduction of [smoothing](https://en.wikipedia.org/wiki/Smoothing) operators into the iteration. He was able to prove the convergence of his smoothed Newton method, for the purpose of proving an [implicit function theorem](https://en.wikipedia.org/wiki/Implicit_function_theorem) for isometric embeddings. In the 1960s, [Jürgen Moser](https://en.wikipedia.org/wiki/J%C3%BCrgen_Moser) showed that Nash's methods were flexible enough to apply to problems beyond isometric embedding, particularly in [celestial mechanics](https://en.wikipedia.org/wiki/Celestial_mechanics). Since then, a number of mathematicians, including [Mikhael Gromov](https://en.wikipedia.org/wiki/Mikhael_Gromov_(mathematician)) and [Richard Hamilton](https://en.wikipedia.org/wiki/Richard_S._Hamilton), have found generalized abstract versions of the Nash–Moser theory.[[31]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-31)[[32]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-32) In Hamilton's formulation, the Nash–Moser theorem forms a generalization of the Banach space Newton method which takes place in certain [Fréchet spaces](https://en.wikipedia.org/wiki/Fr%C3%A9chet_space).

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=29)] Main article: [Chebyshev iteration](https://en.wikipedia.org/wiki/Chebyshev_iteration)

Since higher-order Taylor expansions offer more accurate local approximations of a function f, it is reasonable to ask why Newton’s method relies only on a second-order Taylor approximation. In the 19th century, Russian mathematician Pafnuty Chebyshev explored this idea by developing a variant of Newton’s method that used cubic approximations.[[33]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-33)[[34]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-34)[[35]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-35)

Over p-adic numbers

# Over p-adic numbers

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=30)]

In p-adic analysis, the standard method to show a polynomial equation in one variable has a p-adic root is [Hensel's lemma](https://en.wikipedia.org/wiki/Hensel's_lemma), which uses the recursion from Newton's method on the p-adic numbers. Because of the more stable behavior of addition and multiplication in the p-adic numbers compared to the real numbers (specifically, the unit ball in the p-adics is a ring), convergence in Hensel's lemma can be guaranteed under much simpler hypotheses than in the classical Newton's method on the real line.

# Modified Newton methods

#### Maehly's procedure

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=33)]

A nonlinear equation has multiple solutions in general. But if the initial value is not appropriate, Newton's method may not converge to the desired solution or may converge to the same solution found earlier. When we have already found N solutions of     f ( x ) = 0   {\displaystyle f(x)=0}  , then the next root can be found by applying Newton's method to the next equation:[[37]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-37)[[38]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-38)

F ( x ) =    f ( x )    ∏  i = 1   N   ( x −  x  i   )    = 0.   {\displaystyle F(x)={\frac {f(x)}{\prod _{i=1}^{N}(x-x_{i})}}=0.}

This method is applied to obtain zeros of the [Bessel function](https://en.wikipedia.org/wiki/Bessel_function) of the second kind.[[39]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-39)

#### Hirano's modified Newton method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=34)]

Hirano's modified Newton method is a modification conserving the convergence of Newton method and avoiding unstableness.[[40]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-40) It is developed to solve complex polynomials.

#### Interval Newton's method

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=35)] ‹ The [template](https://en.wikipedia.org/wiki/Help:Template) below (*[Cite check](https://en.wikipedia.org/wiki/Template:Cite_check)*) is being considered for merging with Verify sources. Combining Newton's method with [interval arithmetic](https://en.wikipedia.org/wiki/Interval_arithmetic) is very useful in some contexts. This provides a stopping criterion that is more reliable than the usual ones (which are a small value of the function or a small variation of the variable between consecutive iterations). Also, this may detect cases where Newton's method converges theoretically but diverges numerically because of an insufficient [floating-point precision](https://en.wikipedia.org/wiki/Floating-point_arithmetic) (this is typically the case for polynomials of large degree, where a very small change of the variable may change dramatically the value of the function; see [Wilkinson's polynomial](https://en.wikipedia.org/wiki/Wilkinson's_polynomial)).[[41]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-41)[[42]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-42)

Consider f → C1(X), where X is a real interval, and suppose that we have an interval extension F′ of f′, meaning that F′ takes as input an interval Y ⊆ X and outputs an interval F′(Y) such that:

F ′  ( [ y , y ] )    = {  f ′  ( y ) }      F ′  ( Y )    ⊇ {  f ′  ( y ) ∣ y ∈ Y } .       {\displaystyle {\begin{aligned}F'([y,y])&=\{f'(y)\}\\[5pt]F'(Y)&\supseteq \{f'(y)\mid y\in Y\}.\end{aligned}}}

We also assume that 0 ∉ F′(X), so in particular f has at most one root in X. We then define the interval Newton operator by:

N ( Y ) = m −    f ( m )    F ′  ( Y )    =  {     m −    f ( m )  z      |    z ∈  F ′  ( Y )  }    {\displaystyle N(Y)=m-{\frac {f(m)}{F'(Y)}}=\left\{\left.m-{\frac {f(m)}{z}}~\right|~z\in F'(Y)\right\}}

where m ∈ Y. Note that the hypothesis on F′ implies that N(Y) is well defined and is an interval (see [interval arithmetic](https://en.wikipedia.org/wiki/Interval_arithmetic) for further details on interval operations). This naturally leads to the following sequence:

X  0      = X      X  k + 1      = N (  X  k   ) ∩  X  k   .       {\displaystyle {\begin{aligned}X_{0}&=X\\X_{k+1}&=N(X_{k})\cap X_{k}.\end{aligned}}}

The [mean value theorem](https://en.wikipedia.org/wiki/Mean_value_theorem) ensures that if there is a root of f in Xk, then it is also in Xk + 1. Moreover, the hypothesis on F′ ensures that Xk + 1 is at most half the size of Xk when m is the midpoint of Y, so this sequence converges towards [x*, x*], where x* is the root of f in X.

If F′(X) strictly contains 0, the use of extended interval division produces a union of two intervals for N(X); multiple roots are therefore automatically separated and bounded.

Applications

# Applications

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=36)]

Minimization and maximization problems

# Minimization and maximization problems

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=37)] Main article: [Newton's method in optimization](https://en.wikipedia.org/wiki/Newton's_method_in_optimization)

Newton's method can be used to find a minimum or maximum of a function f(x). The derivative is zero at a minimum or maximum, so local minima and maxima can be found by applying Newton's method to the derivative.[[43]](https://en.wikipedia.org/wiki/Newton's_method#cite_note-43) The iteration becomes:

x  n + 1   =  x  n   −     f ′  (  x  n   )    f ″  (  x  n   )    .   {\displaystyle x_{n+1}=x_{n}-{\frac {f'(x_{n})}{f''(x_{n})}}.}

Multiplicative inverses of numbers and power series

# Multiplicative inverses of numbers and power series

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=38)]

An important application is [Newton–Raphson division](https://en.wikipedia.org/wiki/Division_algorithm#Newton%E2%80%93Raphson_division), which can be used to quickly find the [reciprocal](https://en.wikipedia.org/wiki/Multiplicative_inverse) of a number a, using only multiplication and subtraction, that is to say the number x such that ⁠1/x⁠ = a. We can rephrase that as finding the zero of f(x) = ⁠1/x⁠ − a. We have f′(x) = −⁠1/x2⁠.

Newton's iteration is

x  n + 1   =  x  n   −    f (  x  n   )    f ′  (  x  n   )    =  x  n   +      1  x  n     − a   1  x  n   2      =  x  n   ( 2 − a  x  n   ) .   {\displaystyle x_{n+1}=x_{n}-{\frac {f(x_{n})}{f'(x_{n})}}=x_{n}+{\frac {{\frac {1}{x_{n}}}-a}{\frac {1}{x_{n}^{2}}}}=x_{n}(2-ax_{n}).}

Therefore, Newton's iteration needs only two multiplications and one subtraction.

This method is also very efficient to compute the multiplicative inverse of a [power series](https://en.wikipedia.org/wiki/Power_series).

Solving transcendental equations

# Solving transcendental equations

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=39)]

Many [transcendental equations](https://en.wikipedia.org/wiki/Transcendental_equation) can be solved up to an arbitrary precision by using Newton's method. For example, finding the cumulative [probability density function](https://en.wikipedia.org/wiki/Probability_density_function), such as a [Normal distribution](https://en.wikipedia.org/wiki/Normal_distribution) to fit a known probability generally involves integral functions with no known means to solve in closed form. However, computing the derivatives needed to solve them numerically with Newton's method is generally known, making numerical solutions possible. For an example, see the numerical solution to the [inverse Normal cumulative distribution](https://en.wikipedia.org/wiki/Normal_distribution#Using_the_Taylor_series_and_Newton's_method_for_the_inverse_function).

Algorithm

# Algorithm

[[edit](https://en.wikipedia.org/w/index.php?title=Newton%27s_method&action=edit&section=41)]

The following [pseudocode](https://en.wikipedia.org/wiki/Pseudocode) describes a possible implementation of Newton's method.

```
input:
Real valued function, f
The derivative of the function, f′
An initial guess to the root, x0
The required tolerance, TOL
The maximum number of iterations, MAX_IT
The smallest number we wish to divide by, ε
output:
A value x such that f(x) ≈ 0
x ← x0
for i ← 1 to MAX_IT do
   if |f′(x)| < ε then
       print("Derivative is too close to zero.")
       return
   end if
   xNew ← x - f(x) / f′(x)
   if |xNew - x| < TOL then
       return xNew
   end if
   x ← xNew
end for
print("No solution found.")
```
