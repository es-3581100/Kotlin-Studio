In mathematics, the **mandelbox** is a [fractal](https://en.wikipedia.org/wiki/Fractal) with a boxlike shape found by Tom Lowe in 2010. It is defined in a similar way to the famous [Mandelbrot set](https://en.wikipedia.org/wiki/Mandelbrot_set) as the values of a parameter such that the origin does not escape to infinity under iteration of certain geometrical transformations. The mandelbox is defined as a map of continuous [Julia sets](https://en.wikipedia.org/wiki/Julia_set), but, unlike the Mandelbrot set, can be defined in any number of dimensions.[[1]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-1) It is typically drawn in three dimensions for illustrative purposes.[[2]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-Lowe-2)[[3]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-leys-3)

## Simple definition

[[edit](https://en.wikipedia.org/w/index.php?title=Mandelbox&action=edit&section=1)]

The simple definition of the mandelbox is this: repeatedly transform a vector *z*, according to the following rules:

1. First, for each component *c* of *z* (which corresponds to a dimension), if *c* is greater than 1, subtract it from 2; or if *c* is less than -1, subtract it from −2.
2. Then, depending on the magnitude of the vector, change its magnitude using some fixed values and a specified *scale* factor.

## Generation

[[edit](https://en.wikipedia.org/w/index.php?title=Mandelbox&action=edit&section=2)]

The iteration applies to vector *z* as follows in pseudocode:[*[clarification needed](https://en.wikipedia.org/wiki/Wikipedia:Please_clarify)*]

```
function iterate(z):
    for each component in z:
        if component > 1:
            component := 2 - component
        else if component < -1:
            component := -2 - component

    if magnitude of z < 0.5:
        z := z * 4
    else if magnitude of z < 1:
        z := z / (magnitude of z)^2

    z := scale * z + c
```

Here, *c* is the constant being tested, and *scale* is a real number.[[3]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-leys-3)

## Properties

[[edit](https://en.wikipedia.org/w/index.php?title=Mandelbox&action=edit&section=3)]

A notable property of the mandelbox, particularly for scale −1.5, is that it contains approximations of many well known fractals within it.[[4]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-4)[[5]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-5)[[6]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-6)

For     1 <  |   scale   |  < 2   {\displaystyle 1<|{\text{scale}}|<2}   the mandelbox contains a solid core. Consequently, its [fractal dimension](https://en.wikipedia.org/wiki/Fractal_dimension) is 3, or *n* when generalised to *n* dimensions.[[7]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-properties-7)

For      scale  < − 1   {\displaystyle {\text{scale}}<-1}   the mandelbox sides have length 4 and for     1 <  scale  ≤ 4   n   + 1   {\displaystyle 1<{\text{scale}}\leq 4{\sqrt {n}}+1}   they have length     4 ⋅     scale  + 1    scale  − 1      {\displaystyle 4\cdot {\frac {{\text{scale}}+1}{{\text{scale}}-1}}}  .[[7]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-properties-7)

In mathematics, the **mandelbox** is a [fractal](https://en.wikipedia.org/wiki/Fractal) with a boxlike shape found by Tom Lowe in 2010. It is defined in a similar way to the famous [Mandelbrot set](https://en.wikipedia.org/wiki/Mandelbrot_set) as the values of a parameter such that the origin does not escape to infinity under iteration of certain geometrical transformations. The mandelbox is defined as a map of continuous [Julia sets](https://en.wikipedia.org/wiki/Julia_set), but, unlike the Mandelbrot set, can be defined in any number of dimensions.[[1]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-1) It is typically drawn in three dimensions for illustrative purposes.[[2]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-Lowe-2)[[3]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-leys-3)

Simple definition

# Simple definition

[[edit](https://en.wikipedia.org/w/index.php?title=Mandelbox&action=edit&section=1)]

The simple definition of the mandelbox is this: repeatedly transform a vector *z*, according to the following rules:

1. First, for each component *c* of *z* (which corresponds to a dimension), if *c* is greater than 1, subtract it from 2; or if *c* is less than -1, subtract it from −2.
2. Then, depending on the magnitude of the vector, change its magnitude using some fixed values and a specified *scale* factor.

Generation

# Generation

[[edit](https://en.wikipedia.org/w/index.php?title=Mandelbox&action=edit&section=2)]

The iteration applies to vector *z* as follows in pseudocode:[*[clarification needed](https://en.wikipedia.org/wiki/Wikipedia:Please_clarify)*]

```
function iterate(z):
    for each component in z:
        if component > 1:
            component := 2 - component
        else if component < -1:
            component := -2 - component

    if magnitude of z < 0.5:
        z := z * 4
    else if magnitude of z < 1:
        z := z / (magnitude of z)^2

    z := scale * z + c
```

Here, *c* is the constant being tested, and *scale* is a real number.[[3]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-leys-3)

Properties

# Properties

[[edit](https://en.wikipedia.org/w/index.php?title=Mandelbox&action=edit&section=3)]

A notable property of the mandelbox, particularly for scale −1.5, is that it contains approximations of many well known fractals within it.[[4]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-4)[[5]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-5)[[6]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-6)

For     1 <  |   scale   |  < 2   {\displaystyle 1<|{\text{scale}}|<2}   the mandelbox contains a solid core. Consequently, its [fractal dimension](https://en.wikipedia.org/wiki/Fractal_dimension) is 3, or *n* when generalised to *n* dimensions.[[7]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-properties-7)

For      scale  < − 1   {\displaystyle {\text{scale}}<-1}   the mandelbox sides have length 4 and for     1 <  scale  ≤ 4   n   + 1   {\displaystyle 1<{\text{scale}}\leq 4{\sqrt {n}}+1}   they have length     4 ⋅     scale  + 1    scale  − 1      {\displaystyle 4\cdot {\frac {{\text{scale}}+1}{{\text{scale}}-1}}}  .[[7]](https://en.wikipedia.org/wiki/Mandelbox#cite_note-properties-7)
