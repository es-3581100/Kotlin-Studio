In [mathematics](https://en.wikipedia.org/wiki/Mathematics), a **Misiurewicz point** is a parameter value in the [Mandelbrot set](https://en.wikipedia.org/wiki/Mandelbrot_set) (the [parameter space](https://en.wikipedia.org/wiki/Parameter_space) of [complex quadratic maps](https://en.wikipedia.org/wiki/Complex_quadratic_map)) and also in real quadratic maps of the interval[[1]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-MisiurewiczChaosPaper-1) for which the [critical point](https://en.wikipedia.org/wiki/Critical_point_(mathematics)) is strictly pre-periodic (i.e., it becomes [periodic](https://en.wikipedia.org/wiki/Periodic_points_of_complex_quadratic_mappings) after finitely many iterations but is not periodic itself). By analogy, the term *Misiurewicz point* is also used for parameters in a [multibrot set](https://en.wikipedia.org/wiki/Multibrot_set) where the unique critical point is strictly pre-periodic. This term makes less sense for maps in greater generality that have more than one free critical point because some critical points might be periodic and others not. These points are named after the Polish-American mathematician [Michał Misiurewicz](https://en.wikipedia.org/wiki/Micha%C5%82_Misiurewicz), who was the first to study them.[[2]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-2)

## Mathematical notation

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=1)]

A parameter     c   {\displaystyle c}   is a Misiurewicz point      M  k , n     {\displaystyle M_{k,n}}   if it satisfies the equations:

      f  c   ( k )   (  z  c r   ) =  f  c   ( k + n )   (  z  c r   )   {\displaystyle f_{c}^{(k)}(z_{cr})=f_{c}^{(k+n)}(z_{cr})}

and:

      f  c   ( k − 1 )   (  z  c r   ) ≠  f  c   ( k + n − 1 )   (  z  c r   )   {\displaystyle f_{c}^{(k-1)}(z_{cr})\neq f_{c}^{(k+n-1)}(z_{cr})}

so:

      M  k , n   = c :  f  c   ( k )   (  z  c r   ) =  f  c   ( k + n )   (  z  c r   )   {\displaystyle M_{k,n}=c:f_{c}^{(k)}(z_{cr})=f_{c}^{(k+n)}(z_{cr})}

where:

- z  c r     {\displaystyle z_{cr}}   is a [critical point](https://en.wikipedia.org/wiki/Critical_point_(mathematics)) of      f  c     {\displaystyle f_{c}}  ,
- k   {\displaystyle k}   and     n   {\displaystyle n}   are positive integers,
- f  c   ( k )     {\displaystyle f_{c}^{(k)}}   denotes the     k   {\displaystyle k}  -th iterate of      f  c     {\displaystyle f_{c}}  .

## Name

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=2)]

The term "Misiurewicz point" is used ambiguously: Misiurewicz originally investigated maps in which all critical points were non-recurrent; that is, in which there exists a neighbourhood for every critical point that is not visited by the orbit of this critical point. This meaning is firmly established in the context of the dynamics of iterated interval maps.[[3]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-3) Only in very special cases does a quadratic polynomial have a strictly periodic and unique critical point. In this restricted sense, the term is used in complex dynamics; a more appropriate one would be *Misiurewicz–Thurston points* (after [William Thurston](https://en.wikipedia.org/wiki/William_Thurston), who investigated post-critically finite rational maps).

## Quadratic maps

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=3)]

A [complex quadratic polynomial](https://en.wikipedia.org/wiki/Complex_quadratic_polynomial) has only one critical point. By a suitable [conjugation](https://en.wikipedia.org/wiki/Conjugacy_class) any quadratic polynomial can be transformed into a map of the form      P  c   ( z ) =  z  2   + c   {\displaystyle P_{c}(z)=z^{2}+c}   which has a single critical point at     z = 0   {\displaystyle z=0}  . The Misiurewicz points of this family of maps are [roots](https://en.wikipedia.org/wiki/Root_of_a_function) of the equations:

      P  c   ( k )   ( 0 ) =  P  c   ( k + n )   ( 0 ) ,   {\displaystyle P_{c}^{(k)}(0)=P_{c}^{(k+n)}(0),}

Subject to the condition that the critical point is not periodic, where:

- *k* is the pre-period
- *n* is the period
- P  c   ( n )   =  P  c   (  P  c   ( n − 1 )   )   {\displaystyle P_{c}^{(n)}=P_{c}(P_{c}^{(n-1)})}   denotes the *n*-fold [composition](https://en.wikipedia.org/wiki/Function_composition) of      P  c   ( z ) =  z  2   + c   {\displaystyle P_{c}(z)=z^{2}+c}   with itself i.e. the *n*th [iteration](https://en.wikipedia.org/wiki/Iterated_function) of      P  c     {\displaystyle P_{c}}  .

For example, the Misiurewicz points with *k*= 2 and *n*= 1, denoted by *M*2,1, are roots of:

           P  c   ( 2 )   ( 0 ) =  P  c   ( 3 )   ( 0 )     ⇒      c  2   + c = (  c  2   + c  )  2   + c     ⇒      c  4   + 2  c  3   = 0.       {\displaystyle {\begin{aligned}&P_{c}^{(2)}(0)=P_{c}^{(3)}(0)\\\Rightarrow {}&c^{2}+c=(c^{2}+c)^{2}+c\\\Rightarrow {}&c^{4}+2c^{3}=0.\end{aligned}}}

The root *c*= 0 is not a Misiurewicz point because the critical point is a [fixed point](https://en.wikipedia.org/wiki/Fixed_point_(mathematics)) when *c*= 0, and so is periodic rather than pre-periodic. This leaves a single Misiurewicz point *M*2,1 at *c* = −2.

### Properties of Misiurewicz points of complex quadratic mapping

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=4)]

Misiurewicz points belong to, and are [dense](https://en.wikipedia.org/wiki/Dense_set) in, the [boundary](https://en.wikipedia.org/wiki/Boundary_(topology)) of the Mandelbrot set.[[4]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Douady-4)[[5]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Schleicher-5)

If     c   {\displaystyle c}   is a Misiurewicz point, then the associated [filled Julia set](https://en.wikipedia.org/wiki/Filled_Julia_set) is equal to the [Julia set](https://en.wikipedia.org/wiki/Julia_set) and means the filled Julia set has no [interior](https://en.wikipedia.org/wiki/Interior_(topology)).

If     c   {\displaystyle c}   is a Misiurewicz point, then in the corresponding Julia set all periodic cycles are repelling (in particular the cycle that the critical orbit falls onto).

The Mandelbrot set and Julia set      J  c     {\displaystyle J_{c}}   are locally asymptotically [self-similar](https://en.wikipedia.org/wiki/Self-similarity) around Misiurewicz points.[[6]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-6)

#### Types

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=5)]

Misiurewicz points in the context of the Mandelbrot set can be classified based on several criteria. One such criterion is the number of external rays that converge on such a point.[[4]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Douady-4) Branch points, which can divide the Mandelbrot set into two or more sub-regions, have three or more [external arguments (or angles)](https://en.wikipedia.org/wiki/External_ray). Non-branch points have exactly two external rays (these correspond to points lying on arcs within the Mandelbrot set). These non-branch points are generally more subtle and challenging to identify in visual representations. End points, or branch tips, have only one external ray converging on them. Another criterion for classifying Misiurewicz points is their appearance within a plot of a subset of the Mandelbrot set. Misiurewicz points can be found at the centers of spirals as well as at points where two or more branches meet.[[7]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-7) According to the [Branch Theorem](https://en.wikipedia.org/wiki/Branching_theorem) of the Mandelbrot set,[[5]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Schleicher-5) all branch points of the Mandelbrot set are Misiurewicz points.[[4]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Douady-4)[[5]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Schleicher-5)

Most Misiurewicz parameters within the Mandelbrot set exhibit a "center of a spiral".[[8]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-8) This occurs due to the behavior at a Misiurewicz parameter where the critical value jumps onto a repelling periodic cycle after a finite number of iterations. At each point during the cycle, the Julia set exhibits asymptotic self-similarity through complex multiplication by the derivative of this cycle. If the derivative is non-real, it implies that the Julia set near the periodic cycle has a spiral structure. Consequently, a similar spiral structure occurs in the Julia set near the critical value, and by [Tan Lei](https://en.wikipedia.org/wiki/Tan_Lei)'s theorem, also in the Mandelbrot set near any Misiurewicz parameter for which the repelling orbit has a non-real multiplier. The visibility of the spiral shape depends on the value of this multiplier. The number of arms in the spiral corresponds to the number of branches at the Misiurewicz parameter, which in turn equals the number of branches at the critical value in the Julia set. Even the principal Misiurewicz point      M  4 , 1     {\displaystyle M_{4,1}}   in the 1/3-limb, located at the end of the parameter rays at angles 9/56, 11/56, and 15/56, is asymptotically a spiral with infinitely many turns, although this is difficult to discern without magnification.[*[citation needed](https://en.wikipedia.org/wiki/Wikipedia:Citation_needed)*]

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=6)]

The subscript number in each of these expressions is the base of the [numeral system](https://en.wikipedia.org/wiki/Numeral_system) being used.

In [mathematics](https://en.wikipedia.org/wiki/Mathematics), a **Misiurewicz point** is a parameter value in the [Mandelbrot set](https://en.wikipedia.org/wiki/Mandelbrot_set) (the [parameter space](https://en.wikipedia.org/wiki/Parameter_space) of [complex quadratic maps](https://en.wikipedia.org/wiki/Complex_quadratic_map)) and also in real quadratic maps of the interval[[1]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-MisiurewiczChaosPaper-1) for which the [critical point](https://en.wikipedia.org/wiki/Critical_point_(mathematics)) is strictly pre-periodic (i.e., it becomes [periodic](https://en.wikipedia.org/wiki/Periodic_points_of_complex_quadratic_mappings) after finitely many iterations but is not periodic itself). By analogy, the term *Misiurewicz point* is also used for parameters in a [multibrot set](https://en.wikipedia.org/wiki/Multibrot_set) where the unique critical point is strictly pre-periodic. This term makes less sense for maps in greater generality that have more than one free critical point because some critical points might be periodic and others not. These points are named after the Polish-American mathematician [Michał Misiurewicz](https://en.wikipedia.org/wiki/Micha%C5%82_Misiurewicz), who was the first to study them.[[2]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-2)

Mathematical notation

# Mathematical notation

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=1)]

A parameter     c   {\displaystyle c}   is a Misiurewicz point      M  k , n     {\displaystyle M_{k,n}}   if it satisfies the equations:

      f  c   ( k )   (  z  c r   ) =  f  c   ( k + n )   (  z  c r   )   {\displaystyle f_{c}^{(k)}(z_{cr})=f_{c}^{(k+n)}(z_{cr})}

and:

      f  c   ( k − 1 )   (  z  c r   ) ≠  f  c   ( k + n − 1 )   (  z  c r   )   {\displaystyle f_{c}^{(k-1)}(z_{cr})\neq f_{c}^{(k+n-1)}(z_{cr})}

so:

      M  k , n   = c :  f  c   ( k )   (  z  c r   ) =  f  c   ( k + n )   (  z  c r   )   {\displaystyle M_{k,n}=c:f_{c}^{(k)}(z_{cr})=f_{c}^{(k+n)}(z_{cr})}

where:

- z  c r     {\displaystyle z_{cr}}   is a [critical point](https://en.wikipedia.org/wiki/Critical_point_(mathematics)) of      f  c     {\displaystyle f_{c}}  ,
- k   {\displaystyle k}   and     n   {\displaystyle n}   are positive integers,
- f  c   ( k )     {\displaystyle f_{c}^{(k)}}   denotes the     k   {\displaystyle k}  -th iterate of      f  c     {\displaystyle f_{c}}  .

Name

# Name

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=2)]

The term "Misiurewicz point" is used ambiguously: Misiurewicz originally investigated maps in which all critical points were non-recurrent; that is, in which there exists a neighbourhood for every critical point that is not visited by the orbit of this critical point. This meaning is firmly established in the context of the dynamics of iterated interval maps.[[3]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-3) Only in very special cases does a quadratic polynomial have a strictly periodic and unique critical point. In this restricted sense, the term is used in complex dynamics; a more appropriate one would be *Misiurewicz–Thurston points* (after [William Thurston](https://en.wikipedia.org/wiki/William_Thurston), who investigated post-critically finite rational maps).

Quadratic maps

# Quadratic maps

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=3)]

A [complex quadratic polynomial](https://en.wikipedia.org/wiki/Complex_quadratic_polynomial) has only one critical point. By a suitable [conjugation](https://en.wikipedia.org/wiki/Conjugacy_class) any quadratic polynomial can be transformed into a map of the form      P  c   ( z ) =  z  2   + c   {\displaystyle P_{c}(z)=z^{2}+c}   which has a single critical point at     z = 0   {\displaystyle z=0}  . The Misiurewicz points of this family of maps are [roots](https://en.wikipedia.org/wiki/Root_of_a_function) of the equations:

      P  c   ( k )   ( 0 ) =  P  c   ( k + n )   ( 0 ) ,   {\displaystyle P_{c}^{(k)}(0)=P_{c}^{(k+n)}(0),}

Subject to the condition that the critical point is not periodic, where:

- *k* is the pre-period
- *n* is the period
- P  c   ( n )   =  P  c   (  P  c   ( n − 1 )   )   {\displaystyle P_{c}^{(n)}=P_{c}(P_{c}^{(n-1)})}   denotes the *n*-fold [composition](https://en.wikipedia.org/wiki/Function_composition) of      P  c   ( z ) =  z  2   + c   {\displaystyle P_{c}(z)=z^{2}+c}   with itself i.e. the *n*th [iteration](https://en.wikipedia.org/wiki/Iterated_function) of      P  c     {\displaystyle P_{c}}  .

For example, the Misiurewicz points with *k*= 2 and *n*= 1, denoted by *M*2,1, are roots of:

           P  c   ( 2 )   ( 0 ) =  P  c   ( 3 )   ( 0 )     ⇒      c  2   + c = (  c  2   + c  )  2   + c     ⇒      c  4   + 2  c  3   = 0.       {\displaystyle {\begin{aligned}&P_{c}^{(2)}(0)=P_{c}^{(3)}(0)\\\Rightarrow {}&c^{2}+c=(c^{2}+c)^{2}+c\\\Rightarrow {}&c^{4}+2c^{3}=0.\end{aligned}}}

The root *c*= 0 is not a Misiurewicz point because the critical point is a [fixed point](https://en.wikipedia.org/wiki/Fixed_point_(mathematics)) when *c*= 0, and so is periodic rather than pre-periodic. This leaves a single Misiurewicz point *M*2,1 at *c* = −2.

Properties of Misiurewicz points of complex quadratic mapping

# Properties of Misiurewicz points of complex quadratic mapping

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=4)]

Misiurewicz points belong to, and are [dense](https://en.wikipedia.org/wiki/Dense_set) in, the [boundary](https://en.wikipedia.org/wiki/Boundary_(topology)) of the Mandelbrot set.[[4]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Douady-4)[[5]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Schleicher-5)

If     c   {\displaystyle c}   is a Misiurewicz point, then the associated [filled Julia set](https://en.wikipedia.org/wiki/Filled_Julia_set) is equal to the [Julia set](https://en.wikipedia.org/wiki/Julia_set) and means the filled Julia set has no [interior](https://en.wikipedia.org/wiki/Interior_(topology)).

If     c   {\displaystyle c}   is a Misiurewicz point, then in the corresponding Julia set all periodic cycles are repelling (in particular the cycle that the critical orbit falls onto).

The Mandelbrot set and Julia set      J  c     {\displaystyle J_{c}}   are locally asymptotically [self-similar](https://en.wikipedia.org/wiki/Self-similarity) around Misiurewicz points.[[6]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-6)

#### Types

[[edit](https://en.wikipedia.org/w/index.php?title=Misiurewicz_point&action=edit&section=5)]

Misiurewicz points in the context of the Mandelbrot set can be classified based on several criteria. One such criterion is the number of external rays that converge on such a point.[[4]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Douady-4) Branch points, which can divide the Mandelbrot set into two or more sub-regions, have three or more [external arguments (or angles)](https://en.wikipedia.org/wiki/External_ray). Non-branch points have exactly two external rays (these correspond to points lying on arcs within the Mandelbrot set). These non-branch points are generally more subtle and challenging to identify in visual representations. End points, or branch tips, have only one external ray converging on them. Another criterion for classifying Misiurewicz points is their appearance within a plot of a subset of the Mandelbrot set. Misiurewicz points can be found at the centers of spirals as well as at points where two or more branches meet.[[7]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-7) According to the [Branch Theorem](https://en.wikipedia.org/wiki/Branching_theorem) of the Mandelbrot set,[[5]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Schleicher-5) all branch points of the Mandelbrot set are Misiurewicz points.[[4]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Douady-4)[[5]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-Schleicher-5)

Most Misiurewicz parameters within the Mandelbrot set exhibit a "center of a spiral".[[8]](https://en.wikipedia.org/wiki/Misiurewicz_point#cite_note-8) This occurs due to the behavior at a Misiurewicz parameter where the critical value jumps onto a repelling periodic cycle after a finite number of iterations. At each point during the cycle, the Julia set exhibits asymptotic self-similarity through complex multiplication by the derivative of this cycle. If the derivative is non-real, it implies that the Julia set near the periodic cycle has a spiral structure. Consequently, a similar spiral structure occurs in the Julia set near the critical value, and by [Tan Lei](https://en.wikipedia.org/wiki/Tan_Lei)'s theorem, also in the Mandelbrot set near any Misiurewicz parameter for which the repelling orbit has a non-real multiplier. The visibility of the spiral shape depends on the value of this multiplier. The number of arms in the spiral corresponds to the number of branches at the Misiurewicz parameter, which in turn equals the number of branches at the critical value in the Julia set. Even the principal Misiurewicz point      M  4 , 1     {\displaystyle M_{4,1}}   in the 1/3-limb, located at the end of the parameter rays at angles 9/56, 11/56, and 15/56, is asymptotically a spiral with infinitely many turns, although this is difficult to discern without magnification.[*[citation needed](https://en.wikipedia.org/wiki/Wikipedia:Citation_needed)*]

Point     c = − 1.54368901269208... =  M  3 , 1     {\displaystyle c=-1.54368901269208...=M_{3,1}}   is a principal Misiurewicz point of the main antenna of the Mandelbrot set. It is the landing point for two external rays:       5 12     {\displaystyle {\frac {5}{12}}}  ,       7 12     {\displaystyle {\frac {7}{12}}}  , and has pre-period     k = 3   {\displaystyle k=3}   and period     n = 1   {\displaystyle n=1}  .

Point     c = − 0.77568377... + i  0.13646737... =  M  23 , 2     {\displaystyle c=-0.77568377...+i\,0.13646737...=M_{23,2}}   may be recognized as the center of a two-arms spiral located in the so-called "Seahorse Valley" of the Mandelbrot set. It is the landing point of 2 external rays with angles:       8388611 25165824     {\displaystyle {\frac {8388611}{25165824}}}   and       8388613 25165824     {\displaystyle {\frac {8388613}{25165824}}}   where the denominator is     3 ∗  2  23     {\displaystyle 3*2^{23}}  , and has pre-period     k = 23   {\displaystyle k=23}   and period     n = 2   {\displaystyle n=2}  .
