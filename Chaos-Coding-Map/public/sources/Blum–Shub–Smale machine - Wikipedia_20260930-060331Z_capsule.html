# Blum–Shub–Smale machine

- [Deutsch](https://de.wikipedia.org/wiki/Blum-Shub-Smale-Maschine)
- [Français](https://fr.wikipedia.org/wiki/Machine_de_Blum-Shub-Smale)
- [Português](https://pt.wikipedia.org/wiki/M%C3%A1quina_de_Blum%E2%80%93Shub%E2%80%93Smale)
 [Edit links](https://www.wikidata.org/wiki/Special:EntityPage/Q3274386#sitelinks-wikipedia)                          From Wikipedia, the free encyclopedia   Model of computation over real numbers

In [computation theory](https://en.wikipedia.org/wiki/Computation_theory), the **Blum–Shub–Smale machine**, or **BSS machine**, is a [model of computation](https://en.wikipedia.org/wiki/Model_of_computation) introduced by [Lenore Blum](https://en.wikipedia.org/wiki/Lenore_Blum), [Michael Shub](https://en.wikipedia.org/wiki/Michael_Shub) and [Stephen Smale](https://en.wikipedia.org/wiki/Stephen_Smale), intended to describe computations over the [real numbers](https://en.wikipedia.org/wiki/Real_number).[[1]](https://en.wikipedia.org/wiki/Blum%E2%80%93Shub%E2%80%93Smale_machine#cite_note-1) Essentially, a BSS machine is a [random-access machine](https://en.wikipedia.org/wiki/Random-access_machine) with registers that can store arbitrary real numbers and that can compute [rational functions](https://en.wikipedia.org/wiki/Rational_function) over reals in a single time step. It is closely related to the [real RAM](https://en.wikipedia.org/wiki/Real_RAM) model.

BSS machines are more powerful than [Turing machines](https://en.wikipedia.org/wiki/Turing_machine), because the latter are by definition restricted to a [finite set](https://en.wikipedia.org/wiki/Finite_set) of symbols.[[2]](https://en.wikipedia.org/wiki/Blum%E2%80%93Shub%E2%80%93Smale_machine#cite_note-2) A Turing machine can represent a [countable set](https://en.wikipedia.org/wiki/Countable_set) (such as the rational numbers) by strings of symbols, but this does not extend to the [uncountable](https://en.wikipedia.org/wiki/Uncountable_set) real numbers.

## Definition

[[edit](https://en.wikipedia.org/w/index.php?title=Blum%E2%80%93Shub%E2%80%93Smale_machine&action=edit&section=1)]

A BSS machine **M** is given by a list     I   {\displaystyle I}   of     N + 1   {\displaystyle N+1}   instructions (to be described below), indexed     0 , 1 , … , N   {\displaystyle 0,1,\dots ,N}  . A configuration of M is a tuple     ( k , r , w , x )   {\displaystyle (k,r,w,x)}  , where     k   {\displaystyle k}   is the index of the instruction to be executed next,     r   {\displaystyle r}   and     w   {\displaystyle w}   are registers holding non-negative integers, and     x = (  x  0   ,  x  1   , … )   {\displaystyle x=(x_{0},x_{1},\ldots )}   is a list of real numbers, with all but finitely many being zero. The list     x   {\displaystyle x}   is thought of as holding the contents of all registers of **M**. The computation begins with configuration     ( 0 , 0 , 0 , x )   {\displaystyle (0,0,0,x)}   and ends whenever     k = N   {\displaystyle k=N}  ; the final content of     x   {\displaystyle x}   is said to be the output of the machine.

The instructions of **M** can be of the following types:

- **Computation**: a substitution      x  0   :=  g  k   ( x )   {\displaystyle x_{0}:=g_{k}(x)}   is performed, where      g  k     {\displaystyle g_{k}}   is an arbitrary rational function (a quotient of two polynomial functions with arbitrary real coefficients); registers     r   {\displaystyle r}   and     w   {\displaystyle w}   may be changed, either by     r := 0   {\displaystyle r:=0}   or     r := r + 1   {\displaystyle r:=r+1}   and similarly for     w   {\displaystyle w}  . The next instruction is     k + 1   {\displaystyle k+1}  .
- **Branch(    l   {\displaystyle l}  )**: if      x  0   ≥ 0   {\displaystyle x_{0}\geq 0}   then goto     l   {\displaystyle l}  ; else goto     k + 1   {\displaystyle k+1}  .
- **Copy**(     x  r   ,  x  w     {\displaystyle x_{r},x_{w}}  ): the content of the "read" register      x  r     {\displaystyle x_{r}}   is copied into the "written" register      x  w     {\displaystyle x_{w}}  ; the next instruction is     k + 1   {\displaystyle k+1}  .

## Theory

[[edit](https://en.wikipedia.org/w/index.php?title=Blum%E2%80%93Shub%E2%80%93Smale_machine&action=edit&section=2)]

Blum, Shub and Smale defined the [complexity classes](https://en.wikipedia.org/wiki/Complexity_class) P ([polynomial time](https://en.wikipedia.org/wiki/Time_complexity)) and NP (nondeterministic polynomial time) in the BSS model. Here NP is defined by adding an existentially-quantified input to a problem. They give a problem which is NP-complete for the class NP so defined: existence of roots of quartic polynomials. This is an analogue of the [Cook–Levin theorem](https://en.wikipedia.org/wiki/Cook%E2%80%93Levin_theorem) for real numbers.

A BSS machine **M** is given by a list     I   {\displaystyle I}   of     N + 1   {\displaystyle N+1}   instructions (to be described below), indexed     0 , 1 , … , N   {\displaystyle 0,1,\dots ,N}  . A configuration of M is a tuple     ( k , r , w , x )   {\displaystyle (k,r,w,x)}  , where     k   {\displaystyle k}   is the index of the instruction to be executed next,     r   {\displaystyle r}   and     w   {\displaystyle w}   are registers holding non-negative integers, and     x = (  x  0   ,  x  1   , … )   {\displaystyle x=(x_{0},x_{1},\ldots )}   is a list of real numbers, with all but finitely many being zero. The list     x   {\displaystyle x}   is thought of as holding the contents of all registers of **M**. The computation begins with configuration     ( 0 , 0 , 0 , x )   {\displaystyle (0,0,0,x)}   and ends whenever     k = N   {\displaystyle k=N}  ; the final content of     x   {\displaystyle x}   is said to be the output of the machine.

The instructions of **M** can be of the following types:

- **Computation**: a substitution      x  0   :=  g  k   ( x )   {\displaystyle x_{0}:=g_{k}(x)}   is performed, where      g  k     {\displaystyle g_{k}}   is an arbitrary rational function (a quotient of two polynomial functions with arbitrary real coefficients); registers     r   {\displaystyle r}   and     w   {\displaystyle w}   may be changed, either by     r := 0   {\displaystyle r:=0}   or     r := r + 1   {\displaystyle r:=r+1}   and similarly for     w   {\displaystyle w}  . The next instruction is     k + 1   {\displaystyle k+1}  .
- **Branch(    l   {\displaystyle l}  )**: if      x  0   ≥ 0   {\displaystyle x_{0}\geq 0}   then goto     l   {\displaystyle l}  ; else goto     k + 1   {\displaystyle k+1}  .
- **Copy**(     x  r   ,  x  w     {\displaystyle x_{r},x_{w}}  ): the content of the "read" register      x  r     {\displaystyle x_{r}}   is copied into the "written" register      x  w     {\displaystyle x_{w}}  ; the next instruction is     k + 1   {\displaystyle k+1}  .

Theory

# Theory

[[edit](https://en.wikipedia.org/w/index.php?title=Blum%E2%80%93Shub%E2%80%93Smale_machine&action=edit&section=2)]

Blum, Shub and Smale defined the [complexity classes](https://en.wikipedia.org/wiki/Complexity_class) P ([polynomial time](https://en.wikipedia.org/wiki/Time_complexity)) and NP (nondeterministic polynomial time) in the BSS model. Here NP is defined by adding an existentially-quantified input to a problem. They give a problem which is NP-complete for the class NP so defined: existence of roots of quartic polynomials. This is an analogue of the [Cook–Levin theorem](https://en.wikipedia.org/wiki/Cook%E2%80%93Levin_theorem) for real numbers.
